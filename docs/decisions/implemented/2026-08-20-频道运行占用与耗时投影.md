# 频道运行占用与耗时投影

状态：implemented

## 决策

`ChannelRuntimeProjection` 携带当前 Episode 的上下文占用、缓存读取，以及已关闭区间的轮次 / 步骤 / 工具耗时和本步用量。数据来自 DSH 公开 `sessionProjections`（`contextPressure`、`tokenUsage`、`contextBreakdown`）和 Session 事件的 `time` / `assistant/message.usage`。

## 运行语义

- 占用只在同时有 `projectedTokens` 与 `contextWindow` 时出现；没有样本则省略，不投影 0/0。
- 占用是参考值，不是计费，也不作为压缩或门禁输入。组成三项是启发式，不能加总成占用。
- 耗时只记录事件时间戳的关闭区间。进行中的步骤不写墙上时钟。
- 首字耗时只在投影里出现；`assistant/chunk` 仍不进入 SSE。
- 产品界面：会话检查器用 2px 青蓝细线和 `facts` 展示占用；工作轨迹状态列展示耗时，选中行才展示本步用量。不嵌 DSH 官方状态栏，不把这些数字放进消息列或对象列。

现行接线见 `docs/08-接线与Server宿主设计.md`，界面见 `docs/NekroNxt界面交互模型.md` §3.3。
