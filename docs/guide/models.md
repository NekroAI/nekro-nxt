# 配置模型

NekroNXT 复用 DSH 的模型供应商、Settings 和凭据体系，不维护第二份模型目录。

## 添加供应商

1. 前往「设置 → 模型供应商」；
2. 从可配置目录选择供应商；
3. 填写 API Key、Base URL、协议和供应商要求的字段；
4. 运行连接测试；
5. 保存配置和凭据。

供应商列表和供应商页显示当前配置最近一次连接测试的结果；修改 API 地址、协议或 API Key 后需要重新测试。

API Key 是只写凭据。页面用“已配置”或“未配置”显示凭据状态，保存后不回显原值；清除凭据会使依赖它的模型不可用。

## 管理模型列表

在「设置 → 模型供应商」中选择已配置的供应商，就能编辑它的模型列表。每个模型可以填写模型 ID、显示名、上下文长度和最大输出，并通过“支持图片”开关声明它能否直接理解图片。

- 添加模型：点击“添加模型”填写模型 ID。供应商提供模型查询时，“获取可用模型”会列出尚未加入的模型：可以搜索，点选后“加入所选”，或用“全部加入”加入当前搜索到的全部模型。已在列表中的模型会跳过。不提供查询的供应商（如 DeepSeek 官方接入）不显示这个按钮，需要手动添加；
- 列表超过 10 个模型时，上方出现搜索框，每行前出现勾选框。表头的勾选框选中或取消当前搜索到的全部模型，选中后可以“删除所选”；
- 修改列表只在保存时生效，没有改动模型时保存不会影响供应商自带的列表；
- 改过列表的内置供应商会显示“已自定义”，可以用“恢复默认模型”改回供应商自带的列表。恢复后，使用被移除模型的智能体需要重新选择模型；
- 通用接入的供应商新增目录之外的模型时，需要在高级设置中填写 API 地址并选择 API 协议。选择协议后，该供应商的全部模型都使用这个协议；
- 少数供应商的模型由适配器固定提供，页面只显示列表，不提供编辑。

供应商停用或改名后，原来的模型可能从列表中消失。使用这类模型的智能体会在工作台和“需要处理”中提示，可以改用同一供应商的可用模型，或在模型设置中把它加回列表。

## 为智能体选择模型

创建或编辑智能体时，从实时模型目录选择默认模型。配置保存为不可变版本；运行中的工具使用启动时的配置，兼容的新配置在下一个安全边界生效。

模型提供多档思考强度时，主模型下方会出现“思考强度”，可以选择模型默认或其中一档。强度越高，处理复杂问题越可靠，回答也越慢、用量越多；改用不提供所选强度的模型后，回到模型默认。ChatGPT 套餐的模型在登录或“获取可用模型”时带上账号返回的思考强度、上下文长度和图片能力。

模型明确声明支持图片时，频道原图可以进入主模型上下文。文本模型需要配置辅助视觉模型，再通过图片检查工具取得结构化证据。图片能力以模型列表中的“支持图片”声明为准，可以在模型设置中修改。图片多到超出模型单次请求的上限时，最早的几张不再发给模型，对话照常继续；这些图片在思考与工具执行过程里显示为“图片已省略（超出模型的图片上限）”。

## 备用模型

在智能体的“模型”里，主模型下方可以添加最多 3 个备用模型，按顺序使用。没有添加时，主模型出错照常报错。

- **什么时候换**：主模型的额度或余额用完时立即换；持续限流、服务出错、超时或回复为空时，先照常重试几次，仍然失败才换。API Key 无效、上下文超出长度这类问题换模型也解决不了，不会换，照常报错；
- **换的时候**：只重新请求失败的那一步。失败的那次请求不会执行任何工具，不会重复发消息或改文件。备用模型也都失败时，这一轮照常报错结束；
- **换回主模型**：换过去之后，这段对话会一直用备用模型；过了冷却时间、再收到新消息时换回主模型，一轮处理中途不会来回切换。冷却时间在“设置 → 模型”里调整，默认限流或出错后 10 分钟、额度用完后 1 小时。冷却期间，所有智能体都直接跳过这个模型；重启后会先试主模型；
- **看得到**：用着备用模型时，频道页头显示“备用模型”，悬停可以看原因和什么时候换回；每次换和换回都会记在“日志”里；
- 备用模型的缓存要重新建立，换过去后的第一次请求会慢一些、贵一些。主模型能看图而备用模型不能时，换过去后它只知道这里有一张图片、看不到内容，添加时会提示；
- 跟随主模型的子对话同样会换；单独选了子对话模型的子对话、压缩和视觉模型不受影响。修改备用模型立即生效，不会打断正在进行的对话。

## 上下文压缩

对话变长后，旧内容会被整理成摘要，分两种：

- **会话内压缩**：上下文快满时，在当前会话里整理更早的内容。默认跟随主模型和它的思考强度，这样请求开头和平时一样，能用上模型的缓存；换成别的模型或强度就用不上缓存。
- **开新会话时压缩**：会话闲置满 6 小时后，下次被唤醒时，上下文占用达到“闲置压缩阈值”才会先整理摘要再开新会话；低于阈值则继续原会话。闲置时间按智能体上次收到的对话消息计算。阈值在“设置 → 聊天”中调整，默认 50%，建议 30%–60%，可填写 1%–100%。上下文接近容量上限时仍会自动压缩，频道里的手动压缩也照常执行。开新会话使用该设置页已有的压缩模型，选择更快的模型可缩短等待时间。

两种都可以在智能体的“模型”里另外指定。压缩进行时，频道显示“压缩中”。开新会话时的压缩最多等待的时间在“设置 → 聊天”里调整，默认 3 分钟；到时间还没整理完，就带着一句说明开始新会话，智能体需要时再翻聊天记录。

## 子对话模型

开启子对话后，可以在智能体的“模型”里添加子对话模型，每个写上名称和用途，例如“快速：适合翻聊天记录、整理资料，不适合写代码”。智能体开子对话时会看到这些名称和用途，按事情挑一个；没有挑的时候用“不指定时”选的那个，默认是主模型。

- 子对话开启后一直用同一个模型，追加说明、重启后继续都不会换；
- 子对话页的标题下方显示它用的模型；
- 子对话本来就不复用频道对话的缓存，换成别的模型不会让频道对话变慢或变贵；
- 修改子对话模型后，正在进行的频道对话要到下一段会话才看得到新的选项（闲置后被唤醒、手动压缩或重启之后），不会打断当前对话；
- 子对话模型对应的供应商被删掉后，智能体再选它会收到“现在不可用”的提示，不会悄悄换成别的模型。智能体的“模型”里会标出“模型已移除”。

## 排障

- 目录为空：确认供应商配置已保存，运行 NekroNXT 的设备可以访问供应商；
- 测试失败：核对 API Key、Base URL、协议和模型权限；
- 智能体提示模型已不在列表中：改用同一供应商的可用模型，或在模型设置中把它加回列表；
- 图片不可用：核对模型能力声明或辅助视觉模型配置。
