# NekroNxt 产品交互原型

这是用于确认产品需求与交互语义的离线原型，不连接真实模型、平台账号或本地 Runtime，也不会写入真实配置。

## 打开方式

最简单的方式是直接打开 `index.html`。如果浏览器限制本地脚本，可在本目录启动任意静态文件服务后访问首页。

## 建议验收顺序

顶部“快速跳转”包含七个场景：

1. 智能体首页：确认列表、运行状态、“打开”和“管理”的职责；
2. 创建智能体：连续执行四步向导，确认最终原子创建语义；
3. 单频道会话：展开排队消息，分别测试“让工具完成”和“停止当前任务”；
4. 智能体能力配置：修改开关，分别测试普通保存与安全间隙切换；
5. 频道绑定：回看五个步骤，分别执行接收测试和发送测试；
6. 创造工作台：确认异常 URL 验证，再依次保存本地插件、启用给小奈；
7. 本地扩展详情：切换默认版本、独立更新智能体启用关系、停用全部后观察删除按钮。

顶部“显示交互逻辑标注”会在关键控件旁展示按钮前提和操作后果。

## 已实现的状态约束

- 页面主对象在智能体、频道绑定草稿、扩展草稿和本地扩展之间明确切换；
- 不同频道的消息不混流；
- 新群消息不打断 Tool，只在安全间隙注入；
- 智能体配置保存产生新的配置版本；
- 适配器、平台连接、频道和频道绑定分层；
- 动态运行、保存扩展版本、为智能体启用扩展相互分离；
- 仍有智能体使用扩展时禁止删除本地扩展。

刷新页面会恢复全部初始演示状态。
