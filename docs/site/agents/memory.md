# 记忆与笔记

智能体在每个群里记两种笔记，并在需要时翻这个群的聊天记录。打开频道，右侧的「记忆」里能看到她在这个群记住的内容。

![频道右侧的「记忆」：当前会话、群笔记和成员笔记](shot:agents-memory)

## 群笔记

记关于整个群的事：群规、固定活动、常聊的话题、群里的梗。最多 2000 字。

点「群笔记」旁的“编辑”可以直接修改。打开“锁定”后她就不能再改，适合你整理好、不想被改乱的内容。

## 成员笔记

记关于某个人的事：希望怎么被称呼、最近在忙什么、有什么喜好，每人最多 300 字。成员笔记不会一直放在她眼前，而是在这个人说话时一起出现，所以群里人再多，她也能认出回来的人。

在「成员笔记」点“全部”，可以搜索、修改某个人的笔记，或者点“忘掉”删除关于这个人的全部笔记。

成员笔记只在这个群有效，同一个人在别的群里需要重新认识。

## 她什么时候记

笔记由她自己写：有人告诉她称呼、近况，或者群里定了新规矩，她会顺手记下。群里安静一段时间后，她还会回顾刚才的对话，把值得长期记住的整理进笔记，不会在群里发言。

笔记里没有的事，她会去翻这个群的聊天记录：有人问起之前说过的话，她会先查原话再回答，查不到才说不记得。

## 读取与整理

很久没被叫到时，积压的消息不会一股脑交给她。展开「读取与整理」可以调：

![「读取与整理」的三个设置](shot:agents-reading)

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 未读消息上限 | 4 万字 | 被叫醒时最多读这么多未读消息，更早的合并成一段摘要 |
| 未读图片上限 | 6 张 | 最多看这么多张未读图片 |
| 静默后整理 | 45 分钟 | 群里安静这么久后整理笔记；可以关闭 |

跑团、记录类的群可以调高读取上限；表情包多的群少看几张图，回复会更快、更省。

## 和上下文的区别

笔记会一直保留，“清空上下文”和压缩都不会动它。上下文是她眼下这段对话记得的内容，会被压缩或清空，见[上下文与压缩](context.md)。
