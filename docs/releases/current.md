# ✨ 本次更新

这次更新主要改进智能体在群里什么时候开口、用什么模型：新增「智能响应」，对方话没说完时会先等一等；主模型用完额度时可以自动换到备用模型。凭据集中到一处管理，扩展用它们发请求时拿不到明文。扩展还可以在智能体的消息发出前做处理。

## 🚀 主要变化

- **智能响应**：频道的「何时回复」新增「智能响应」。被 @ 或回复时一定回；提到它的名字或别名、刚和它聊过的人接着说话时也会叫醒它，由它决定接不接话；同一个人连着发的几条会合并后再交给它。别名在智能体设定里填写，各项参数在频道信息里按频道调整；
- **等对方说完**：智能体判断对方话还没说完时，可以先等一等，等这个人停下来后再一起回复。每次最多等多久、一共最多等多久，可以在频道信息里调整，也可以关掉；
- **备用模型**：智能体可以按顺序配置最多 3 个备用模型。主模型额度用完、持续出错或超时时，自动换到下一个，过了冷却时间再换回主模型。频道页头会标出当前在用备用模型，冷却时长在设置中调整；
- **按用途选模型**：子对话、整理上下文可以各自选用不同的模型，智能体也可以设置思考强度；
- **ChatGPT 账号登录**：模型供应商可以用 ChatGPT 账号登录使用，同一个供应商可以保存多个账号；
- **凭据**：「设置 → 凭据」集中管理 API Key 等凭据，扩展配置、试运行配置、MCP 服务和命令都可以直接选用。扩展发请求时只拿到占位符，凭据只在发往它允许的网站时填入；工具结果进入上下文前也会隐藏凭据。GitHub 账号移到「设置 → 关联账号」，在智能体能力中授权给哪个智能体使用；
- **扩展配置**：智能体可以查看扩展的配置与状态，并逐项修改；配置项可以设为只有管理员能改；每次修改都会留下记录，可以恢复到之前的配置；
- **出站处理**：扩展可以在智能体的消息发出前修改内容、追加消息或取消发送，也可以只查看发出的消息。频道时间线会标出经过了哪些处理，多个扩展的处理顺序可以调整；
- **频道列表**：频道可以置顶，分组可以收起，收起后显示组内的未读数；
- **更换数据目录**：桌面版可以在「设置 → 存储」中更改数据目录，选择移动或复制，失败时回到原目录。升级前的备份也在这里管理；
- **扩展更新**：启动后会检查一次社区更新，有新版本的扩展会出现在提醒里，在扩展详情页可以直接更新；社区发现页会标出已安装的扩展。

## 🛠️ 改进与修复

- **模型出错时**：失败的原因会写进日志；智能体不可用时，失败的那一轮下面会提供「压缩上下文」和「清空上下文」；图片超过模型上限时，自动省略最早的图片继续对话；群聊里的 GIF 以第一帧发给模型；
- **整理上下文**：会话闲置较久后再被叫醒时，上下文占用达到阈值才整理摘要并开新会话，阈值在「设置 → 聊天」中调整；整理时网页上会显示「压缩中」；
- **模型列表**：获取可用模型改为搜索后挑选加入，模型很多时可以搜索和批量删除；测试连接时先选一个模型再发测试请求；
- **通知**：可以分别关闭扩展通知和实例连接状态通知；同一来源的通知会合并成一条；桌面版窗口在前台时不再弹出系统通知；
- **连接**：OneBot 合并转发兼容更多协议端，文件消息保留文件名并能下载；OneBot 的处理中表情回应偶尔失败后，不再整个连接都不挂；QQ 官方机器人恢复发送普通文件；
- **扩展**：已过期或已由智能体自行完成的请求不再留在等待确认里；保存候选扩展不再被其他频道的回合挡住，也不再因为工具返回值里的空字段而失败；发布到社区失败后，填好的内容会保留，失败原因显示在对话框里；
- **桌面版与浏览器**：本地实例重启后沿用上次的端口和外观设置；在局域网用 HTTP 打开时，发消息、上传附件和复制都能正常使用；侧边浮层和全屏编辑在 Windows 上不再和窗口按钮重叠。

## ⚠️ 升级前留意

- **GitHub 账号位置变了**：原来在凭据里的 GitHub 账号会自动移到「设置 → 关联账号」，已有的命令授权保持不变；
- **安装用到新能力的扩展**：用到凭据占位符或出站处理的扩展需要本版本才能安装，旧版本在安装时会提示先升级。
