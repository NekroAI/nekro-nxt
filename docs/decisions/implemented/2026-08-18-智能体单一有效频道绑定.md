# 智能体单一有效频道绑定

状态：implemented

## 决策

一个智能体同一时间只允许存在一个有效 Channel Binding。用户为已有绑定的智能体选择其他频道时，系统执行原子换绑：旧 Binding 标记为非活动，新 Binding 创建或重新启用。一个 Channel 仍可按明确触发策略绑定多个智能体。

## 原因

智能体页面、消息导航和运行入口都需要一个明确的当前频道。允许同一智能体同时绑定多个频道会让“打开智能体”、短期上下文和当前响应目标变得含糊，也会增加误发到其他平台的风险。

## 数据与运行语义

- 旧 Binding 不删除，历史 Episode 继续引用原 Binding 与 Binding Revision；
- Core 查询和产品快照只投影活动 Binding；
- 升级已有数据库时，每个智能体按 `created_at, id` 保留最新 Binding 为活动状态，其余转为历史状态；
- 换绑提交在 SQLite 事务内完成，并由部分唯一索引保证每个智能体最多一个活动 Binding；
- 换绑不合并频道消息，不迁移短期上下文，也不删除旧频道。

## 未提前实现

本次不增加频道归档、历史 Binding 管理页或自动迁移消息。需要重新绑定旧频道时，复用原 Binding 身份并递增 Binding Revision。
