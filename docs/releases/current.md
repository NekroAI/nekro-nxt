# ✨ 本次更新

这次更新的重点是让智能体能在群里把扩展从做出来到发布一路做完：扩展有了版本和分支，修改已保存的扩展和新建一样自然，管理员在聊天里点一下就能确认；开到自主模式的智能体可以直接试运行自己做的扩展，不用再去后台点批准。智能体还可以开「子对话」把费时的事交出去，自己继续陪大家聊。界面也整体整理了一遍，手机上可以正常使用。

## 🚀 主要变化

- **子对话**：在智能体能力中打开「子对话」后，智能体可以把查资料、翻聊天记录这类费时的事交给一个子对话单独处理，自己留在群里继续聊，结果送回来后再发到群里。进行中的子对话显示在频道列表里所属频道的下方，点开可以看它做了什么；结束后保留的时长在「设置 → 子对话」中选择；
- **扩展的版本与分支**：扩展像代码一样记录每个版本从哪个版本改来，扩展详情里的谱系图能看到整条历史；可以从任何一个版本另起分支。智能体可以修改已经保存的扩展，改好的候选保存为该扩展的下一个版本；对话结束后任务会暂停，换个对话可以接着做；
- **扩展数据跟着版本走**：长期积累数据的扩展升级、回滚或分支时，数据会按扩展声明的格式迁移，迁移前自动留快照，失败时自动恢复；也可以在扩展的「数据」页手动把数据迁入另一个扩展；
- **在聊天里确认**：智能体的扩展自主权分为手动、管理员确认和自主三档。需要确认的操作会在频道里出现一条请求，管理员发送 `/ext approve 编号` 或 `/ext reject 编号` 即可，不必打开后台；
- **自主模式直接试运行**：扩展自主权为「自主」时，智能体做出的候选会直接试运行。带界面的候选由任意一个打开的 NekroNXT 页面在后台加载并检查；一个页面都没开时，可以在「设置 → 界面检查」里下载后台浏览器，由 NekroNXT 自己完成检查，服务端镜像已经自带。非自主模式下，管理员可以在聊天里用 `/ext run 任务名称` 允许运行；
- **管理员与聊天命令**：「设置 → 管理员」中列出谁是 NekroNXT 管理员，也可以在聊天里用 `/admin claim 认领码` 认领。聊天命令统一管理，「设置 → 聊天命令」以表格列出每条命令、说明、生效权限与开关；
- **命令使用 GitHub 账号**：在「设置 → 账号与服务」中添加 GitHub 账号，再在智能体能力中授权，智能体运行命令时就能以这个账号查看和处理 issue；没有 GitHub CLI 时可以在界面里直接下载；
- **社区反馈**：在「设置 → 社区反馈」中给社区提交问题与建议并跟进回复，也可以授权智能体代为提交；
- **日志**：新的「日志」页集中查看服务、连接与扩展的运行日志，按级别筛选，需要排查时可以临时打开调试日志；
- **频道附件**：在频道中可以给智能体发送图片和文件。

## 🛠️ 改进与修复

- **界面整理**：设置分为智能体运行、连接、权限、系统四组；概览只做汇总，需要处理的事项统一在右上角的提醒中完成；扩展详情改为概览、配置、版本、数据、诊断几个页签，版本以时间和改动内容呈现；频道和智能体的绑定在各处使用同一套选择方式；手机宽度下各页面可以正常操作；
- **表情包**：OneBot 消息里的表情包会被标出来，扩展可以读到消息中的图片，表情包扩展据此可以在后台收集群里常用的表情包；
- **处理超时提醒**：智能体处理时间过长时，频道里会提醒一次；
- **连接**：可以直接修改连接地址与凭据；OneBot 合并转发中的图片、视频和语音可以下载播放；QQ 引用消息的内容会保留；
- **启动更可靠**：某个频道的对话记录损坏时，只结束那一段对话，其余频道照常启动，不再整个服务停在恢复页；重启后已经验证通过的扩展候选不再重新调用一遍它的工具；
- **桌面版**：修复在部分环境下启动即退出、退出时卡住的问题，Windows 打包资源完整。

## ⚠️ 升级前留意

- **子智能体改为子对话**：智能体能力中的「子智能体」改称「子对话」。升级前正在进行的子智能体任务不会出现在新的子对话列表中；
- **谁是管理员**：群主和群管理员不再自动被当作 NekroNXT 管理员。升级后请在「设置 → 管理员」中添加需要管理扩展和命令的平台账号，或让他们在聊天里认领；
- **服务端镜像变大**：镜像自带了检查扩展界面用的无头浏览器，体积比上个版本大；
- **旧版本安装新扩展**：使用新能力的扩展（例如新版表情包）需要本版本才能安装，旧版本在安装时会提示先升级。
