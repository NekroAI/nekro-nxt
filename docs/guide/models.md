# 配置模型

NekroNXT 复用 DSH 的模型供应商、Settings 和凭据体系，不维护第二份模型目录。

## 添加供应商

1. 前往「设置 → 模型供应商」；
2. 从可配置目录选择供应商；
3. 填写 API Key、Base URL、协议和供应商要求的字段；
4. 运行连接测试；
5. 保存配置和凭据。

供应商列表和供应商页显示当前配置最近一次连接测试的结果；修改 API 地址、协议或 API Key 后需要重新测试。

API Key 是只写凭据。页面用“已配置”或“未配置”显示凭据状态，保存后不回显原值；清除凭据会使依赖它的模型不可用。

## 管理模型列表

在「设置 → 模型供应商」中选择已配置的供应商，就能编辑它的模型列表。每个模型可以填写模型 ID、显示名、上下文长度和最大输出，并通过“支持图片”开关声明它能否直接理解图片。

- 添加模型：点击“添加模型”填写模型 ID。供应商提供模型查询时，“获取可用模型”会列出尚未加入的模型，可以逐个或全部加入；不提供查询的供应商（如 DeepSeek 官方接入）不显示这个按钮，需要手动添加；
- 修改列表只在保存时生效，没有改动模型时保存不会影响供应商自带的列表；
- 改过列表的内置供应商会显示“已自定义”，可以用“恢复默认模型”改回供应商自带的列表。恢复后，使用被移除模型的智能体需要重新选择模型；
- 通用接入的供应商新增目录之外的模型时，需要在高级设置中填写 API 地址并选择 API 协议。选择协议后，该供应商的全部模型都使用这个协议；
- 少数供应商的模型由适配器固定提供，页面只显示列表，不提供编辑。

供应商停用或改名后，原来的模型可能从列表中消失。使用这类模型的智能体会在工作台和“需要处理”中提示，可以改用同一供应商的可用模型，或在模型设置中把它加回列表。

## 为智能体选择模型

创建或编辑智能体时，从实时模型目录选择默认模型。配置保存为不可变版本；运行中的工具使用启动时的配置，兼容的新配置在下一个安全边界生效。

模型明确声明支持图片时，频道原图可以进入主模型上下文。文本模型需要配置辅助视觉模型，再通过图片检查工具取得结构化证据。图片能力以模型列表中的“支持图片”声明为准，可以在模型设置中修改。

## 排障

- 目录为空：确认供应商配置已保存，运行 NekroNXT 的设备可以访问供应商；
- 测试失败：核对 API Key、Base URL、协议和模型权限；
- 智能体提示模型已不在列表中：改用同一供应商的可用模型，或在模型设置中把它加回列表；
- 图片不可用：核对模型能力声明或辅助视觉模型配置。
