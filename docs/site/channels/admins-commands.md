# 管理员与聊天命令

在群里可以用 `/` 开头的聊天命令查看状态、暂停回应、清空上下文、批准扩展请求。哪些人能用哪些命令，由管理员和命令权限决定。

## 谁是管理员

- 登录这个 NekroNXT 控制台的人，始终是管理员；
- 平台上的账号要在「设置 → 管理员」里添加，才算管理员；
- 群主、群管理员不会自动成为 NekroNXT 的管理员。

管理员可以在每个频道使用管理命令，在聊天里批准智能体的扩展请求。

![「设置 → 管理员」](shot:channels-admins)

## 把自己的平台账号设为管理员

两种方式：

- **从列表添加**：点「添加管理员」，按昵称搜索，点“设为管理员”。只有在接入的频道里说过话的账号才会出现；
- **用认领码**：点「生成认领码」，然后用你自己的账号在任意一个接入了 NekroNXT 的频道里发 `/admin claim 认领码`（群聊里先 @ 机器人）。认领码 10 分钟内有效，只能用一次，输错 5 次作废。

## 聊天命令

| 命令 | 作用 | 谁能用 |
| --- | --- | --- |
| `/help` | 查看能用的命令和用法 | 所有人 |
| `/status` | 查看这个频道由谁回复、触发方式、是否暂停 | 所有人 |
| `/stop` | 停下当前这一轮，保留上下文 | 频道管理 |
| `/reset` | 清空上下文从头开始，聊天记录、频道说明和笔记保留 | 频道管理 |
| `/compact` | 压缩上下文，会中断当前工作 | 频道管理 |
| `/threshold` | 临时调整这段对话的压缩阈值，如 `/threshold 40%` | 频道管理 |
| `/pause`、`/resume` | 暂停、恢复这个频道的自动回应（别名 `/off`、`/on`） | 频道管理 |
| `/ext` | 查看扩展和待确认的请求；批准、启用等操作需要管理员 | 所有人可查看 |
| `/admin` | `claim` 认领管理员，`list` 列出管理员 | 认领所有人可用 |

扩展也可以带自己的命令，在命令列表里会标出来源。

在内置频道和私聊里直接发 `/命令`；在群里默认要先 @ 机器人，比如 `@小奈 /status`，避免和群里别的机器人冲突。不认识的 `/xxx` 会当作普通聊天交给智能体。想发一句以 `/` 开头的普通话，写成 `//`。

## 命令权限

权限从低到高是：普通用户、频道管理、NekroNXT 管理员。管理员在每个频道都有频道管理权限；其他人要在某个频道单独授权。

在「设置 → 聊天命令」可以调整每个命令的生效权限、停用某个命令，以及没有权限的人用命令时要不要回复提示。

![「设置 → 聊天命令」](shot:channels-commands)

## 在某个群单独设置

打开频道，右侧往下有：

- 「聊天命令」：这个群和全局设置不同的命令。权限只能比全局更严，不能放宽；
- 「命令授权成员」：点“添加成员”，把群里的某个人设为可以用管理命令，只在这个群有效；
- 群聊里还有“允许不带 @ 的命令”，打开后群里直接发 `/命令` 也会执行。

![频道里的「命令授权成员」](shot:channels-command-members)

## 命令没反应

- 群里没有先 @ 机器人，又没打开“允许不带 @ 的命令”；
- 没有权限：默认会回复一句需要管理员授权，也可能在「设置 → 聊天命令」里关了提示；
- 发得太快：平台来的命令每人每分钟最多 10 条，超出的会被忽略。
