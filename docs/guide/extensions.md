# 使用扩展

工具、适配器、Preset、MCP 接入和产品 UI Slot 都属于同一 Extension 体系。当前公开产品优先支持本地动态创造闭环，尚未开放社区市场。

## 动态创造流程

1. 为目标智能体开启动态创造权限；
2. 描述需要的新工具或界面；
3. 在创造工作台生成并运行动态包；
4. 查看真实构建、调用、渲染和停止证据；
5. 修改并重新验证；
6. 保存为本地扩展；
7. 在扩展详情或智能体工作台为指定智能体启用。

动态运行、保存扩展版本和为智能体启用是三个独立提交点。试跑成功不等于已经保存，保存也不等于已经启用。

## 安全边界

动态创造本身不授予开发 Shell、文件读写或完整文件访问。扩展只获得当前智能体配置版本允许的能力；卸载和停用必须撤销工具、RPC、监听器和界面贡献。

## DSH 兼容

NekroNXT 优先通过 DSH 公开 Plugin、Service、Tool、Provider、Settings、Scope、Bundle 和 Preset 接缝运行能力插件。产品元数据和中文界面只增强体验，不应成为加载 DSH 能力的前提。
