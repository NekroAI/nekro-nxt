# 在手机上使用

手机上可以用两种方式管理自己的 NekroNXT 实例：

- **Android 应用**：安装 APK，扫码连接，关掉应用后也能收到通知；
- **主屏幕应用（PWA）**：iPhone、iPad 和其他设备在浏览器里打开实例，添加到主屏幕。

两种方式显示的都是实例自己的界面，实例升级后手机上的界面随之更新。手机在外面使用时，实例要能从公网访问，做法见[服务端部署](server.md#通过反向代理使用-https)。Desktop 本机实例目前只在这台电脑上可用，手机连不上。

## Android 应用

### 下载

- **正式版**：在 [NekroNXT 社区的下载页](https://nxt.nekro.ai/download)或 GitHub 上 `android-v` 开头的发布下载，应用名为「NekroNXT」；
- **开发版**：[预览版](https://github.com/NekroAI/nekro-nxt/releases/tag/preview)附带的 APK，跟随 `main` 更新，应用名为「NekroNXT 开发版」，可以和正式版同时安装。

需要 Android 10 及以上。下载页和发布说明列出安装包和签名证书的 SHA-256。安装时如果系统提示「未知来源」，按提示允许这一次即可。

### 连接实例

1. 在已登录的电脑或浏览器上打开「设置 → 登录与访问」，在「其他设备登录」里点「连接安卓应用」旁的「显示配对码」；
2. 打开应用，点「扫码连接」，扫描屏幕上的二维码；
3. 确认显示的地址正确后点「连接」。

二维码里有实例地址、实例的证书指纹和一次性配对码，5 分钟内有效，只能用一次。扫码时应用会核对实例出示的证书与二维码里的一致，所以自签名证书的实例也不用另外确认指纹。

不能扫码时点「输入地址」，填实例地址，再填配对码或管理密钥。管理密钥只用这一次，不会保存在手机上。用 `http://` 地址连接时应用会先说明风险，只建议在可信的局域网或加密隧道里这样连接。

连接后这台手机会出现在实例的「已登录设备」里，在那里撤销后应用会回到连接页。要切换或添加实例，在左侧菜单点「切换实例」，或长按应用图标选「切换实例」。

### 后台通知

第一次连接后，应用会询问是否开启后台通知。开启后，关掉应用也会和实例保持连接，有扩展等你允许运行、智能体申请凭据这类需要处理的事时弹出通知，点击打开对应页面。

- 为了保持连接，通知栏会常驻一条「保持连接」。可以在系统的通知设置里把这一类折叠起来，不影响其他提醒；
- 每类提醒在系统设置里是单独的通知类别，可以分别关闭；
- 系统的电池优化可能在后台停掉应用。开启时应用会请系统允许它在后台运行；部分手机还要在系统设置里允许自启动；
- 实例的「设置 → 通知」里「系统通知」要开着，手机才收得到；这台手机的后台通知在同一页的「这台手机」里开关。

### 更新

应用启动时检查新版本，有更新时询问是否下载。下载走 NekroAI 下载镜像（`dl.nekro.ai`），失败时改用 GitHub，核对大小和 SHA-256 后交给系统安装。第一次更新时系统会询问是否允许 NekroNXT 安装应用。正式版只更新到正式版，开发版只更新到开发版。

## 主屏幕应用（PWA）

1. 在浏览器里打开实例地址并登录；
2. iPhone 和 iPad：在 Safari 点「分享」，选「添加到主屏幕」；安卓的 Chrome：在菜单里点「安装应用」或「添加到主屏幕」；
3. 之后从主屏幕图标打开，界面全屏显示，和应用一样使用。

添加到主屏幕和浏览器推送都需要受信任的 HTTPS 地址，局域网 HTTP 或自签名证书不行。iPhone 上的主屏幕应用与 Safari 不共享登录，第一次打开要再登录一次，可以用已登录设备扫码。浏览器推送在「设置 → 通知 → 接收推送的设备」里开启；国内的安卓手机通常收不到浏览器推送，建议用 Android 应用。
