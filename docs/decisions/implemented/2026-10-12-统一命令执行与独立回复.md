# 统一命令执行与独立回复

状态：implemented（2026-10-12）

选择在已有 Channel Runtime 事实提交与模型准入之间放置命令门禁，由 Host 组合统一执行服务。命令需要在无模型、仅观察和无绑定情况下仍能提供帮助，所以它不属于 DSH Session 的工具调用。

复用现有 Outbox，而为命令提供独立来源，是为了保留 Adapter 的投递规划与结果未知语义，同时避免清空上下文后为回执重建会话。命令回复以 (执行, 序号) 唯一，一次执行可发出若干过程回复再以终态结束，恢复时不重发已规划的回复。Drizzle 迁移在旧表复制时为新来源列填 NULL，并保存截止点；升级不会追溯执行旧聊天。

暂停是频道绑定上的独立状态，而不是改写响应规则再恢复：规则与暂停各有唯一来源，Web 控件与命令操作同一份，避免「恢复时用哪份规则」的歧义。外部群聊默认要求命令指向本账号，因为同群可能有多个机器人；Web 管理员在外部频道执行的结果默认只在控制台显示，避免一次查看产生对外消息。平台来源的命令按频道与用户限速，因为命令不消耗模型成本，否则任何群成员都能让账号刷屏。

命令注册归扩展本机实例所有，执行和取消按智能体挂载隔离，取消和清理先于 Session 静止等待。显式平台身份授权限定到连接和频道，不从平台角色推断，Web 身份由宿主鉴权边界确定。

现行语法、权限、持久化、SDK 与界面契约见[命令系统](../../10-命令系统.md)。实现与验证入口为 Contracts 命令测试、Server 命令服务和扩展生命周期测试、SQLite 升级测试及 Web 生产命令旅程。
