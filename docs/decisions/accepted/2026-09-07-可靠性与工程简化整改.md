# 决策：可靠性与工程简化整改

状态：accepted

## 决定与边界

保留聊天、连接、智能体配置与客户端偏好；保留 Drizzle 与 Zustand。迁移完整性检查必须发生在事务提交前，历史分页在数据库完成。客户端统一类型化请求和宿主数据缓存，宿主按状态与生命周期所有者拆分。新扩展统一显式 scope，旧源码保留并提供重建入口。视觉建议不代替运行成功条件。工程检查与 CI 去除重复事实和重复执行，相关 main 提交继续自动 Preview，正式发布仍须明确授权。

## 实施状态

- 阶段 0：相关存储与 HTTP 基线 69 项通过；迁移回归证明旧实现失败。已允许迁移所有者执行 SQL。
- 阶段 1：已实现迁移事务与数据库历史查询；新增 0023 索引迁移，存储测试与类型检查通过。1 万与 10 万历史场景验证限量解码，搜索保留单次扫描限制。
- 阶段 2：实施中。已统一类型化产品动作与传输、移除生产全局 activeHost 和 Coordinator 镜像、分离主题偏好，增加快照与频道读取游标、请求串行合并和生命周期保护，分离提交与同步结果。组件级运行实例注入、动态审批与扩展协调器隔离、枚举状态投影和契约失效声明已实现；253 项相关测试与生产构建通过；生产旅程中的保存身份字段混用已修复并通过保存闭环复验，频道上下文、扩展启停、Host UI 页面与连接数据保留旅程通过。平台用户目录已归入数据层并通过乱序与生产旅程验证；模型供应商与 DSH 目录读取已归入宿主数据 Store，合并在途读取并保护保存后的状态，57 项相关测试与 3 项生产设置旅程通过，浅深主题画面已审查，完整集成与覆盖率验收留到后续整改。
- 阶段 3：实施中。Session 身份与资源已归入单一注册表；运行状态投影拥有订阅及合并通知计时器；模型、设置与凭据操作移入独立服务，保留宿主公开适配方法。129 项 Server 测试通过，新增模块纳入原覆盖率范围。持久扩展挂载已拥有独立状态与初始化、关闭并发控制，17 项相关测试通过。创造任务批准与停止已进入共享应用服务，停止等待后的并发版本变化有回归测试；55 项扩展运行测试和17项相关宿主测试通过。频道活动反馈已独立持有租约和重试生命周期，45 项频道测试通过，关闭后不再产生迟到重试。频道交互意图已归入独立服务，46 项频道测试通过，并发重复请求返回一致结果。频道投递计划、回执提交和恢复已移入独立服务，原频道测试保持通过。图片上下文、附件存储与压缩后恢复已独立，32 项相关宿主测试通过。动态创造验证与保存、Session 驱动、快照批量查询及 HTTP 领域路由拆分尚未完成。
- 阶段 4–6：尚未实施，不能以本决定推断现有实现已完成。
