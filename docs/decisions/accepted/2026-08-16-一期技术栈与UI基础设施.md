# 一期技术栈与 UI 基础设施

状态：accepted

Web 与 Server 使用这一套栈。Desktop 在 M7 复用同一 Web 产物，不另起技术栈。

## 工程

- Node `^22.19.0 || >=24.0.0`，pnpm `11.7.0`，TypeScript 与 DSH 包对齐，全仓 ESM；
- pnpm workspace；库用 tsdown，Web 用 Vite 6；
- DSH 以 lockfile 冻结的精确 npm 包接入，当前 `0.1.1-rc.2`。

## Web

- React `18.3.1` singleton，React Router 7，Radix + CSS Modules + `--nxt-*` Token，空间动效用 `motion/react`；
- 业务页面不直接导入 Radix 或 `motion`；ui-kit 由 `apps/web/src/ui-kit/` 拥有；
- Zustand 只保存主题、布局和未提交草稿；业务事实只在 Server；
- 视觉规范见 `docs/05-桌面UI与动效规范.md`。

## Host 与数据

- HTTP/SSE/静态托管复用 DSH WebServer，领域 API 由 NekroNxt 定义，见 `docs/08-接线与Server宿主设计.md`；
- Core：`better-sqlite3` + Drizzle typed Repository，禁止业务手写 SQL；
- DSH Session SQLite 由 DSH 拥有，Core 不读其私有表；
- 频道检索：分页 + `search_text` 字面子串匹配。

## Desktop 与测试

- Desktop 使用 Electron + electron-builder，启动同一 Product Release 内的 Server 生产入口并加载该 Host 托管的 Web dist；UI、Host、DSH 与 migration 不独立发布，IPC 只承载窗口、选文件、Keychain 和完整包更新所需系统能力；
- 测试：Vitest、Testing Library、Playwright 生产旅程；用户可见 UI 的像素级验收见 `docs/06-开发与测试规范.md` §5.1；根命令为 `pnpm dev/check/test/build`。

不引入 Tailwind/shadcn、第二 HTTP 框架、外部数据库、SSR 或 Tauri。
