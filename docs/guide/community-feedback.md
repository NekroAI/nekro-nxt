# 社区反馈

在「社区 → 反馈」提交 NekroNXT 或扩展的问题、建议和提问，查看维护者的回复与修复进展。需要登录支持反馈的社区；没有智能体也可以手动新建。

## 提交反馈

1. 打开「社区 → 反馈」，选择「新建反馈」，填写对象、标题和正文。
2. 保存草稿，选择「预览并发送」。版本、运行环境与扩展诊断由 NekroNXT 附上，展开可以查看将发送的完整内容。
3. 检查文字和诊断；智能体附上了对话摘录时，可以取消。确认后发送，成功后会获得 `FB-…` 编号。

发送失败会保留草稿，可以修改后重试。同一份草稿重试不会重复创建反馈。「设置 → 社区反馈」可以查看最近一次发送的完整内容。切换社区地址或账号后，原身份的草稿与反馈不会显示；切回后恢复。

也可以在社区网站的「我的反馈」里填写表单。针对某个扩展的问题，从它的详情页选择「反馈问题」；「已知问题」只展示维护者公开的标题、状态和修复版本，遇到相同问题可以标记「我也遇到」。

## 让智能体起草

在「设置 → 社区反馈」登录社区并开启「启用社区反馈工具」。开关默认关闭，第一次开启会说明发送范围并请你同意。

之后可以对智能体说：“把这个问题反馈到社区。”它会先查找已有反馈，再起草内容；你在客户端查看草稿并确认发送。智能体只可以指定当前频道里的消息作为摘录，不能自行编造摘录或诊断。它能查询公开问题和本频道产生的反馈，不能读取其他频道的私有反馈。

需要直接发送时，在该智能体的「能力」里开启「免确认提交反馈」，阅读说明并保存。它只对你从客户端发出的消息触发的轮次生效：群成员触发的轮次仍会留下待确认草稿。直接发送不附对话摘录，每个实例每天最多 5 条，达到上限后回到草稿确认。

## 查看处理进展

「反馈」页按待确认、进行中和已解决分组。打开页面、发送后及每日检查更新时会同步处理进展；维护者回复、状态与修复版本更新会进入通知和概览的「需要关注」。在「设置 → 通知」可以关闭反馈提醒。

需要补充信息时，在详情里追加说明。维护者标记修复后会显示修复版本；当前版本达到要求时，页面提示可以确认是否已解决。「已解决」记录你的确认，不改变维护者设置的全局状态。如果仍能复现，在标记修复或不处理后的 30 天内选择「重新打开」并填写原因。

「我也遇到」订阅状态与修复版本变化，不会开放其他提交者的私有正文、摘录或回复。针对扩展的反馈由该扩展作者和社区管理员处理；作者可在社区网站的「收到的反馈」里按扩展查看。

## 隐私与撤回

反馈默认私有。提交者和管理员能看到正文及诊断；相关扩展作者只能看到与该扩展有关的诊断，对话摘录需要提交者另行允许。管理员可以公开展示标题、状态与修复版本。

NekroNXT 会替换已知成员、频道与账号信息、本机路径和疑似密钥；附件只记作“附件一份”。自动处理不能识别所有隐私内容，发送前仍要检查预览。社区会再次检查密钥和本机绝对路径，命中时拒绝提交并说明类别。

处理结束前可以撤回，并选择同时删除标题、正文和自己追加的说明。撤回会立即清除诊断与摘录，维护者的回复和编号保留，撤回后不能恢复。已修复、不处理和重复反馈的诊断与摘录在结束处理满 180 天后清除；其他文本长期保留。取消「我也遇到」会清除该标记附带的诊断。

反馈附带的随机实例 ID 只给管理员查看，用于关联同一实例的问题，与管理端设备身份无关。社区反馈不等于匿名使用统计；本功能不会定期发送聊天内容。
