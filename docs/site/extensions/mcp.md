# 接入 MCP 服务

MCP（Model Context Protocol）是很多 AI 工具通用的工具接口。已经有 MCP 服务时，不用写代码，填个地址就能让智能体用上它的工具。接进来的 MCP 服务在 NekroNXT 里是一个扩展，和其他扩展一样管理。

## 添加

在「工坊」顶部点“添加 MCP 服务”：

![添加 MCP 服务](shot:extensions-mcp)

- **名称**：显示用，比如“团队知识库”；
- **连接方式**：
  - 「远程服务」：填服务的地址，以 `http://` 或 `https://` 开头。需要认证时在“请求头”里添加，比如 `Authorization`；
  - 「本机程序」：在运行 NekroNXT 的这台机器上启动一个程序，填命令、参数（每行一个）和环境变量。程序的工作目录是智能体的工作区。只有管理员能添加本机程序；
- **工具前缀**：工具在智能体那里叫 `mcp__前缀__工具名`，留空会从地址或命令推断；
- **启用到**：直接为某个智能体启用，也可以“暂不启用”。

请求头和环境变量的值可以直接填写，也可以选「设置 → 凭据」里的凭据。打开“作为凭据保存”的值会存成凭据，不写进扩展。

## 测试和启用

点「测试连接」，能连上时会列出这个服务提供的工具。确认后点「添加」。

添加后在扩展详情能看到连接状态，比如“已连接 · 5 个工具”或者缺少哪个凭据。要给更多智能体用，在扩展详情的“智能体”里打开，或在智能体资料页的“扩展”里打开。

反过来，NekroNXT 社区站也提供一个公开的 MCP 服务，可以在 Claude、Cursor 这类工具里查 NekroNXT 的使用文档和社区扩展，见[在 AI 工具里查文档](../develop/docs-mcp.md)。
