# ✨ 本次更新

智能体的扩展、定时任务和文件管理工具改成按需加载，用到时再取出来。智能体可以浏览社区扩展，每个智能体可以单独设置上下文压缩阈值。Windows 桌面版的命令改用 PowerShell。这一版还修复了频道会一直不回复、图片多时回复变慢等问题。

## 🚀 主要变化

- **能力包**：扩展管理、扩展开发、社区、定时任务和文件管理的工具改成按需加载，智能体需要时自己取用。在频道右侧栏「当前会话」点「查看」，可以看到系统提示词由哪几部分组成、各占多少；
- **扩展自主权单独设置**：智能体设置里的「扩展自主权」不再跟「动态创造」绑在一起，没开动态创造的智能体也能管理已安装的扩展；
- **社区扩展**：智能体可以在社区里查找扩展、查看详情。从社区安装扩展一律要管理员确认，申请里写明版本、权限和理由。智能体发布的扩展审查结束后，结论和修改意见交给这个智能体，频道里只通知结果；
- **压缩阈值**：在智能体设置里拖动「压缩阈值」滑块，可以调整上下文压缩时机，同时能看到当前用量。聊天里发 `/threshold` 可以只改本次对话；
- **重启服务**：在「设置」里可以重启服务，智能体也可以请管理员批准后重启；
- **彻底清除频道记录**：频道信息里新增「彻底清除」，删除这个频道的聊天记录，保留频道本身和智能体的绑定；
- **修改扩展信息**：已保存的扩展可以修改名称和说明；
- **思考档位**：模型表新增思考档位列，每一档都可以填写上游接受的参数值；
- **Markdown**：智能体能知道每个频道能不能显示 Markdown。讲资料、解答问题时整理成一条消息发出，不再拆成好几条；
- **工作区文件工具**：「工作区读写」档的智能体可以移动、复制、删除、压缩和解压工作区里的文件。删除的文件先放进回收站，7 天后清除；
- **Docker 镜像**：镜像里补齐了常用命令，智能体可以把需要的工具装到 `/data/tools`；
- **其他新增**：DSH 插件配置可以切到原始 JSON 整份编辑；智能体可以查到正在运行的 NekroNXT 版本；子对话列表显示多久没有动静；时间线显示模型请求发出前的准备时间；桌面版更改数据目录时分别列出要搬走和会留下的大小，可以删除旧的恢复点。

## 🛠️ 改进与修复

- **频道一直不回复**：同一条消息被交给智能体两次后，频道可能停止回复，要用 `/reset` 才能恢复。这个问题已修复；
- **中转站临时故障**：部分中转站在上游暂时没有可用资源时返回请求错误。现在这类错误会自动重试，重试仍不成功时改用备用模型；
- **图片多的对话**：使用 DeepSeek 时，频道里有 GIF 会让每一步都重新上传全部图片，回复明显变慢。这个问题已修复；包含多张图片的合并转发不会再整条存不进来；
- **语义检索**：新安装的 NekroNXT 内置语义检索可能一直没生效。这个问题已修复；
- **扩展**：扩展里没处理的错误不再导致服务停止；扩展网络请求默认等待 100 秒，单次最长可以放宽到 10 分钟；权限说明能认出文件、音视频、命令和语音转文字，不再显示「未知能力」；智能体升级扩展、保存带密钥的扩展、等批准后继续操作时不再卡住；切换扩展版本时不再卡在批准对话框；
- **语音**：QQ 语音按音频接收，可以转成文字；智能体可以转写频道里以前的语音；
- **子对话**：子对话出错、上下文超限或被中断时会自动结束；单次输出不再限制在 4096 token，跟随主对话的模型设置；
- **Windows 桌面版**：媒体处理能正常运行；安装时手动选择目录、安装完成后点「完成」不再卡住；
- **界面**：手动压缩上下文时界面不再卡住，频道右侧栏把不常用的设置收进「回复细节」；窄窗口下社区、智能体、频道的列表改成抽屉打开；服务繁忙时保存不再一直转圈；「完整访问」档也能给智能体选择关联账号；
- **其他修复**：智能体能读回本会话里超长工具输出的完整内容；「运行命令」档的智能体在代码仓库里能使用 git 和 gh；Android 上的 Docker 容器不用 root 也能监听端口；官方 DeepSeek 供应商可以测试还没保存的密钥。

## ⚠️ 升级前留意

- **Windows 桌面版的命令**：命令改用 PowerShell。在「运行命令」档，命令拿不到它启动的其他程序的输出，因此做不了 git 克隆、pip 或 npm 安装依赖，需要时把智能体调到「完整访问」。要用 git 和 bash 时，在「设置 → 附加功能」安装「Git 与 Bash」。
