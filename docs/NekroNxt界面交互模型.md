# NekroNXT 界面交互模型

> 用途：约束产品概念图、交互原型和后续 UI 实现  
> 状态：产品形态设计基线  
> 原则：先定义页面对象、状态和操作后果，再设计控件
>
> 视觉 Token、桌面布局尺寸、组件状态和动效遵循 `05-桌面UI与动效规范.md`。用户可见改动的像素级验收遵循 `06-开发与测试规范.md` §5.1。

> 文案铁律：界面中的实体统一称“智能体”。Agent、AI 成员、Bot、助手不得作为同一实体的替代类型名；英文内部类型不得直接显示给用户。

## 1. 全局对象规则

### 1.1 每个页面只有一个主要对象

| 页面 | 主要对象 | 次要上下文 |
|---|---|---|
| 工作模式默认画布 | 上次使用的 Channel | 对象列中的智能体树 |
| 零智能体空态 | 创建入口 | 无 |
|智能体创建页面 |智能体Draft | 默认内置频道 |
| Channel 对话 | Channel Binding | 响应它的智能体|
|智能体工作台 | `AgentDefinitionDraft` | 当前 Revision、绑定频道和活动 Session |
| 频道绑定向导 | Binding Draft | Connection、Channel、智能体|
| 创造工作台 | 当前智能体的动态 Package | 审批与保存 |
| 本地扩展 | Local Extension | 当前版本和启用关系 |

同一时刻画布只有一个主要对象；检查器只服务它。页面标题、主操作和检查器都必须服务这个对象。完整编辑进入该对象的画布，而不是另一个一级模式。

### 1.2智能体与 Channel 的关系

-智能体是长期产品实体；
- Channel 是一段消息事实流；
- Channel Binding 决定哪个智能体响应该 Channel；
- 一个智能体可以同时保留多个有效 Channel Binding，并分别参与多个独立频道；
- 一个 Channel 同一时间只能绑定一个智能体；换绑改变后续响应所有权，不删除该频道已有消息；
- 一个 Channel Conversation 只显示该 Channel 的消息；
- 跨 Channel 长期记忆可以共享，但短期聊天记录不直接混合；
- 切换左侧 Channel 就是切换中央 Conversation，而不是筛选同一混合流。

### 1.3 Extension 的三个独立动作

```text
动态运行
→ 保存为本地 Extension Revision
→ 激活给一个或多个智能体
```

- 动态运行：临时、可停止、可能重启丢失；
- 保存：源码和 Revision 持久化，但不自动扩大作用范围；
- 激活：指定哪个智能体使用哪个 Revision。

## 2. 状态词典

### 2.1 Host 状态

- 正在连接；
- 运行正常；
- 连接不稳定；
- 无法连接。

### 2.2 Connection 状态

- 已连接；
- 正在连接；
- 认证过期；
- 已断开；
- 异常。

### 2.3智能体运行状态

- 空闲：没有活动 Turn；
- 思考中：模型正在生成；
- 使用工具：Tool 正在运行；
- 等待输入：等待用户问题或审批；
- 已暂停：用户暂停新 Turn；
- 不可用：模型、配置或 Runtime 有错误。

智能体不使用含糊的“在线”表示一切正常。

### 2.4 Channel Binding 状态

- 监听中；
- 已暂停响应；
- Connection 断开；
- 配置错误。

### 2.5 扩展启用状态

- 未启用；
- 已启用；
- 启用失败。

## 3. 应用外壳

### 3.1 全局模式

```text
工作（默认）
连接
用户
扩展
设置
```

图标轨只切换模式。工作模式的对象列是智能体树；连接、用户、扩展、设置各自用对象列列出该类对象。用户模式使用 `/users`，展示全部持久化平台身份并按 Adapter 分类；创造工作台和运行详情由明确动作进入，不占据图标轨。默认打开上次使用的频道；没有频道则打开第一个智能体；一个智能体都没有时进入创建空态。

Desktop 在图标轨底部的主题按钮下提供“服务实例”。它打开本地可信浮层，不属于一级模式。浮层用于切换本地实例和已添加的远程实例，以及添加、重认证、编辑、通知开关和移除远程实例。实例切换替换完整产品页面；当前页面存在已注册的未保存更改时，先确认是否放弃。普通浏览器访问 Server 时不显示该入口。

工作模式使用 `/work` 路由族：`/work/channels/:channelId`、`/work/agents/:agentId`、`/work/agents/new` 和 `/work/creator`。旧 `/channels/*`、`/agents/*`、`/creator` 只做 replace 兼容重定向，不再作为产品链接目标。

### 3.2 工作模式对象列

```text
小奈
├─ 内置频道
├─ 设计群
└─ 项目频道
```

- 点击智能体名称：画布换成该智能体工作台，对象列保持；
- 点击 Channel：画布换成该 Channel Conversation；
- 智能体和频道可在同组内拖动排序，松手后立即按新顺序展示，并由 Host 保存；
- 未绑定频道拖进智能体：确认后绑定（日常绑定入口，确认框可选响应方式）；
- 已绑定频道拖到另一智能体：确认后换绑；
- 已绑定频道拖到「未绑定频道」或树外侧：确认后先停止该频道正在工作的智能体（若有），再解绑；
- 跨组拖放只提案：投放处显示虚线，松手后树保持原绑定位置再确认；执行权在 Host，SSE 只播报步骤；
- 拖动智能体时整组（名称和它的频道）一起走，其他组不跟着抖动；拖动频道时只有同组频道让位，不把别的智能体条目挤来挤去；
- 智能体标题行和频道整行都可直接 Pointer 拖动，不显示 `...` 菜单或右键操作列表。行尾移动图标只提示可拖动并提供键盘入口，视觉上不呈现为按钮；图标覆盖在行尾，常态不占标题空间，只在 Hover、键盘聚焦或拖动时出现；绑定、换绑与解绑由拖放确认、频道检查器或智能体管理页提供；
- 绑定关系改变后，焦点跟随频道到新位置；顺序保存失败时恢复 Host 权威顺序，不保留仅存在于浏览器中的临时排序；
- `+`：打开创建智能体页面；「未绑定频道」旁的加号新建未绑定内置频道，再拖到智能体上交给它响应；
- 绑定向导仍可用于改触发策略和没有拖拽时的备用；
- Connection 状态不在这里用一个绿点替代，异常时显示明确图标与文案。
- 对象列是外壳的一部分，不在频道页里再画第二棵树。
- 对象列和右侧检查器都可通过分隔条调整宽度；检查器默认宽度为 344px。拖动结束后只在当前浏览器保存。双击分隔条、键盘 Enter / Space 或设置页“恢复默认分栏”恢复默认宽度。对象列始终保留，不提供会清空主要导航的收起入口；频道与智能体工作台共用检查器宽度和默认显示偏好。检查器展开时，收起按钮属于检查器自身标题栏；折叠后分隔条与空列一起归零，只在主画布右边缘显示独立的展开按钮。

### 3.3 右侧检查器

频道会话页头切换「会话 / 工作轨迹」。右侧检查器列保持：会话视图显示绑定和活状态，工作轨迹视图按选中记录类型叠放详情。切换视图不得卸掉检查器列。时间轴只出现在工作轨迹，会话页不放。

会话检查器的「运行」在有样本时用两个紧凑环形图展示上下文：已用/剩余，以及系统/工具/对话/其他组成；Hover 扇区轻微浮起，跟随指针且只淡入的 Tooltip 显示精确 token 与比例，键盘 Focus 提供同等信息。缓存不混入上下文组成，独立展示本次会话的最近一次输入缓存覆盖、最近 8 次加权覆盖、会话加权覆盖、逐请求平均、请求命中、累计输入桶、数据覆盖率和最近请求趋势；每项都标明统计范围，未报告缓存统计不显示成 0%。没有窗口、用量或模型请求样本时省略对应区块，不画空表盘。工作轨迹台账状态列写耗时；选中一行后检查器叠放本步用量和首字耗时（有才显示），仍不使用页签。占用是参考值，不是计费或压缩门禁。

检查器的「绑定」把智能体名称、更换智能体和管理智能体聚合在同一区块，频道来源和响应方式作为绑定的子内容；未绑定时只给出状态和绑定入口。频道显示名称属于次要编辑。人设、模型和能力仍进入智能体管理页。工作轨迹检查器不使用摘要 / 输入 / 输出页签：内部输出看全文，发送看发出的内容，工具同时看输入和输出。

## 4. 工作模式入口

### 4.1 默认画布

工作模式打开上次使用的频道。没有上次记录时打开第一个频道；没有频道时打开第一个智能体工作台。一个智能体都没有时，画布是创建空态。

对象列列出智能体及其绑定频道、尚未绑定的频道。点击智能体名称进入该智能体工作台；点击频道进入该频道会话。对象列的 `+` 打开创建智能体页面。

智能体卡片墙不是默认首页，不为“浏览全部智能体”单独保留一级目的地。

### 4.2 创建入口

| 按钮 | 显示条件 | 结果 |
|---|---|---|
| 创建智能体 / 创建第一个智能体 | 用户可管理当前实例 | 打开智能体 Draft 页面 |
| 打开最近频道 | 智能体已绑定频道 | 打开该智能体最近使用的频道 |

## 5. 创建智能体页面

创建入口打开 `/work/agents/new` 完整页面。创建与编辑智能体复用名称、人设、模型、能力、字段校验和双列布局；创建模式明确标记“新智能体草稿”，编辑模式展示真实运行状态和未保存变化。创建不使用 Dialog 或分步 Tabs。

### 5.1 默认行为

- 自动创建内置频道；
- 默认使用“通用方式”；
- 默认启用子智能体；网页搜索只在 DSH Web Provider 与凭据就绪时默认启用；系统访问默认停在“基础权限”，动态创造默认关闭；
- 可以先跳过外部平台；
- 没有可用模型时，在模型分区就地保存供应商，不中断创建去设置页；
- 最终确认前不写入正式 `AgentDefinition`。

### 5.2 按钮逻辑

| 按钮 | 结果 |
|---|---|
| 创建智能体| 原子创建 `AgentDefinition`、首个 Revision 和内置频道 |
| 取消创建 | 丢弃 Draft，返回 `/work`，不留下半创建智能体|

## 6. Channel Conversation

### 6.1 页面标题

标题使用 Channel 名称，例如“设计群”。副标题显示：

```text
由“小奈”响应 · 被提及或回复时触发
```

智能体不是该页面标题，因为中央事实流属于 Channel。

### 6.2 消息流

- 只显示当前 Channel 的平台消息；
- 智能体消息只能来自已成功记录的通信工具调用，并标记发送中、已发送、部分发送、失败或结果未知；
- DSH 模型原始文字和 reasoning 不投递给 Adapter，但 Web UI 会话流以「内部输出」展示；
- 文字、Mention、图片和文件均是同一逻辑消息的有序内容部分；
- 工具卡片穿插在会话流中，归属于触发它的智能体 Turn；通信工具成功发送的内容仍是聊天气泡；
- 系统事件使用低噪声状态行，不伪装成聊天消息；
- 其他 Channel 的消息只产生全局未读提示，不进入当前流。

内置频道以客户端用户为观察者：智能体消息在左，用户输入在右。外部频道以智能体/管理员观察频道为视角：平台成员在左，智能体和管理员通过机器人账号发出的消息在右。消息车道占满中央可用宽度；两侧使用相同气泡几何和表面，所有文本 part 经过同一个安全 Markdown 渲染内核，连续的 text 与 Mention 按原文位置内联，媒体与引用保持原始有序结构。

### 6.3 新群消息与当前 Tool

Tool 运行时到达的新消息先入库，并在安全间隙注入下一步思考。会话页用说明文字表达这一点；展开待注入列表尚未作为主操作开放。

### 6.4 Composer

Composer 只在会话视图浮动于消息画布底部，不形成独立说明区；切换工作轨迹后不渲染。内置频道常态从左到右显示信息图标、短标签“发给智能体”、输入和靠右的无文字发送图标；信息 Tooltip 说明该内容作为当前内置频道入站交给绑定智能体。

管理员输入作为该频道的入站消息交给绑定智能体，不是智能体的模型输出。

外部平台频道常态从左到右显示信息图标、短标签“发到频道”、输入和靠右的无文字发送图标；信息 Tooltip 说明连接展示名、平台可见后果和“管理员从客户端发出”来源。Composer 只画一个整体外框，不在里面再套有边框的输入框。连接未允许主动发送或尚未绑定智能体时，短标签替换为一句可见阻塞原因并禁用发送。

内容经 Adapter 以机器人账号投递到该频道；会话注入系统事实，不记为 `send_channel_message`。消息列表用「管理员从客户端发出」标记。连接未允许主动发送、或尚未绑定智能体时，说明前置条件并禁用发送。可另外提供「去内置频道和智能体对话」。

不放含义模糊的“能力”按钮。智能体能力在智能体管理页配置。尚未绑定智能体时，“绑定智能体”只出现在右侧检查器的绑定模块，打开共享绑定向导；频道页顶栏不重复该动作。

### 6.5 运行控制

会话页说明新消息会在安全间隙注入。存在活动上下文时，页头的紧凑“上下文操作”菜单提供两种可在运行中执行的控制：

- “压缩上下文”立即中止当前生成或 Tool，把当前 Episode 的 durable history 整理成交接摘要，并以摘要开始新上下文；
- “清空上下文”立即中止当前生成或 Tool，不生成交接，并开始空白上下文；频道历史可由智能体通过历史查询工具主动查找。

两个确认框都写明已完成外部操作的既有结果。展开待注入消息、编辑绑定和暂停响应不与上下文操作混为一组。

## 7.智能体管理与 Revision

智能体工作台是这个智能体的完整画布。人设、模型、频道、授权能力和扩展在同一文档中滚动；动态创造位于授权能力的扩展能力子区，不再作为同级章节，也不使用四个一级 Tab 切换身份。页头固定名称、运行状态和保存；右侧检查器只给出运行概况、配置摘要、阻塞项和真实存在的创造运行，不重复主编辑区的频道绑定，也不把首个绑定频道伪装成“最近频道”。缺模型、未绑定频道、网页搜索待凭据和动态创造运行都在本页给出就地入口。`?tab=` 只滚动到对应章节。

创建页与本页共用 `AgentEditorShell`：主编辑列承载名称、人设、模型和能力，辅助列只显示当前状态、阻塞项和创建/保存结果预览。创建模式不伪造已绑定频道或扩展，编辑模式继续显示真实频道与扩展。

### 7.1 页面分区

- 人设与模型；
- 已绑定频道；
- 授权能力；
- 可用扩展及当前智能体的启用状态。

### 7.2 Draft 规则

人设与模型进入同一份 Draft。页面在有未保存更改时提供保存和放弃。能力开关独立提交，不进入这份 Draft。

人设 Draft 是结构化文档。编辑器内可以 `@` 引用平台用户、频道和已保存扩展；频道候选同时说明 Adapter 与平台连接，扩展候选说明当前智能体是否启用。引用只稳定识别对象，不授予权限、不读取其他频道、不启用扩展。失效引用保留在历史配置版本中，以警告 Chip 显示并允许删除或替换。

### 7.3 保存结果

| 按钮 | 结果 |
|---|---|
| 保存新配置 | 为人设与模型创建新 Revision |
| 放弃更改 | 丢弃人设与模型 Draft |
| 系统访问预设 / 逐项设置 / 能力开关 | 立即写入能力 Revision |

运行中的任务在安全间隙使用兼容的新配置。产品不提供“立即替换工具执行中的 Session”。

### 7.4 授权能力

系统访问使用四段拖动条提供快捷预设：“基础权限（Lv.0）→ 文件读写（Lv.1）→ 运行命令（Lv.2）→ 完整访问（Lv.3）”。每一级包含左侧等级，风险样式随等级增强。拖动时滑块连续跟随指针，不在整数节点间跳跃；指针未松开时就高亮最近的预计吸附节点，松开后才吸附并提交该预设。滑轨、节点、滑块和四段标签共用同一条水平坐标轴。拖动条可展开为“文件读写 / 运行命令 / 完整访问”三个独立开关；逐项组合不属于四个预设时，拖动条回到最左端并显示“自定义权限（Lv.C）”，不得暗中修正用户选择。智能体列表中的 Chip 只显示 `Lv.X`，悬浮后再显示等级名称与具体授权情况。

动态创造是授权能力中的扩展能力子区，区头开关同时控制授权和下方入口，不再与授权能力并列，也不在别处重复开关。没有运行时选择沟通频道并“前往频道提出需求”；存在运行后显示“查看创造进度”。保存和启用仍是独立动作。

子智能体与网页搜索后置在“更多能力”，两项互不依赖。网页搜索缺少凭据时，在本区就地保存搜索服务凭据；完整配置仍进入设置。

工作树中智能体名称右侧显示轻量系统访问 Chip（`Lv.0` 至 `Lv.3` / `Lv.C`）；Chip 不承载长说明，Hover 后展示当前等级名称或逐项授权详情。

### 7.5 频道与扩展

已绑定频道可在本页改触发策略。未发现频道的平台账号在本页说明，绑定仍打开共享任务单；是否执行过可选收发测试不构成智能体配置阻塞。扩展章节列出全部本地扩展及当前智能体的启用状态，可以逐项启用或停用；它与扩展详情的“使用范围”共同修改同一条 `(agentId, extensionId)` 关系，任一入口提交后都读取 Host 权威结果。

### 7.6 删除智能体

智能体工作台底部使用紧凑“危险操作”区提供删除。确认框要求完整输入当前已保存名称，并默认开启“同时删除自动创建的内置频道”：tombstone 范围限于删除时绑定给该智能体、且创建智能体时自动生成的内置频道；已换绑频道、手工创建的内置频道和外部频道解除绑定。频道事实、历史配置版本和 DSH 审计用于追溯；扩展、图片和工作区文件归原位置管理。本操作不提供清理工作区或共享资源的选项。

### 7.7 删除或移除频道

频道检查器的“绑定”模块底部提供危险操作，不在频道顶栏重复。内置频道显示“删除内置频道”；外部平台频道显示“从 NekroNXT 移除”。两者都立即取消当前生成或 Tool、关闭 Episode、解除绑定并把频道从活动列表移除。消息事实、资源引用、审计和 DSH 历史可用于追溯；外部 Adapter 再次发现同一频道时复用原频道身份和历史。

### 7.8 领域页面

- 设置：对象列是唯一分类导航，页面不再渲染重复 Tabs。分类包括模型供应商、系统扩展、DSH 扩展、外观和关于。主画布使用安静页头，偏好组依靠标题与间距建立层级，不使用品牌竖线和连续分隔线。系统扩展列出已安装适配器，不在此创建账号；DSH 扩展只配置模型侧能力；关于页展示产品名、组织、版本、Release ID、仓库、许可证状态和品牌版权，旧 Server 缺少产品元数据时使用构建期回退值并把未知字段显示为“暂无”。
- 连接：围绕当前平台连接的身份、健康、发现频道、绑定和配置。对象列「添加平台连接」打开选平台向导；账号详情上的「再添加一个账号」只对该适配器走配置表单。内置频道由 NekroNXT 托管，详情页不提供添加入口。
- 用户：对象列显示“全部用户”和 Adapter 分类计数，筛选写入 `/users` 查询参数。画布默认按 Adapter 分组，选择 Adapter 后平铺；名称、Adapter 与平台连接可以组合筛选。目录包含仅存在于历史或已移除频道中的平台身份，这类行标记“仅历史记录”。本页没有编辑、删除、权限、登录或身份合并操作。
- 扩展：使用安静页头，按“使用进度、当前版本、包含内容、检查结果、使用范围”组织成少量清晰区域。使用范围以紧凑卡片列出所有智能体及启用状态，每张卡片保留身份、版本和独立开关；同一个扩展可以同时给多个智能体启用。创建来源只说明扩展从哪里产生，不限制谁能使用。工具名、扩展格式和 DSH 版本作为次级技术信息保留，不向用户暴露 Host、Client、RPC、Slot、Contribution 等内部称呼；
- 设置、连接和扩展的内容切换层保持透明，连续画布由页面本身提供；内容宽度约束不得形成一块与外层色阶不同、边缘硬切的居中矩形；
- 三类页面使用各自的信息层级，不复用同一张详情大卡片仅替换标题；顶栏不复述模式名，对象列只命名对象集合，主画布只命名当前对象或任务；
- 空对象列不重复主画布空态。连接主画布用“接入聊天平台”引导首个账号；扩展主画布用“扩展库 / 从一次动态运行开始”提供创造入口，对象列只保留集合标题。

## 8. 频道绑定向导

绑定是共享任务单，不是两个一级页面互相跳转。连接页发现频道后即可就地绑定；智能体工作台绑定新频道；未绑定的会话页就地选择智能体。完成后留在原处。收发测试不进入绑定步骤，只在需要诊断平台权限时单独执行。

### 8.1 步骤

```text
选择平台
→ 连接账号
→ 选择频道
→ 绑定智能体
→ 完成绑定
```

### 8.2 最终确认内容

- Adapter 与 Connection；
- Channel；
- 响应它的智能体；
- 触发方式。

### 8.3 按钮逻辑

| 按钮 | 结果 |
|---|---|
| 测试接收 | 验证 Adapter 事件能到达 Channel Runtime，不触发正式智能体|
| 发送测试消息 | 通过目标平台的机器人账号向 Channel 发送明确标记的测试消息 |
| 绑定频道 | 在当前页创建或替换 Binding，不跳转到另一个一级页面 |
| 完成绑定 | 创建 Binding 并开始监听，不要求先执行收发测试 |
| 测试接收 / 发送 | 在连接详情的可选诊断区单独执行一次，不改变绑定流程状态 |

### 8.4 连接辨识名

创建连接时可以填写最多 80 个字符的辨识名；输入会 trim，空值表示未设置。连接详情、对象列、频道来源、智能体频道列表和绑定选择器统一显示“辨识名或连接名”，同时以 Adapter displayName 标注平台身份。已创建的非系统托管连接可保存或清除辨识名；系统托管 Web 连接不显示编辑入口。

## 9. 创造工作台

创造不是一级导航。页面展示已授权智能体活动会话里的动态 Package，以及待确认的 Client 预览。需求在该智能体的频道里描述，不另建创造智能体。

| 按钮 | 结果 |
|---|---|
| 允许预览 / 拒绝 | 审批或拒绝当前动态 Client 界面 |
| 保存为本地扩展 | 写入当前 Episode / Plugin / Package 对应的不可变源码 Revision，随后进入并选中新扩展；不自动启用 |

保存后可在扩展详情的“使用范围”或任一智能体工作台的“可用扩展”中启用。停止动态版本、继续修改、回到上个动态版本尚未作为工作台主操作开放。

## 10. 本地扩展

页面列出已保存的本地扩展、当前版本、创建来源和完整使用范围。每个智能体使用一张带身份、版本状态和独立开关的紧凑卡片；同一扩展可同时给多个智能体启用，停用其中一个不影响其他智能体。

| 操作 | 结果 |
|---|---|
| 打开某个智能体的扩展开关 | 为该扩展的当前版本创建对应智能体的启用关系 |
| 关闭某个智能体的扩展开关 | 只去掉该智能体的启用关系 |

版本回退、停用全部、删除本地扩展和新建修改会话尚未开放。

## 11. 按钮命名铁律

1. 动词必须说明对象：用“停止当前任务”，不用“停止”；
2. 保存和生效分开：用“保存为本地扩展”“启用给小奈”；
3. 不使用“确定”代替真实动作；
4. 不使用“查看”而不说明查看什么；
5. 不把权限、能力和运行模式塞进 Composer；
6. 危险动作只在它真正危险时使用警示色；
7. 不可执行的按钮说明前置条件，不能只灰掉；
8. 每个主按钮只产生一种可解释状态变化。

## 12. 未开放

以下对象可以保留在设计里，但不得画成可点击主操作：

- 记忆、高级分区；
- 应用到当前会话、兼容性 diff；
- 停止当前任务、展开待注入、暂停响应；
- Binding 编辑 / 删除、读取绑定前历史；
- 扩展历史版本回退、停用全部、删除本地扩展、新建修改会话；
- 创造工作台的停止/继续修改/回退动态版本；
- 恢复模式产品面。
