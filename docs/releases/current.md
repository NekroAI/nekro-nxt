# ✨ 本次更新

本次更新新增企业微信智能机器人和实验性的微信 iLink 连接。扩展可以提供侧栏中的专属页面，也可以作为新的平台连接安装到本机；DSH 插件可以在设置中安装和管理。动态创造从描述需求到保存可以连续完成，中途不需要补发“继续”。DSH 引擎随本版升级，升级前请先阅读文末的说明。

## 🚀 主要变化

- **企业微信智能机器人**：填写 BotID 和 Secret 即可通过官方长连接接入，不需要公网回调地址。支持单聊和群聊中提及机器人，可收发 Markdown、图片、文件、语音和视频，并在智能体处理时显示进度；
- **微信 iLink（实验性）**：用微信扫码登录创建连接，智能体可以回复已发现私聊中的文字消息，也可以选择接收对方发来的图片和文件；
- **扩展专属页面**：扩展可以提供出现在侧栏的独立页面。安装前会列出页面入口和所需权限，新版本增加权限时需要重新批准；“扩展 → 页面入口”统一调整各页面的显示和顺序；
- **作为扩展安装的平台连接**：智能体创造或导入的平台适配器安装到本机后，会出现在“添加连接”中。卸载适配器时，已有的连接、频道和历史会保留；
- **DSH 插件管理**：“设置 → DSH 扩展”可以安装指定版本的 npm 包、npm 压缩包或分享包，选择在本机或指定智能体上启用，并导出给其他设备；
- **扩展分享与重建**：本地扩展的任意版本都可以导出为 `.nxt-extension` 文件，导入后在本机重新构建和验证。旧格式的扩展可以从原有源码重建为新版本；
- **动态创造闭环**：在频道里描述需求后，智能体会自己生成、运行并验证扩展。带界面的扩展在浏览器中确认运行后自动继续，智能体会收到结果并完成收尾；带参数的工具会用智能体给出的示例输入真实调用一次；
- **回到已验证的版本**：如果智能体之后又生成了尚未验证的版本，任务页会提供“回到第 N 次候选”，重新验证通过后即可保存；
- **频道活动默认值**：连接详情可以一次设置该账号下所有频道的特殊事件和处理中提示，个别频道再单独调整；
- **移除模型供应商**：可以在设置中移除不再使用的模型供应商。确认前会列出受影响的模型、智能体和频道；智能体配置、频道绑定、聊天记录和已保存的密钥都会保留。

## 🛠️ 改进与修复

- **动态创造**：修复验证通过后无法保存、保存后的页面报错 `styles is not defined`、智能体连续出错后无法继续修复，以及任务长期显示“正在开发”等问题。保存时会再运行一次保存后的扩展，运行失败不会生成新版本；任务需要在浏览器中操作时，频道卡片会提示打开任务页面；
- **工作轨迹与用量**：修复部分模型返回的用量数据导致工作轨迹无法更新、智能体图片诊断无法加载的问题；每一步的用量会显示合计 Token；
- **OneBot 11**：修复部分图片、文件下载失败和系统事件显示不正确的问题；
- **界面**：修复导航栏与对象列之间的空隙、编辑智能体配置时草稿丢失，以及侧栏拖拽排序时的反馈问题；
- **错误提示**：创建智能体等操作失败时会显示具体原因，例如所选模型尚未在供应商中注册。

## ⚠️ 升级前留意

- **会话会重新开始**：升级会先在数据目录的 `backups/` 中创建恢复点，聊天记录、附件、智能体配置、连接、凭据和扩展都会保留。升级前的模型上下文、未完成的运行和未完成的扩展开发任务不会继续，升级前积压的消息也不会补答；下一条新消息会开始新的上下文；
- **需要处理的配置**：与新版不兼容的模型配置或扩展会暂停并显示原因，请到对应的设置、智能体或扩展页面修改，或点击“重新检查兼容性”；
- **旧格式扩展**：显示“需要重建”的扩展，请在扩展详情中点击“从已有源码重建”，然后手动选择新版本并重新核对权限。保存后页面报 `styles is not defined` 的旧版本，需要在创造工作台让智能体重新生成；
- **平台适配器扩展**：平台适配器运行在服务进程内，请只安装来源可信的适配器；
- **微信 iLink 的限制**：目前只能回复已发现私聊中的文字，不支持群聊、提及、主动发起消息和发送图片文件；
- **保留旧版本**：恢复点不包含旧版程序本身。升级前请记下当前版本号，并保留对应的安装包或镜像，以便需要时退回。
