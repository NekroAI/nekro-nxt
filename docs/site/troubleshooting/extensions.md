# 扩展

## 扩展保存了，但没生效

扩展从做出来到能用，要经过几步，每一步都是单独的：试运行通过 → 保存 → 启用。

- 给智能体用的扩展，要在扩展详情或智能体资料里，为这个智能体「启用」；
- 带页面或平台的扩展，要在扩展详情「安装」；
- 扩展申请了权限时，要先批准；
- 从社区装的、从文件导入的扩展，同样要手动启用。

## 有请求在等你确认

智能体做扩展、改配置时，有些操作要管理员同意。工坊列表顶部会显示等待确认的请求，右上角铃铛「需要关注」里也有提醒。在群里也可以直接回复 `/ext approve 编号`。

同一个扩展有好几条请求时，只批最新的一条，旧的会自动作废。

智能体能自己做到哪一步，看她「能力」里“动态创造”的扩展自主权：手动、管理员确认、自主。不管哪一档，切换会影响其他智能体的版本、发布到社区这类操作都要你确认。详见[让她自己做扩展](../extensions/dynamic-creation.md)。

## 试运行失败或保存不了

在工坊打开这个创造任务，看每次尝试的状态和失败原因。保存按钮灰着时，鼠标悬停或点开会说明原因：

- 还没运行过，或还在验证中：等试运行有结果；
- 上次试运行失败：让智能体按失败原因修好后重新运行；
- 界面还没通过验证：带页面的扩展要有人打开 NekroNXT 网页把它加载出来。不想一直开着网页，到「设置 → 附加功能」安装后台浏览器；
- 被拒绝运行：改好后重新提交。

智能体在同一个问题上反复失败时，这一轮会被暂停修改代码。不用重启，在频道里再发一条消息，下一轮会自动恢复。

## 试运行时的数据，保存后不见了

试运行用的是临时存储，保存成扩展后换成正式存储，两边不相通。试运行时写入的数据、填的测试配置不会带过来，保存后在扩展详情重新填写配置即可。

## 填了 API Key 还是用不了

带密钥的配置项要绑定一个凭据：在扩展详情的配置里选择或新建凭据。「本机配置」所有智能体共用，「智能体配置」每个智能体一份。凭据统一在「设置 → 凭据」管理。

## 版本被换掉了或想回退

扩展详情里能看到所有版本，点“回到上一个版本”即可回退。和已有扩展同名的新扩展会被拦下，需要修改原来的扩展，而不是再建一个。

显示“格式不受支持”的扩展来自很早的版本，要在工坊里更新后才能使用。

## 社区扩展更新冲突

「工坊」扩展库里的“社区更新”列出本机版本和社区最新发布的关系：已是最新、社区有更新、本机有修改、两边都有修改。本机改过又想跟上社区的更新时，可以让智能体把社区的改动合进本机版本，或者选择保留本机、改用社区版本。别人的扩展不能直接发新版本，要先创建分支。见[版本、分支与发布](../extensions/versions.md)。

## 下载太大或需要附加功能

- 扩展单次下载默认最多 1 GB，管理员可以在「设置 → 存储」的“扩展下载上限”里调高，最多 5 GB；
- 扩展需要媒体处理、语音识别等组件时，详情里会写“需要附加功能”，点“去安装”。

## DSH 插件用不了

「设置 → DSH 插件」里装好的插件默认关闭，要为本机或某个智能体启用。显示“缺少服务”的插件需要只对官方插件开放的服务；显示“等待服务”的会在依赖的插件启用后自动加载。

## 还是解决不了

导航底部的「日志」可以按来源查看扩展的报错。到[反馈问题](report.md)提交时，附上创造任务里的失败原因和相关日志。
