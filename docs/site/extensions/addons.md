# 附加功能

有些能力要用到额外的程序或模型，比如处理视频要 ffmpeg、语音转文字要识别模型。这些在「设置 → 附加功能」里按需安装，不用的不占空间。

![「设置 → 附加功能」](shot:extensions-addons)

## 有哪些

| 附加功能 | 做什么 | 用在 |
| --- | --- | --- |
| 媒体处理 | 处理音频、视频和动图，比如截取画面、转换格式（ffmpeg） | 扩展 |
| 语音识别 | 把语音转成文字 | 扩展、“语音消息转文字” |
| 语义检索 | 按意思检索扩展保存的内容，比如表情包 | 扩展 |
| 后台浏览器 | 没有打开 NekroNXT 页面时，检查智能体做的扩展界面 | 动态创造 |
| 编排运行环境 | Node，智能体用编排模式运行程序时需要 | 智能体命令 |
| GitHub CLI | 智能体在命令里用 `gh` 操作 GitHub | 智能体命令 |
| Git 与 Bash | 让智能体的命令能用 `git` 和 `bash`，Windows 上可选 | 智能体命令 |

## 安装和选择

点开一项，能看到可用的提供方，以及每个的下载大小、运行时内存和许可证。点“安装”下载，或选“使用这一项”。

- 这台设备已经装有 ffmpeg、Node、gh 时可以直接用，不用再下载；
- Docker 镜像已自带后台浏览器；
- 有的附加功能依赖别的，比如语音识别依赖媒体处理，页面上会写明。

## 语音识别

![语音识别的提供方](shot:extensions-speech)

- **本地识别**：下载模型在这台设备上识别，语音不会发到别处。有偏中文、识别快的，也有支持中英日韩粤的；
- **云端识别**：用「设置 → 模型」里兼容 OpenAI 的供应商识别，按供应商价格计费，语音会发给所选的供应商。在“云端设置”里选供应商、模型和语言。

装好后，到智能体的“能力”里打开“语音消息转文字”，见[能力与授权](../agents/abilities.md#其他开关)。

## 扩展需要附加功能时

扩展用到某个附加功能时，批准页和扩展详情会写“需要附加功能：媒体处理（未安装）”，点“去安装”直接跳到对应页面。
