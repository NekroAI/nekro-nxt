# 产品身份与公开元数据

状态：implemented

## 问题

项目从内部开发仓库转向公开发行时，需要让 README、Web、Desktop、安装器和仓库元数据使用同一个产品身份，同时不能因为改名破坏已安装应用的数据目录、协议、包名或 Release 工件。软件代码采用 GNU Affero General Public License v3.0，品牌资产不并入软件许可证。

## 决定

面向用户和公开展示的正式名称统一为 `NekroNXT`，空间不足时使用 `NXT`。Preview 通道显示 `NekroNXT Preview`，Stable 显示 `NekroNXT`。组织名称统一为 `NekroAI`。

下列值属于兼容性身份，不因展示名变化而重命名：

- 仓库、根包和 workspace scope：`nekro-nxt`、`@nekro-nxt/*`；
- TypeScript 类型中的 `NekroNxt*`；
- 环境变量、协议名、appId、NSIS GUID、可执行文件名和 Release 工件 slug；
- Stable 的持久数据目录 `NekroNxt` 与 Preview 的 `NekroNxt Preview`。

公开文案门禁检查 README、现行文档、HTML、PWA、安装器和用户界面，只允许 `NekroNXT` 或 `NXT`。兼容性身份按精确上下文保留，不用全局替换改写。

Host snapshot 可选提供只读 `productMetadata`：

```ts
interface ProductMetadata {
  displayName: string
  organizationName: string
  version: string
  releaseId: string
  repositoryUrl: string
  licenseSpdx: string | null
}
```

字段整体保持可选，Web 必须兼容没有该字段的旧 Server。关于页优先显示 Host 提供的身份和 Release 信息；缺失时使用构建期产品名、组织、版本、仓库地址与软件许可证，无法可靠推断的 Release ID 显示“暂无”。当前 Host 提供 `AGPL-3.0-only`；旧 Server 缺少该字段时，Web 使用同一构建期回退值。

代码版权声明为 `Copyright © 2026 NekroAI contributors`。Logo、水月荧、角色插画、安装器图形和宣传素材为 `Copyright © 2026 NekroAI. All rights reserved.`，不随代码许可证授权。第三方可在介绍、链接和未修改截图中原样引用；修改或衍生发行不得冒充官方，并应替换品牌资产。

公开可重建的品牌母版、确定性生成器、平台导出和资产清单位于 `assets/brand/`。`.local` 只承载未选稿、提示过程和私有参考，公开构建不读取它。

## 边界

- 根目录与所有 workspace `package.json` 使用 `AGPL-3.0-only`，完整条款以根 `LICENSE` 为准；
- 软件许可证不授权 NekroNXT、NXT、水月荧、Logo、角色插画、安装器图形和宣传素材；
- Desktop 安装包与 Server 镜像同时携带 `LICENSE` 和 `NOTICE`，使软件条款与品牌边界不依赖仓库页面才能查看；
- 不修改仓库可见性、Topics、Private Vulnerability Reporting、Discussions 或 Wiki；
- 不变更签名、公证、升级协议和数据迁移语义；
- 水月荧是品牌角色，不默认成为产品中的智能体。

## 验证

- `pnpm brand:check` 验证资产格式、尺寸、哈希、权利类别、用途、源文件及消费者同步；
- 展示名检查验证公开文案没有遗留 `NekroNxt`；
- Host contract、Server 投影和 Web 旧 Host fallback 测试覆盖可选元数据；
- 产品旅程与人工视觉验收覆盖关于页、品牌空态、Stable/Preview 图标和公开截图。
