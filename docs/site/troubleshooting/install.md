# 安装与启动

查看系统或插件的运行过程，从导航底部打开「日志」，或从对应对象详情进入。操作与保存规则见[查看运行日志](../ops/logs.md)。

## 安装包被系统拦截

当前 Preview 尚未使用平台开发者证书签名。确认下载来自 `NekroAI/nekro-nxt` Release；GitHub 资产列表会显示安装包的 SHA-256。macOS 的完整放行步骤和截图见[桌面版安装：首次打开被系统拦截](../install/desktop.md#macos)。不要为第三方来源的安装包跳过系统检查。

## 桌面版一直显示正在连接或无法连接

完全退出并重新打开桌面版。若本地服务在短时间内反复退出，应用会停止自动恢复；保存诊断日志，并确认数据目录可写、磁盘空间充足。

远程实例需要核对地址、证书指纹、设备配对和服务端状态。轮换管理密钥后旧设备必须重新配对。
