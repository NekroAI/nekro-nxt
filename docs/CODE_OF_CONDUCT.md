# 社区行为准则

NekroNXT 社区希望讨论保持友善、具体并以解决问题为目标。

## 我们鼓励

- 尊重不同经验、背景、语言和观点；
- 对代码、设计和证据提出意见，不攻击个人；
- 给出可复现步骤、上下文和建设性替代方案；
- 承认错误并主动修正；
- 保护用户隐私，不公开真实聊天、账号、群标识或凭据。

## 不可接受

- 骚扰、歧视、威胁、侮辱或持续的人身攻击；
- 未经同意公开他人的身份或私人信息；
- 发布恶意代码、凭据、真实用户数据或利用细节；
- 冒充 NekroAI、维护者、官方构建或项目角色；
- 在维护者明确停止后继续扰乱讨论。

## 执行

普通内容问题可在对应 Issue 或 Pull Request 中提醒维护者。涉及安全、隐私、骚扰或需要私密处理的事件，请使用 GitHub 仓库的私密安全报告入口，并在标题中注明“社区行为”。

维护者可以编辑或删除违规内容、锁定讨论、拒绝贡献，或临时/永久限制参与。执行时会尽量说明具体行为和适用边界，并只向处理事件所需的人员披露信息。
