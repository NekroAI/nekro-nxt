# ✨ 本次更新

这次更新新增「附加功能」：媒体处理、语音识别等按需安装的能力集中在一处管理，同一种能力可以在本机运行，也可以交给云端，按设备情况选择。智能体可以把语音消息转成文字来读，扩展可以处理频道里的文件、音频和视频。桌面版可以在应用内下载更新。

## 🚀 主要变化

- **附加功能**：「设置 → 附加功能」集中列出按需安装的能力，包括媒体处理、语音识别、语义检索、编排运行环境、GitHub CLI 和后台浏览器，原来的「界面检查」「检索」也并到这里。同一种能力有多种提供方式时，可以分别安装、删除，选用其中一种；每种方式写明下载大小、占用空间和运行时内存；
- **媒体处理**：可以直接用这台设备已经安装的 ffmpeg，也可以由 NekroNXT 下载。装好后，智能体的命令里可以直接使用 ffmpeg 和 ffprobe；
- **语音识别**：可以选本地 Paraformer（中文，占用资源少）、本地 SenseVoice（中文、英语、日语、韩语、粤语），或者使用「设置 → 模型」里提供 OpenAI 兼容语音转写的供应商；
- **语音消息转文字**：智能体能力里新增「语音消息转文字」。打开后，智能体收到语音时会同时看到转写的文字，频道时间线也会显示；
- **扩展新能力**：扩展可以读取频道里的文件、处理音频和视频（取画面、截取音频、转换格式）、用 ffmpeg 处理交给它的文件、把语音转成文字，并让智能体看清图片细节。耗时的工具可以显示进度。用到需要安装的附加功能时，启用扩展前会提示先安装；
- **智能体保存附件**：智能体可以把频道里的图片、语音、视频和文件存进自己的工作区，在命令里继续处理；
- **DSH 插件提交图片**：管理员在插件详情里打开「允许提交图片」后，第三方 DSH 插件返回的图片也能交给智能体查看；
- **应用内更新**：桌面版发现新版本后，可以在应用内下载并打开安装包，优先从 NekroNXT 下载镜像获取，失败时改用 GitHub；
- **扩展版本谱系**：扩展的版本页改成纵向谱系图，中间版本可以折叠，可以保留重要版本、清理不用的版本；
- **拖入附件**：文件拖到频道的任何位置都能加为附件。

## 🛠️ 改进与修复

- **需要关注**：同一原因的提醒合并成一条，可以批量忽略；忽略后，直到原因再次出现才会提醒；
- **扩展请求**：同一件事的新请求会替换旧请求，智能体可以撤回自己发出的请求，审批结果只回到发起审批的地方；等待试运行的候选每小时最多提醒一次；
- **定时任务**：按来源分组，已停用扩展的任务先隐藏；
- **命令被拦下时**：命令被沙箱拦下或沙箱没能启动时，智能体会知道原因和该请管理员做什么；
- **发布到社区**：对话框写明要发布的本地版本和版本号；
- **图片多的对话**：整理上下文后保留的图片更少，整理不动时会暂停一会儿，并先省略最早的图片；
- **其他修复**：后台检查扩展页面时，纯文字页面不再被判成空白；智能响应的设置连续修改时不再丢掉前一次修改；桌面版跨盘更换数据目录不再卡在「正在校验数据」，迁移时显示步骤和用时，可以取消。

## ⚠️ 升级前留意

- **入口变了**：「界面检查」和「检索」移到「设置 → 附加功能」，原来的设置保持不变；
- **安装用到新能力的扩展**：用到媒体处理、语音识别、读取频道文件等新能力的扩展需要本版本才能安装；
- **本地语音识别**：加载模型后会占用较多内存，SenseVoice 约 0.9 GB，Paraformer 约 0.35 GB，闲置几分钟后释放。
