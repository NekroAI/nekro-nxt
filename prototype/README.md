# NekroNxt 产品界面原型

离线高保真原型，结构和文案对齐当前 Web 实现：会话 / 工作轨迹、智能体工作台、连接测试、绑定、创造、扩展、设置。不连接 Host。

```bash
pnpm prototype
```

打开 `http://127.0.0.1:4173/`。

顶部场景只给演示者跳转。图标轨、对象列、检查器和对话框可以点。

| 场景 | 对应实现 |
|---|---|
| 进行中 / 已完成 / 工作轨迹 / 网页频道 | 频道会话页 |
| 未绑定 | 未绑定频道的会话与检查器 |
| 第一次 / 创建 | 零智能体空态与四步创建向导 |
| 智能体 | 智能体工作台 |
| 连接 | 连接详情、收发测试、绑定 |
| 绑定 | 共享绑定向导 |
| 创造 / 创造空态 | 创造工作台 |
| 扩展 | 本地扩展详情 |
| 设置 | 外观 |
