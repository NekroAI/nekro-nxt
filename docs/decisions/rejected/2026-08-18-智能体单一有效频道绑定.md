# 已拒绝：智能体单一有效频道绑定

状态：rejected

## 原错误决定

曾错误实现“一个智能体同一时间只允许存在一个有效 Channel Binding”，并允许一个频道绑定多个智能体。该方向与产品真实约束完全相反，导致同一智能体原有网页、QQ 等频道关联被错误停用。

## 拒绝原因

正确关系是：一个智能体可以绑定多个频道，但一个频道同一时间只能绑定一个智能体。每个频道拥有独立消息事实流和 Episode，因此智能体多频道不会混合短期上下文；频道唯一智能体则提供明确的响应所有权。

错误的 `0013_single_active_agent_binding.sql` 已经可能被本地运行实例执行，不能修改其历史内容。后续通过追加迁移按频道恢复唯一活动 Binding，并保留全部历史记录。
