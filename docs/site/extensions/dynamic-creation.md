# 让她自己做扩展

打开动态创造后，在频道里用平常话说出需要，比如“做一个查天气的工具”“给群里做个签到排行榜”，智能体会自己写出扩展、试运行，做好后交给你保存和启用。

## 打开

在智能体资料页的「能力」里打开「动态创造」，改完点页面底部的“保存”。新建的智能体默认关着。

![「动态创造」和「扩展自主权」](shot:extensions-autonomy)

动态创造本身不让她读写文件或运行命令，那些在“系统访问”里另外打开。

## 扩展自主权

「扩展自主权」决定她能自己走到哪一步：

| 档位 | 她能做的 |
| --- | --- |
| 手动（默认） | 开发和试运行；保存、启用都由你在「工坊」里完成 |
| 管理员确认 | 保存、启用、切换版本等每一步都在频道里发请求，管理员回复 `/ext approve 编号` 同意后完成 |
| 自主 | 只影响她自己的普通操作直接完成，并在频道里留下记录和撤销方法 |

不管哪一档，新增高风险权限要在后台批准；发布到社区、迁移数据、会影响其他智能体的操作都要管理员确认。

「谁可以让它做扩展」默认是频道里的所有人，可以改成只有管理员；「谁可以让它改配置」默认只有管理员。管理员怎么设，见[管理员与聊天命令](../channels/admins-commands.md)。

## 做的过程

1. 在频道里说出需要。她开始动手后，「工坊」的“创造任务”里会出现这个任务，任务页显示进度、每一次尝试和实际效果预览；
2. 每写好一版（候选），要先试运行。不是自主档时，在任务页点“允许运行”，或者在群里发 `/ext run 任务名称`；
3. 带界面的候选需要在浏览器里加载一次来检查。开着任何一个 NekroNXT 页面都可以，不用停在任务页；
4. 试运行没通过，她会自己接着修，不用催；
5. 通过后点“保存为扩展”；
6. 保存后还没启用，在任务页点“给她启用”，或去扩展详情启用。

![群友在聊天里提出需求，智能体做好工具并试运行通过](media:dynamic-creation-chat)

试运行、保存、安装、启用是分开的四步。等你确认的任务也会出现在右上角的“需要关注”里。

一个页面都没开着时，可以在「设置 → 附加功能」装上“后台浏览器”，由 NekroNXT 在后台完成界面检查，见[附加功能](addons.md)。没装时候选照常运行，标为“界面未检查”，保存前请先在预览里确认能用。

验证工具时，NekroNXT 会在频道下开一个叫“验证 工具名”的子对话，把每个工具试调一次，可以点开看每次的输入和结果。

## 测试配置

扩展有配置项时，可以在任务页的“测试配置”里填试运行用的值，你填的优先于她填的。API Key 可以选「设置 → 凭据」里的凭据；局域网里的服务地址只能由你填。这些值只用于试运行，保存成扩展后要在扩展详情里重新填写；试运行时写入的数据也不会带到保存后的扩展里。

## 修改已经做好的扩展

在频道里直接说要改什么，她会以当前版本为基础开一个修改任务，保存后成为这个扩展的下一个版本。也可以在扩展详情的版本里选一个版本，点“让智能体在此基础上修改”。见[版本、分支与发布](versions.md)。

对话被清空或换了会话时，进行中的任务会暂停而不是丢失。在频道里说“继续那个任务”，她会接着做。暂停 30 天没继续的任务会自动归档。

## 在聊天里管理

| 命令 | 作用 |
| --- | --- |
| `/ext` | 列出她的扩展、进行中的任务和等待确认的请求 |
| `/ext info 名称` | 查看版本和与社区的同步状态 |
| `/ext approve 编号`、`/ext reject 编号` | 同意或拒绝她的请求，24 小时内有效 |
| `/ext run 任务名称` | 允许运行候选 |
| `/ext enable`、`/ext disable` | 启用、停用扩展 |
| `/ext use 名称 v2`、`/ext revert 名称` | 切换到某个版本、回到上一个版本 |

除了 `/ext` 和 `/ext info`，其他操作都要管理员。
