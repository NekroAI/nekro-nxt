# 创建智能体

智能体是在频道里和大家聊天、帮大家做事的角色。可以有好几个，各自有自己的名字、设定、模型和能力；一个智能体可以同时在很多个群里工作。

## 新建

在「概览」点「创建智能体」，或者在「智能体」列表顶部点 `+`：

1. 给它起个名字；
2. 「模型」里选它用的模型，默认是第一个可用的模型；
3. 「能力」里决定除了聊天还让它做什么，默认开着子对话、定时任务和查阅社区文档（配好 DeepSeek 密钥时还有网页搜索），读写文件、运行命令都关着；
4. 「设定」里写它是谁、怎么说话；
5. 点「创建并开始对话」。

![新建智能体的页面](shot:quickstart-new-agent)

创建后会自动生成它的内置频道并直接打开，可以马上试聊。要让它进群，见[把她拉进第一个群](../start/first-group.md)。

## 资料页

在「智能体」里点开一个智能体，就是它的资料页，按分节排列：

| 分节 | 管什么 | 详见 |
| --- | --- | --- |
| 模型 | 主模型、思考强度、备用模型、压缩、子对话模型 | [选模型与控制花费](../models/choosing.md) |
| 频道 | 它在哪些频道里回复、什么时候回复 | [触发与回复节奏](../channels/response.md) |
| 能力 | 读写文件、运行命令、搜索、子对话、动态创造等 | [能力与授权](abilities.md) |
| 扩展 | 为它启用的扩展 | [扩展是什么](../extensions/overview.md) |
| 定时任务 | 它在聊天里建的提醒和周期任务 | [定时任务](scheduled-tasks.md) |
| 设定 | 它是谁、怎么说话、别名 | [设定与频道说明](persona.md) |

改完点页面底部的“保存”。正在进行的对话会在当前这一步结束后用上新配置。

每次保存都留一个版本。想回到以前的样子，用“更多 → 恢复之前的配置”。

## 它在每个群里是分开的

同一个智能体在不同的群里，对话上下文各自独立，不会把甲群的话带到乙群。每个群里，它会记下关于这个群和群里每个人的笔记，见[记忆与笔记](memory.md)。
