# NekroNxt 决策记录

这里只记录公共协议、领域模型、持久格式、DSH 集成、Extension/Adapter Runtime 和重要产品行为。

- `proposed/`：仍需负责人选择或等待关键证据；
- `accepted/`：设计已经确认，代码可以尚未落地；
- `implemented/`：已经落实的当前事实，用现在时书写；
- `rejected/`：仍可能阻止现实诱惑的否决。过期否决与过程日记在 `../archive/`，不是现行权威。

模板、状态流转与写作规则见 `../06-开发与测试规范.md`。普通功能、局部修复和临时计划不需要 Decision Note。
