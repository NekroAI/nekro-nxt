# 配置模型

NekroNXT 复用 DSH 的模型供应商、Settings 和凭据体系，不维护第二份模型目录。

## 添加供应商

1. 前往「设置 → 模型供应商」；
2. 从可配置目录选择供应商；
3. 填写 API Key、Base URL、协议和供应商要求的字段；
4. 运行连接测试；
5. 保存配置和凭据。

API Key 是只写凭据。页面只显示是否已经配置，不会重新返回原值；清除凭据会使依赖它的模型不可用。

## 为智能体选择模型

创建或编辑智能体时，从实时模型目录选择默认模型。配置保存为不可变版本；运行中的工具不会被半途替换，兼容的新配置在安全边界生效。

模型明确声明支持图片时，频道原图可以进入主模型上下文；文本模型只有在配置了辅助视觉模型后，才能通过图片检查工具取得结构化证据。NekroNXT 不按模型名称猜测图片能力。

## 排障

- 目录为空：确认供应商配置已保存，Host 可以访问供应商；
- 测试失败：核对 API Key、Base URL、协议和模型权限；
- 智能体不可用：确认它引用的模型仍在实时目录中；
- 图片不可用：核对模型能力声明或辅助视觉模型配置。
