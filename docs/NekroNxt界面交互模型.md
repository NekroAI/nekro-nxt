# NekroNXT 界面交互模型

> 用途：约束界面的对象、状态和操作后果
> 状态：现行，按[界面体系第二轮改造](decisions/accepted/2026-10-06-界面体系第二轮改造.md)更新。标注“实现中”的条目是已确认的目标交互，按该决定 §10 分阶段落地
> 原则：先定义对象、状态和操作后果，再设计控件
>
> 视觉 Token、组件和动效遵循 `05-桌面UI与动效规范.md`。用户可见改动的像素级验收遵循 `06-开发与测试规范.md` §5.1。

> 文案铁律：界面中的实体统一称“智能体”。Agent、AI 成员、Bot、助手不得作为同一实体的替代类型名；英文内部类型不得直接显示给用户。空间与交互术语见 `01-术语与文案规范.md` §3.1。

## 1. 全局对象规则

### 1.1 每个空间只有一个主要对象

| 空间 | 路由 | 主要对象 | 次要上下文 |
|---|---|---|---|
| 概览 | `/live` | 需要关注的事项与活动中的频道 | 近期活动潮汐 |
| 频道 | `/channels/:channelId` | 当前频道的消息时间线 | 检查器：响应智能体、上下文、来源 |
| 智能体 | `/agents/:agentId`、`/agents/new` | 智能体资料（新建时为草稿） | 模型、频道、能力、扩展、设定 |
| 工坊 | `/workshop/tasks/:taskId`、`/workshop/extensions/:extensionId` | 创造任务或本地扩展 | 发起任务的智能体、使用它的智能体 |
| 接线 | `/wiring/connections/:id`、`/wiring/channels/:id`、`/wiring/new` | 平台账号或频道的绑定关系 | 接线板全景 |
| 设置 | `/settings/:section` | 一个设置分区 | 无 |
| 日志 | `/logs` | 当前实例的运行记录 | 来源筛选与单条详情 |
| 扩展页面 | `/apps/:pageInstanceId/*` | 扩展自有页面 | 无 |

进入应用默认打开概览。打开 `/channels` 时回到上次打开的频道，没有记录时打开第一个频道。

日志位于导航底部、设置上方，使用来源列表、日志列表和详情的工作台布局。回看历史或选择详情暂停自动跟随；清空视图不删除历史。插件和连接详情可带条件跳转，顶部当前状态仍由原业务对象拥有；复制、导出和临时 Debug 的行为见[查看运行日志](guide/logs.md)。

### 1.2 智能体与频道的关系

- 智能体是长期产品实体；频道是一段消息事实流；
- 频道绑定决定哪个智能体响应该频道；一个智能体可同时绑定多个频道，一个频道同一时间只有一个响应智能体；
- 换绑改变后续响应，不删除频道已有消息；
- 绑定与触发方式可以在接线、智能体资料页“频道”和频道检查器“谁来回复”三处修改，三处使用同一个组件：同样的控件、措辞与可改范围；
- 频道时间线只显示该频道的消息；短期上下文不跨频道混合。

### 1.3 扩展的独立动作

```text
动态运行（工坊中的创造任务）
→ 保存为本地扩展的不可变版本
→ 智能体扩展：启用给一个或多个智能体（需要时先批准权限）
  或 宿主扩展：安装到本机（页面扩展需要先批准权限）
```

- 动态运行：临时、可停止；
- 保存：版本持久化，但不自动启用；
- 启用 / 安装：明确作用于哪个智能体或本机、使用哪个版本。卸载适配器保留连接和历史。

### 1.4 交互语法

全产品使用同一套交互语法（实现中）：

- **选中与打开**：单击对象只选中它，并在详情栏显示；详情中的“打开”或双击才跳转到对象所属的空间。列表行、接线节点、概览卡片一致。
- **两种保存方式**：
  - 智能体的名称、设定、模型、能力就地编辑，修改累积到页面底部的保存栏“N 项未保存的修改 · 保存”，一次保存，也可放弃；
  - 频道触发方式、连接设置、外观、通知等设置改动即时生效，以 Toast 反馈，可撤销。
- **就地编辑**：不再有整页“编辑模式”；名称、别名等短字段原位编辑，设定这类长文本在原位展开专用编辑面板，可全屏。
- **危险操作**：确认框写明会发生什么、保留什么；授权类操作按风险级别决定确认力度。

### 1.5 信息分层与诊断区

- 第一层只呈现名称、状态、后果和下一步；
- 键名、错误码、包名、命名空间、配置版本、内部 ID 和内部版本编号放进默认收起的“诊断”区，可复制；
- 错误码映射为中文原因与建议操作；没有映射的错误显示通用原因，原始错误码只在诊断区出现。

## 2. 状态词典

连接、智能体、任务与扩展各有一套固定的状态、颜色与措辞。状态栏、列表、详情与概览都从这里取值，不各自命名。

### 2.1 本机状态

正在连接、运行正常、连接不稳定、无法连接。连接不稳定时保留最后一次成功的数据。

### 2.2 平台账号状态

| 状态 | 颜色 |
|---|---|
| 已连接 | 成功 |
| 正在连接、已配置 | 警告 |
| 认证过期、已断开、异常 | 错误 |

“已配置”表示配置已保存但尚未连上，详情中写明原因与下一步。

### 2.3 智能体运行状态

| 状态 | 含义 | 颜色 |
|---|---|---|
| 空闲 | 没有活动轮次 | 中性 |
| 思考中 | 模型正在生成 | 强调 |
| 使用工具 | 工具正在运行 | 强调 |
| 等待输入 | 等待用户回答或批准 | 警告 |
| 不可用 | 模型、配置或运行时有错误 | 错误 |

不使用含糊的“在线”。

### 2.4 创造任务状态

正在开发、等待确认、正在验证、可以保存、正在修复、需要处理（失败或中断）、已停止、已保存。

### 2.5 扩展状态

智能体扩展：未启用、N 个智能体使用、运行异常。宿主扩展：未安装、已安装、运行异常。版本格式不再受支持时标记“格式不受支持”，该版本不能启用。

扩展的版本以“时间 + 改了什么 + 来源”区分，例如“10月11日 · 加上下播通知 · 水月荧修改”“10月14日 · 社区更新：修复直播间筛选”。“改了什么”取自修改任务的需求或社区发布说明，过长时截断；没有可用的说明时只写来源（智能体创造、文件导入、社区安装、分支创建）。谱系中的版本号与社区发布编号（如 v3、社区 #3）只出现在版本详情的小字与诊断区，用于反馈与排查。

### 2.6 其他状态

| 对象 | 状态 | 形态与颜色 |
|---|---|---|
| 社区审查 | 官方、已审查、待复审、有风险 | `Chip`：官方为强调，已审查为成功，待复审为警告，有风险为错误；审查建议只在详情页出现 |
| 本机与社区的版本 | 已是最新、有更新、本机较新、已分叉 | `Chip`：有更新为强调，已分叉为警告，其余中性 |
| 保存 | 已保存、N 项未保存 | 已保存不显示；未保存由 `SaveBar` 表达 |
| 开关类设置 | 开、关 | 只用 `Switch` 表达，旁边不再写“启用”“已开启” |
| 始终开启的项目 | 始终开启 | 文字说明，不显示禁用的开关 |

## 3. 应用外壳

- **导航轨**：概览、频道、智能体、工坊、社区、接线；分隔线下是扩展页面区（扩展注册的页面），按剩余高度显示，放不下的收进“更多”；日志和设置在底部。面包屑与导航层级一致：扩展页面的位置是“扩展页面 / 页面名”。窄屏底栏见 [UI 规范](05-桌面UI与动效规范.md) §6.2。
- **顶栏**：服务实例（Desktop 中点击打开实例切换，浏览器中点击进入关于页，连接异常时直接显示状态）、当前位置、搜索、关注铃。当前位置只是文字，不可点击：空间之间靠导航轨切换，回到空间根路径会清空当前选中。
- **状态栏**：本机、每个平台账号、正在工作的智能体，各自点击进入对应对象；颜色与措辞取自 §2 状态词典。
- **命令面板**（`⌘K` / `Ctrl+K`）：分组为前往、频道、智能体、扩展页面、操作（新建智能体、切换浅色或深色）和成员。输入时向服务查找平台成员，选中后打开成员所在频道或所属账号。上下键选择，回车打开。第二轮改造增加最近使用置顶与更多动作类命令（实现中）。
- **关注铃**：数字为需要关注的事项数；点击在任何页面展开需要关注列表，处理与忽略都在这里完成。
- **升级提示**：服务已升级而页面未刷新时，画布顶部提示刷新；刷新前保存频道草稿，有未保存表单时先确认。

## 4. 概览

- 顶部统计：正在工作的智能体、需要关注的事项、近期消息数；
- **活动图**：近两小时每 5 分钟（无数据时扩展到一天每小时）的消息数，按频道堆叠成柱，消息最多的 5 个频道各用可区分的身份色，其余合为“其他频道”；带数值刻度与时刻，悬停显示该时段的分频道数量与合计，图例可按频道隐藏；
- **需要关注**：只做汇总。同一来源的同类事项合为一行，例如“9 条消息发送失败 · NekroAI(伪)智能研究所”，按严重程度排序；点击打开关注铃里已筛选到这一组的列表。处理与忽略只在关注铃中进行。事项来源：未确认投递、投递失败、失败轮次、等待确认的创造任务、异常账号、缺少模型或识图模型；
- **活动频道**：有近期消息或正在工作的频道卡片，显示响应智能体、末条消息和贴底的活动曲线，卡片颜色与活动图一致；有新消息时卡片短暂高亮；其余频道收为一行快捷入口；
- **实时性**：智能体状态、频道末条消息与未读经 SSE（`/api/events`）即时推送；活动图与消息数在新消息到达后约 1.5 秒内合并刷新一次，安静时每分钟随时间窗前移；相对时间每半分钟刷新；
- 引擎升级后的上下文归档说明与兼容性隔离提示也在这里显示，可重新检查。

## 5. 频道

### 5.1 频道列表

- 两种视图：“按智能体”分组和“最近活动”；支持检索与筛选（实现中）；
- 按智能体视图支持拖动：组内调整顺序；拖到另一个智能体组即换绑，拖到“未接线”即解绑。跨组放下后弹出确认，确认框显示前后接线与触发方式；
- 每行副标题显示连接展示名（`alias ?? 适配器名`），有未读时显示数量。

### 5.2 时间线

- 成员消息、管理员从客户端发出的消息与智能体发言分开呈现；智能体发言只来自通信工具；
- 每个智能体轮次在常态下按执行顺序列出工具步骤，每步一行可读摘要（搜索词、命令说明或命令、发出的消息、结束原因），不显示 JSON。点击一步就地展开它的详情：搜索词与找到的来源、完整命令与输出（可复制）、发出的内容与送达结果；完整内容在展开时按需读取。打开头部的“透视”后，同一时间线展开思考、工具输入输出、扩展工具视图和用量，不跳转到另一视图；
- 扩展的入站钩子改变了一条成员消息的处理时，消息下方一行小字说明结果与扩展名（对智能体隐藏、未唤醒智能体、已唤醒智能体、附加了说明、扩展处理出错），隐藏的消息气泡变淡，悬停显示说明与出错原因；
- 定时任务到期是宿主事实，以居中的提示行显示（闹钟图标、“定时任务”或扩展名、任务内容，补充说明另起一行），不显示为成员发言；
- 未确认送达的出站消息显示“重发”和“已送达”两个处理动作；
- 打开频道即推进阅读位置。

### 5.3 排队与停止

- 工具执行期间到达的新消息会被收录并排队，在安全间隙注入；时间线底部显示“N 条新消息排队中”，可展开查看；
- 正在进行的轮次带“停止”按钮，确认后中止当前模型或工具，不清空上下文，已完成的步骤不撤回，排队的消息保留。普通新消息不会隐式取消当前工具。

### 5.4 Composer

- 发给内置频道时直接提交；发到外部频道时标明以哪个平台账号发出，记为“管理员从客户端发出”；
- 输入法组字期间回车不发送；无法发送时就地说明原因；
- 草稿按频道保存，切换频道和刷新后保留。

### 5.5 检查器

检查器使用统一的详情栏与属性列表，每一行都是“名称 + 一句说明 + 控件”，不出现没有说明的按钮。分组为：

- 谁来回复：智能体（下拉选择，含“不回复”以解绑；旁边的图标打开它的资料）、何时回复（说明当前触发方式的实际含义）、处理中反馈与特殊事件（按事件覆盖账号默认的触发）；
- 上下文：容量条显示占用量与来源构成；“压缩”“清空”各占一行并说明后果（均需确认）；
- 定时任务：本频道仍会触发或已暂停的任务，最多三行，行内可暂停/恢复、立即执行、删除（删除需确认）；更多时“全部 N 个”进入智能体资料页；没有任务时不显示本组；
- 来源：所属平台账号与状态，图标按钮跳到接线；内置频道说明它不来自外部平台；
- 诊断：技术值，默认收起；
- 扩展面板：频道面板与该频道响应智能体的紧凑面板；
- 页尾危险操作区：清空上下文，内置频道“删除频道”，外部频道“移除频道”。频道名称只在标题处出现并就地编辑，不再另起“名称”分组。

### 5.6 子对话

子对话是挂在频道对话下的一段独立对话：有自己的记录和上下文，不在频道里发言，和频道对话互不占用。它有两种来源：

- 智能体开启：开启“子对话”能力的智能体用 `conversation_open` 把一件需要单独处理的事交给子对话，子对话每次回复都送回频道对话；两边用 `conversation_send` 互相传话，事情办完由智能体用 `conversation_close` 结束并写下结论，用 `conversation_delete` 销毁自己开的、已结束的子对话；
- NekroNXT 开启：验证扩展候选时，宿主在频道对话下开一个按固定步骤调用候选工具的子对话（显示为“验证 工具名”），调用完成后自动结束，记为已完成或未完成。

呈现：

- 频道列表中，子对话缩进显示在所属频道下方：进行中的始终显示，已结束的收进“已结束 N”，展开后可见；当前打开的子对话所在折叠自动展开；
- 子对话页沿用频道对话的页头与时间线：标题、状态、所属频道（可点回）、开启者与时间；有结论时在时间线上方显示；时间线默认展开透视，列出它收到的任务、传话、工具步骤与回复；
- 子对话页只读，没有输入框，底部说明“子对话里的消息由智能体之间传递，这里只能查看”。进行中的可以“结束”（停下当前的事，记录保留），已结束的可以“销毁”（连同记录删除），均需确认；
- 创造任务页的“验证对话”列出该任务的验证子对话，点击进入；
- 频道对话结束（清空上下文、停止、换绑）时，它的子对话一并结束；已结束的子对话按“设置 → 子对话”的保留时长（默认 7 天）连同记录清理。

## 6. 智能体

### 6.1 新建

填写名称、设定和模型后创建；创建会同时生成一个内置频道，完成后进入该频道。

### 6.2 资料页

智能体只是几个配置项的集合，界面不呈现“版本”概念：只有“保存”，不出现“发布新版本”、版本号或版本历史区。每次保存在内部生成不可变配置快照，用于运行中的会话在安全点切换与审计，用户无需关心。

目标结构（实现中）为一页滚动加固定的分节导航，先展示功能，设定放在最后：

1. **对象头部**：头像、名称、当前状态、模型、频道数；主操作“在频道中对话”，“更多”菜单中有“恢复之前的配置”与“删除”。缺少模型或识图模型、默认模型已不在供应商列表时显示提示与替换动作；
2. **模型**：主模型与视觉模型的选择，显示视觉、上下文长度等能力；主模型提供多档思考强度时，用与“系统访问”同样的分档刻度选择，首档为模型默认；
3. **频道**：该智能体响应的频道与各自触发方式，行内可改，可添加或移除频道；
4. **能力**：系统访问使用风险阶梯（基础权限 → 工作区读写 → 运行命令 → 完整访问，可点选或拖动，逐级显示新增能力，运行命令及以上需确认；可展开“手动调整”单独控制各项能力，不属于任何级别时显示“自定义”）；开启运行命令后出现“命令联网”（默认开启；完整访问下或这台设备无法限制时开关固定为开启并说明原因）、“命令可用的凭据”（只读，列出命令会拿到的凭据名称和环境变量名，范围在凭据上管理，旁边可前往“设置 → 凭据”）和“编排模式（PTC）”（这台设备没有可用的 Node 时，开关置灰，下方可就地下载运行环境并显示进度）；子对话、网页搜索（缺凭据时就地保存）、动态创造、定时任务（默认开启）。从属于某项能力的设置（运行命令下的命令联网与命令可用的凭据，动态创造下的扩展自主权、“谁可以让它做扩展”与“谁可以让它改配置”（默认只有管理员））缩进在父项之下，父项关闭时收起；
5. **扩展**：已启用的扩展、它们的完整面板，以及启用新扩展的入口（需要时先批准权限）；
6. **定时任务**：该智能体在各频道的全部任务，显示内容、频道与来源、计划的人话描述、下次触发或状态；行内暂停/恢复、立即执行、删除。不提供新建表单，创建与修改在频道里对智能体说；
7. **设定**：默认折叠为几行摘要，展开或编辑时才显示全文；编辑在原位展开专用面板，支持结构化引用，可全屏。

名称、模型、能力和设定的修改累积到底部保存栏统一保存；频道触发方式即时生效。

- **恢复之前的配置**：从“更多”进入，按保存时间列出之前的配置，选择后恢复为当前配置；
- **删除**：输入名称确认；可选同时删除它自动创建的内置频道、同时删除工作区。

## 7. 工坊

### 7.1 列表

左侧分为“创造任务”（按状态分组，进行中的置顶）与“扩展库”（按类型：智能体扩展、页面、适配器）。社区有更新的扩展在列表中标“有更新”，顶部可一次检查全部更新（原社区“同步”）。顶部可导入 `.nxt-extension` 文件，导入后不自动启用；也可“添加 MCP 服务”：填写远程地址或本机命令、请求头或环境变量（可直接填写、作为凭据保存，或选择已添加的凭据）、工具前缀与要启用的智能体，“测试连接”列出服务提供的工具，添加后按普通扩展审批启用（详见[MCP 服务接入](decisions/implemented/2026-10-07-MCP服务接入.md)）。没有任务和扩展时，空状态说明扩展能做什么、给出工具、面板、页面三类示例，列出已开启动态创造的智能体（点击进入其频道描述需求），并提供导入入口（实现中）。

窄于 1100px 时工坊入口显示完整列表，打开任务或扩展后通过“返回工坊列表”切换对象；宽屏继续并列显示列表与详情。

### 7.2 创造任务

- 进度：生成候选 → 确认运行 → 启动 → 界面验证 → 保存 → 启用；失败步骤标红；改为紧凑的水平阶段条，主区为预览与当前待办，操作集中在页头（实现中）；
- 下一步：根据状态只给一个主动作——等待确认时“允许运行 / 拒绝”；通过验证后“保存为扩展”；已保存后“查看扩展 / 给某智能体启用”；失败时显示失败阶段与原因，可回到已验证的上一次候选；
- 预览：任务进行中显示候选界面；
- 确认运行：
  - 智能体的扩展自主权为“自主”时，候选不需要确认；
  - 管理员已经允许过同等风险的候选，或在聊天里发送 `/ext run 任务名称` 允许过，也不需要再确认；
  - 拒绝用“拒绝”按钮或 `/ext reject 任务名称`；
- 界面验证：不需要确认的候选，由任意打开的 NekroNXT 页面在后台加载界面并完成验证，不必停在任务页。约 8 秒内没有页面接手时：
  - 已在“设置 → 界面检查”装了后台浏览器（无头 Chromium，服务端镜像自带），由服务端打开任务页完成；
  - 没装或无法启动时，候选照常运行，记为“界面未检查”。保存前在预览里确认能用；
- 尝试：全部候选尝试与各自状态；
- 保存：保存为新扩展，或保存为已有扩展的新版本；
- 停止任务、删除任务记录（已保存的扩展保留）。

### 7.3 本地扩展详情

对象头部之后用页签分为：

- **概览**：能提供什么（按类别一行，名称为 Chip，可展开；供界面读取的数据接口不展示）、当前版本与安装状态、启用它的智能体（每个智能体一行开关）；
- **配置**：扩展声明的配置项，使用统一配置表单；
- **版本**：谱系图与版本列表合并，按 §2.5 的方式呈现版本；切换、回退、社区更新与发布都在这里；
- **数据**：扩展数据的备份、导入与迁移；
- **诊断**：内部编号与技术值；
- 导出放在“更多”菜单；卸载与删除放在概览页尾的危险操作区。

## 8. 接线

- 接线板三列：平台账号 → 频道 → 智能体。从频道端口拖到智能体即接线（确认后生效）；点击端口用列表选择智能体；点击连线可换绑或断开；
- 所有节点（账号、频道、智能体）单击都只选中并在右侧显示详情，“打开智能体”“打开频道”放在详情中（实现中）；
- 频道按账号分组并可折叠，支持检索与“只看未接线”；智能体列固定在视口内（实现中）；
- 右侧详情：平台账号显示状态与错误、名称、频道、频道活动默认触发、诊断（测试接收、测试发送）、扩展面板、成员列表、重新扫码登录（扫码类平台）与删除（可选同时删除频道数据）；错误码映射为中文原因，原始错误码进入诊断区；
- **编辑连接设置**：通过适配器的配置表单修改公开设置；凭据区分保留、替换和清除，旧值不回显。保存保留连接和频道身份，连接结果单独显示。
- **添加账号**（`/wiring/new`）：先选平台，再填写统一配置表单或扫码登录；也可恢复已移除的账号；
- 1100px 以下先展示平台账号、频道和智能体列表；选中对象后详情占用主区，提供“返回接线列表”。添加账号入口始终可达。

## 9. 设置

设置分节分为四组：

| 组 | 分节 |
|---|---|
| 智能体运行 | 模型、检索、DSH 插件、聊天、子对话、界面检查 |
| 连接 | 平台适配器、凭据 |
| 权限 | 管理员、聊天命令 |
| 系统 | 通知、外观、日志保存、社区反馈、关于 |

聊天命令以表格呈现，一条命令一行：命令、说明、生效权限、开关；`/help` 始终开启，不显示开关。频道检查器的“命令”只列出本频道与默认不同的设置，并可在那里覆盖。

设置列表的分节行为一致：点击即打开该分节，不在列表里展开子项。有子对象的分节先显示概览表格，点击一行进入对象页，对象页顶部提供返回概览的入口；地址只记录用户打开的对象，不自动选中第一项。

- **模型**：概览表格列出已配置的供应商（接入方式、状态、模型数）；状态在供应商待启用时显示“待启用”，否则显示当前已保存配置最近一次连接测试的结果（未测试、测试通过或测试失败及时间），失败原因在供应商页状态旁的说明中；供应商页分为凭据、模型列表、连接测试、高级；删除供应商后回到概览；模型列表为可行内编辑的表格，含视觉能力列；供应商的技术字段进入诊断区；
- 可登录套餐的供应商（目前为 OpenAI 的 ChatGPT 套餐）在凭据中切换 API 密钥与套餐：套餐方式显示账号选择、登录或添加账号、使用此账号、重命名、退出和使用量入口；登录进行中显示授权页面链接和粘贴回调网址的输入框。“添加供应商”中另有“ChatGPT 套餐（登录账号）”入口。
- **DSH 插件**：概览表格按内置、用户安装、其他扩展排序，状态列只在已启用或加载失败时显示；安装收进“安装插件”对话框完成预检与确认；插件配置使用统一配置表单并显示中文字段名，键名、命名空间与配置版本进入诊断区；
- **平台适配器**：列表，显示账号数与添加入口；只有存在非内置来源时才显示来源列；
- **凭据**：概览表格列出名称、说明、用途（允许的域名，或“程序可读”与环境变量名）、行内的自动使用开关和最近使用时间，GitHub 凭据显示账号；智能体申请但尚未添加的凭据列在表格上方，可“添加”（打开预填的添加表单）或“忽略”；通知里的申请链接（`?add=1&name=…`）直接打开预填的表单。“添加凭据”填写名称、说明、值、使用方式（仅用于网络请求 / 允许程序读取，选择后者时就地提示风险）、允许的域名、环境变量名（仅程序读取）和自动使用，“可用智能体”收在“高级”里，默认全部智能体；值少于 8 个字符时提示无法在智能体的上下文中隐藏。“添加 GitHub 账号”填写 token 或选择本机 gh 已登录的账号。对象页可修改以上设置、更换值，查看使用方、已同意的智能体（可撤销）与使用记录（时间、智能体、频道、使用方、目标），页尾删除时列出仍在使用它的扩展和命令。表格下方是模型供应商的开放开关和 GitHub CLI 的下载或移除。扩展配置、创造任务的测试配置和 MCP 服务的凭据字段都可以选择已添加的凭据或就地新建；
- **通知、外观、关于**：阅读型；外观中增加密度（标准 / 紧凑）。

## 10. 扩展贡献的放置

| 贡献 | 出现位置 |
|---|---|
| 智能体面板 | 智能体资料页（完整）；它响应频道的检查器（紧凑） |
| 频道面板 | 频道检查器 |
| 扩展面板 | 工坊扩展详情 |
| 连接面板 | 接线账号详情（状态、诊断）；添加账号页（设置） |
| 工具视图 | 时间线工具摘要（chip）与透视卡片（card） |

没有贡献时不渲染任何占位。

## 11. 按钮命名铁律

1. 动词说明对象：用“停止当前任务”“压缩上下文”，不用孤立的“确定”；
2. 保存和生效分开：“保存为扩展”“给小奈启用”；智能体配置只写“保存”，不写“发布新版本”；
3. 不使用“查看”而不说明查看什么；
4. 危险动作只在真正危险时使用警示色，并在确认框中说明后果与保留的对象；
5. 不可执行的按钮说明前置条件；
6. 每个主按钮只产生一种可解释的状态变化。

## 12. 未开放

未实现的操作不出现在界面中；必须展示时禁用并标注“尚未开放”，不占据一级导航或主操作位置。

## 命令交互

设置增加「聊天命令」入口（区别于智能体的运行命令与命令面板），展示来源、用法、默认权限、全局开关及加载问题。频道检查器提供「暂停回应」开关（与 `/pause`、`/resume` 同一状态，暂停时频道标题与列表显示「已暂停」）、启用覆盖、外部群的「允许不带 @ 的命令」和现有成员的管理命令授权。Composer 输入 `/` 提供键盘选择、补全与用法提示；外部频道里提示命令只在控制台执行还是也会发送到频道，原文不发往平台。消息流分别显示执行状态、只在控制台显示的结果与投递失败，操作规则见[命令系统](10-命令系统.md)。
