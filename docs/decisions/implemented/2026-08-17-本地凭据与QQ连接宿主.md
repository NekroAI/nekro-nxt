# 本地凭据与 QQ Connection

状态：implemented

Web 创建 QQ 连接时一次性提交 App ID、Client Secret 和主动发送策略。Secret 只写入 Host 私有凭据目录（目录 `0700`、文件 `0600`，staging + fsync + 原子 rename）。Core Connection 只保存 `credential:local:<id>`，解析器拒绝路径和符号链接。

`NekroRuntime` 拥有 Connection 生命周期：创建或恢复 QQ Runtime，注册 Adapter，发布 Gateway 状态，dispose 时等待静止。Gateway resume 使用 SQLite Adapter 状态；Web Connection 重启复用已有记录。

接收测试只在真实 Gateway 入站已提交 Channel Event 后通过。发送测试必须先发现频道，再经 QQ HTTP 发送诊断消息。认证、限流、未知结果和无频道各自返回。

凭据文件先提交再创建 Connection；Connection 提交失败则删除刚写的凭据。Runtime 启动失败保留 Connection 并标记错误。引用缺失时不启动 Gateway。

真实账号通知、额度、CDN/上传和断网恢复尚未验收。不做云凭据、钥匙串、多用户 RBAC 或凭据同步。
