# 配置模型

智能体用的模型都来自「设置 → 模型」里配好的供应商。NekroNXT 内置了 DeepSeek，填上 API 密钥就能用；也可以接入其他供应商或兼容 OpenAI 接口的中转服务。

## 填写内置 DeepSeek 的密钥

在「设置 → 模型」点 DeepSeek，把密钥填进「API 密钥」，点「保存供应商」。

![DeepSeek 供应商页：凭据和模型列表](shot:quickstart-model-key)

## 添加供应商

1. 在「设置 → 模型」点“添加供应商”，从目录里选择供应商；
2. 填写 API 密钥，以及供应商要求的接口地址、协议等字段；
3. 点「测试连接」；
4. 点「保存供应商」。

供应商列表和供应商页显示当前配置最近一次连接测试的结果；修改 API 地址、协议或 API Key 后需要重新测试。

API Key 是只写凭据。页面用“已配置”或“未配置”显示凭据状态，保存后不回显原值；清除凭据会使依赖它的模型不可用。

## 管理模型列表

在「设置 → 模型」中选择已配置的供应商，就能编辑它的模型列表。每个模型可以填写模型 ID、显示名、上下文长度和最大输出，并通过“支持图片”开关声明它能否直接理解图片。

- 添加模型：点击“添加模型”填写模型 ID。供应商提供模型查询时，“获取可用模型”会列出尚未加入的模型：可以搜索，点选后“加入所选”，或用“全部加入”加入当前搜索到的全部模型。已在列表中的模型会跳过。不提供查询的供应商（如 DeepSeek 官方接入）不显示这个按钮，需要手动添加；
- 列表超过 10 个模型时，上方出现搜索框，每行前出现勾选框。表头的勾选框选中或取消当前搜索到的全部模型，选中后可以“删除所选”；
- “思考档位”列声明模型提供哪些思考强度，点击后勾选档位（关闭、最少、低、中、高、很高、最高）。第三方网关对某一档用别的参数值时，在“上游参数值”里填写；留空时发送档位名，“关闭”留空时不发送。至少要选一个“关闭”以外的档位；全部取消后显示“未设置”，模型改用供应商目录里的思考能力，目录里没有的模型不思考。“获取可用模型”只为还没有档位的模型补充，不覆盖手动选的档位。窄窗口下“最大输出”先收起，更窄时这一列和“显示名”一起收起；
- 修改列表只在保存时生效，没有改动模型时保存不会影响供应商自带的列表；
- 改过列表的内置供应商会显示“已自定义”，可以用“恢复默认模型”改回供应商自带的列表。恢复后，使用被移除模型的智能体需要重新选择模型；
- 通用接入的供应商新增目录之外的模型时，需要在高级设置中填写 API 地址并选择 API 协议。选择协议后，该供应商的全部模型都使用这个协议；
- 少数供应商的模型由适配器固定提供，页面只显示列表，不提供编辑。

供应商停用或改名后，原来的模型可能从列表中消失。使用这类模型的智能体会在右上角的“需要关注”里提示，可以改用同一供应商的可用模型，或在模型设置中把它加回列表。

## 用 ChatGPT 套餐

已有 ChatGPT 付费套餐时，可以在供应商目录里选择 ChatGPT，用账号登录，不需要 API 密钥。登录后点“获取可用模型”，列表会带上账号可用的模型、思考强度和上下文长度。套餐额度用完、账号或工作区不允许外部使用时，测试连接会说明原因，可以换账号或改用 API 密钥。
