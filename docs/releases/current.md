# ✨ 本次更新

## 🛠️ 改进与修复

- **启动更快**：同一版本再次启动时，不再把升级恢复点的每个文件重新读一遍，只核对文件是否齐全、大小和修改时间是否一致，数据多的实例能省下几分钟。恢复点第一次生成时，以及真正从它恢复之前，仍会逐个文件完整校验；完整校验本身也比原来快。群里积压了大量聊天记录时，启动后也不再要等几十秒才开始处理新消息、重新连上平台。
- **扩展读取凭据**：扩展配置里绑定的凭据设为「仅用于网络请求」或没有开放给当前智能体时，扩展读取它会直接报出凭据名称、原因和改法，不再像没填一样提示缺少密钥。
- **扩展更新**：从社区安装或发布到社区的扩展，详情页标题下有“检查更新”按钮，社区有新版时直接显示“更新到”按钮。打开扩展详情或社区更新页时，距上次检查超过 1 小时会自动再查；后台改为每 6 小时检查一次。
