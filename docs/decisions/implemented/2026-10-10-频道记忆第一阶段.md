# 频道记忆第一阶段

状态：implemented（2026-10-10 负责人确认方向并实施第一阶段）

一个 11 天没被叫到的群，一次 @ 把 1399 条积压消息和 203 张图塞进上下文，首字等了 143 秒。追查下去是两件事：上下文和图片怎么管才能兼顾缓存、体验和成本；以及群聊智能体的长短期记忆该怎么做。调研材料（通用智能体与陪伴产品、群聊 bot 生态、Nekro Agent 复盘、NXT 与 DSH 现有机制）存放在维护者本地，这里只记结论和契约。

## 1. 方向

1. 不引入向量库、嵌入服务、后台实体抽取、时间衰减遗忘，也不按相似度往提示词前缀里注入记忆。理由：群聊场景没有正面证据；上一代 Nekro Agent 的结构化记忆在默认配置下结构性地起不了作用；每轮注入会破坏提示缓存；自托管用户多一套部署和学习成本。
2. 记忆分两层：小而常驻的频道笔记（智能体自己写，管理员可改可锁），大而按需的聊天原文（智能体自己翻）。频道笔记是唯一的长期记忆常驻层，不另建第二个写入处。
3. 第一阶段只接通现有骨架，不新增存储依赖。第二阶段（频道记忆文档等）等评测数据再定。

## 2. 第一阶段内容

| 环节 | 做法 |
|---|---|
| 聊天记录工具 | `conversation_history_read` / `conversation_history_search` 返回给模型的是消息本身（`[时间 · 消息编号] 发言人：正文`，按时间顺序，满页时给出继续往前的游标），不再只是条数。支持时间段（`since`、`until`、`withinHours`）、发言人（成员编号或名字片段，「你」表示自己）、多个词同时出现。 |
| 先查再答 | 系统提示要求：被问到以前的事，眼前没有就先查原话；查过没有再说不记得。 |
| 积压预算 | 按频道设置逐条读入的文字量（默认约 4 万字），从新往旧取，至少保留最近 20 条；更早的折叠成一句概括（时间范围、条数、图片数、说话多的人）。积压里只把最新的几张图片（默认 6 张）直接给模型，其余保留编号。 |
| 频道笔记 | 默认开放给智能体写。笔记在运行时上下文里，改动只在末尾追加快照，不打断缓存；之前默认锁定的理由不成立。工具描述写明记什么（称呼、规矩、固定活动、对人的了解、更正）、写清是谁哪天说的、不记什么。 |
| 安静后整理 | 群里安静一段时间（默认 45 分钟）后，在热会话里跑一轮不说话的回顾，有值得记的就更新笔记。笔记被锁定、频道设置关闭或会话忙时不跑。 |
| 压缩与交接 | 压缩改用中文群聊模板（参与者与称呼、正在进行的事、约定与要求、承诺与待办、关键结论、有用的资料、正在做的事），跑团细节和名字、数字原样保留；仍复用对话前缀以命中缓存。会话交接读取整段会话（按字数上限从新往旧取），不再只看最后 100 条。 |
| 可观测 | 会话记录 `nekro-nxt/memory` 事件（积压折叠、聊天记录搜索及命中数、笔记更新、安静后整理），频道详情「上下文」列出最近几条；上下文占用里「其他」注明含多少张图片。 |
| 图片上传索引 | DeepSeek 适配器的上传索引只接受 `sha256:` 形式的附件编号，任一记录不符就整份作废，导致每一步都重新串行上传所有图片。NXT 在 `readImageRequest` 里把交给适配器的附件编号换成内容摘要；变体编号仍由原引用计算。不修改 DSH，DSH 修复后可去掉这层转换。 |

## 3. 频道设置

`channel_context_policies` 表（迁移 0038）按频道保存 `backlogTextChars`、`backlogImages`、`idleReviewMinutes`；没有记录的频道用默认值。接口为 `GET/PUT /api/channels/:channelId/context-policy`，`policy: null` 恢复默认。界面在频道详情「上下文」里给出几档预设。

## 4. 评测

本地评测工具用虚构的群聊场景和真实 DeepSeek 模型对比改动前后：跨会话回忆、跑团细节、长积压唤醒、纠错与玩笑、时间性回忆。结果见第 5 节。

## 5. 结果

2026-10-10 用水月荧人设和 DeepSeek 官方接口，每个场景各跑两轮，改动前后对比：

| 场景 | 改动前 | 改动后 |
|---|---|---|
| 换会话后回忆（7 问） | 第一轮错 2 问、第二轮错 1 问：搜了也说「没聊过」 | 两轮全对，每问约 4–9 秒 |
| 闲聊群换会话后第一问 | 整轮 77–81 秒，7 步，夹着命令行 | 整轮 6–9 秒 |
| 跑团换会话后第一问 | 整轮 42–106 秒，最多 18 步、11 次命令行 | 整轮 3–4 秒；笔记里记下了设定、角色、线索和进展 |
| 600 条积压、120 张图后被叫 | 首字 23–24 秒，整轮 96–122 秒；第二问整轮 47–68 秒 | 首字 2–4 秒，整轮 12–17 秒；第二问整轮 4–7 秒 |
| 纠错与玩笑 | 正确 | 正确，玩笑查原话后才下结论 |
| 安静后整理 | 无 | 安静 1 分钟（评测设置）后跑了一轮，未在群里发言 |

评测中发现笔记会记下一次性的提问，已在写入规则里补上「别人问你的问题、一次性的安排不记」。

## 6. 进入第二阶段的条件

- 评测或真实使用中出现：笔记写满后质量下降、跨会话回忆仍依赖碰巧搜中、零命中搜索占比高；
- 届时再评估频道记忆文档、中文分词索引等方案。
