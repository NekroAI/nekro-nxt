# 能力与授权

智能体资料页的「能力」决定她除了聊天还能做什么。改完点页面底部的“保存”；风险较高的开关会先让你确认。

## 系统访问

「系统访问」分四级，越往后能做的事越多，风险也越高。新建的智能体在最低一级。

![「系统访问」的四个级别](shot:agents-abilities)

| 级别 | 能做什么 |
| --- | --- |
| 基础权限 | 只能对话，不能读写文件或运行命令 |
| 工作区读写 | 读写她自己的工作区（数据目录下的 `workspaces/<智能体>`），看不到其他智能体的工作区和 NekroNXT 的数据 |
| 运行命令 | 在工作区里运行命令；命令只能写工作区 |
| 完整访问 | 读写范围和 NekroNXT 程序本身一样，命令始终可以联网 |

「手动调整」可以单独打开或关闭每一项，组合不属于这四级时显示为自定义。

**工作区读写**这一级没有命令，她用专门的文件工具移动、复制、删除、查找、压缩解压文件。删除的内容先放进工作区的 `.trash/`，7 天后自动清理。

**运行命令**这一级，读取时 NekroNXT 的数据目录、其他智能体的工作区和你的用户主目录都被挡住，系统程序、常见语言运行时（nvm、pyenv、conda 装的 Node 和 Python）和字体照常可用。“命令联网”默认开启，关掉后命令无法访问网络。“设置 → 附加功能”里装好的程序（如 `ffmpeg`、`gh`）在命令里可以直接用。

不同系统能限制的范围不同：

- macOS 和装有 bubblewrap 的 Linux：能限制读取范围和联网；
- Docker 部署：宿主内核支持 Landlock 时能限制读取范围，但 `/tmp` 这类临时目录仍可读取，也不能断开命令的网络；
- Windows：命令用 PowerShell 运行，沙箱只限制写入，命令仍能读取工作区以外的文件和联网；git 克隆、推送和 pip、npm 安装依赖在这一级做不了，要调到完整访问。“设置 → 附加功能”里可以装“Git 与 Bash”。

界面会在对应的开关旁说明这台设备的情况。

## 关联账号和凭据

打开运行命令后，可以让她的命令以某个 GitHub 账号工作：

1. 在「设置 → 关联账号」添加账号：填 token，或用本机 `gh` 已登录的账号。建议建一个只开所需权限的专用 token；
2. 回到智能体的「能力」，在关联账号里为她选这个账号，每个平台选一个。

选好后，`gh` 可以直接用，`git` 走 https 会带上这个账号。“使用提示”（查看内容、处理 issue、处理 PR、推送代码）只是告诉她账号用来做什么，实际能做什么由 token 的权限决定。

API Key 这类密钥在「设置 → 凭据」里添加。使用方式选“允许程序读取”并填了环境变量名的凭据，会作为这个环境变量交给可用的智能体的命令。哪些智能体能用、使用前要不要先申请，都在凭据上设置。

## 编排模式（PTC）

打开运行命令后，还可以打开“编排模式（PTC）”：她把翻大量记录、批量处理文件这类多步骤的事写成一段程序一次做完，更快也更省。开启后她的所有操作都通过程序完成，运行记录里每次编排下列出程序调用过的工具。桌面版没有可用的 Node 时，开关下方可以直接下载运行环境。

## 其他开关

![「能力」里的其他开关](shot:agents-capability-switches)

- 「子对话」：把费时的事交给一个单独的对话去做，自己继续在群里聊。见[子对话](sub-conversations.md)；
- 「网页搜索」：搜索公开网页。用 DeepSeek 的搜索，需要 DeepSeek API 密钥，每次搜索另计模型费用；
- 「查阅社区文档」：有人问 NekroNXT 怎么用、遇到报错时，她会查 [nxt.nekro.ai](https://nxt.nekro.ai/docs) 上的使用文档，先用自己的话解释，再附上链接。问题会发到社区站搜索，默认开启；
- 「动态创造」：在频道里按需求给自己做新工具和页面。见[让她自己做扩展](../extensions/dynamic-creation.md)；
- 「定时任务」：群友可以请她设提醒和周期任务。见[定时任务](scheduled-tasks.md)；
- 「语音消息转文字」：收到语音时同时看到转写的文字，也能自己转写以前的语音。要先在「设置 → 附加功能」安装语音识别或配置云端识别；最多等 30 秒，转不出来时照常回应。

## 免确认提交反馈

开启「设置 → 社区反馈」后，可以请智能体搜索和起草社区反馈，默认由管理员确认后发送。“免确认提交反馈”打开后，只有管理员从客户端发出的消息触发的那一轮可以直接提交，每个实例每天最多 5 条。详见[反馈问题](../troubleshooting/report.md)。
