# 存储与清理

NekroNXT 的数据都在一个数据目录里：聊天记录、智能体配置、扩展、工作区、日志和升级前的备份。占用变大时，按下面的办法找到大头并清理。

![「设置 → 存储」](shot:ops-storage)

## 数据目录

- 桌面版：「设置 → 存储」第一行显示数据目录和占用，可以点“更改”迁移到别的磁盘，见[更改数据目录](../install/desktop.md#更改数据目录)；
- Docker：数据在你挂载的目录里，见 [Docker 部署](../install/docker.md#数据目录与升级)。

## 升级前备份

每次升级前会把整个数据目录备份一份，最多保留最近 2 份，通常是占用最大的部分。在「升级前备份」里可以：

- **保存在数据目录**（默认）；
- **保存到其他位置**：比如外置盘，填一个数据目录以外的绝对路径；
- **不备份**：省空间，但升级出问题时就无法从备份恢复。

详见[升级、备份与恢复](upgrade-backup.md)。

## 扩展下载上限

扩展一次最多能下载多大的文件，比如让智能体下载视频来看。默认 1 GB，可以调到 5 GB。

## 清理聊天记录

聊天记录按频道清理：打开频道，在右侧“危险操作”点“彻底清除”，输入频道名确认。会删除这个频道的全部消息、对话和附件，智能体也查不到了，无法恢复；频道、接线、频道说明和成员笔记保留。详见[上下文与压缩](../agents/context.md#彻底清除聊天记录)。

结束的子对话按「设置 → 子对话」里的保留时长自动清理，见[子对话](../agents/sub-conversations.md#保留多久)。

## 日志占用

日志单独保存，在「设置 → 日志保存」里设置保留时间和容量上限，超出的旧日志自动清理。见[查看运行日志](logs.md)。
