# ✨ 本次更新

扩展现在可以下载视频、音频、压缩包这类大文件，例如让智能体把一段视频下载下来看，不再被 8 MB 的限制卡住。

## 🚀 主要变化

- **扩展下载大文件**：扩展可以把网上的文件直接下载下来交给媒体处理、语音识别，或发到频道，单次默认最多 1 GB；
- **扩展下载上限**：管理员可以在「设置 → 存储 → 扩展下载上限」调整，范围是 64 MB 到 5 GB。超过上限时，报错会写明是哪一项限制、该去哪里调整。

## 🛠️ 改进与修复

- **扩展的网络请求**：读取接口和网页时，单次响应的上限从 8 MB 放宽到 32 MB；扩展直接把网上的图片或文件存成频道文件时，最多 128 MB。

## ⚠️ 升级前留意

- **用到下载功能的扩展**：需要本版本才能安装，智能体从现在起创建的扩展也是如此。
