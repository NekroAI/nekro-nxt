# 平台接入

各平台接入页的末尾都有更细的“按症状排障”：[QQ 官方机器人](../channels/qq-official.md)、[OneBot V11](../channels/onebot-11.md)、[企业微信](../channels/wecom.md)、[微信 iLink](../channels/wechat-ilink.md)。这页先帮你判断问题出在哪一段。

## 先看账号状态

打开「接线」，点这个平台账号，看「状态」：

| 状态 | 意思 |
| --- | --- |
| 正常 | 已经连上平台 |
| 正在连接 | 正在连或断线重连，持续很久就是连不上 |
| 需要处理 | 连接失败、登录失效或还没填凭据，下面会写原因和建议 |
| 已停用 | 你停用了这个账号 |

账号断开时，右上角铃铛的「需要关注」也会提醒。改地址、令牌等设置，在账号详情点「编辑连接设置」。

## 群没有出现在接线里

账号连上不等于群会自动出现。NekroNXT 要先收到这个群的消息，才知道它存在。

到群里发一条消息（QQ 官方机器人和企业微信要 @ 机器人），稍等片刻再看。还是没有：

- 确认机器人确实在这个群里；
- OneBot：协议端的消息格式要设成 array，NapCat 还要打开强制推送事件；
- QQ 官方机器人：机器人能进哪些群由 QQ 平台开放的范围决定；
- 微信 iLink 目前只支持私聊。

## 群里发了消息，频道里没有

频道里看不到群里的新消息，说明消息没进来：

1. 看账号状态是否“正常”；
2. 账号详情的「诊断」里点“测试接收”，然后到群里发一句话；
3. 看「最近消息」的时间有没有更新。

收到了消息、但智能体不回复，问题不在平台，见[群里没反应](models.md#群里没反应)。

## 收得到，发不出去

在频道里打开她这一轮的“发送频道消息”，详情里会写结果：

- **已送达频道**：平台已经收下。群里看不到时，可能被平台吞了，比如被禁言、被风控。
- **送达结果未确认**：平台没有回执。先去群里看看有没有发出来，再决定是否重发，避免重复。
- **没有发出**：详情里有失败原因，展开“诊断信息”可以看到平台返回的原文。

常见原因：

- 机器人被禁言或已经不在群里；
- QQ 官方机器人只能在收到消息后的一段时间内、有限次数地回复，一次说太多段会超出额度。需要时在账号的连接设置里打开“允许主动发送”，并确认机器人有这项权限；
- 企业微信有发送频率和文件格式限制，比如语音只支持 AMR；
- 微信 iLink 只能回复已经发过消息的私聊，只支持纯文本。

## 一直正在连接

- **OneBot**：Endpoint 的协议、端口和完整路径要和协议端配置一模一样；Access Token 两边一致；协议端和 NekroNXT 不在同一台机器或同一个容器时，协议端不能只监听 127.0.0.1。
- **QQ 官方机器人**：NekroNXT 要能访问 QQ 的接口地址，检查网络、代理和系统时间。
- **企业微信**：用的是长连接模式的 BotID 和 Secret，不是 Webhook 的 Token；同一个 BotID 只能被一个地方连接，别的程序连上后这里会显示连接冲突。

## 认证失败或登录已失效

- **QQ 官方机器人**：AppID 和 AppSecret 要属于同一个机器人。在 QQ 开放平台再次查看 AppSecret 会把它重置，旧的立即失效，要在「编辑连接设置」里重新填写。
- **企业微信**：连续三次认证失败后会停止重连，改好 BotID 和 Secret 后保存。
- **微信 iLink**：提示会话已过期时，在账号详情点“重新扫码登录”，用同一个微信号扫码，频道和接线都会保留。

## 图片、语音、文件收不到

- 图片或语音显示下载失败：OneBot 协议端要上报一个 NekroNXT 能访问到的下载地址；QQ 图片链接过期后也会失败，请对方重发；
- 微信 iLink 的图片和文件，要在账号详情打开入站媒体接收；
- 智能体看不懂图片或语音，见[模型与回复排障](models.md#看不懂图片)。

## 频道里的消息不再更新

偶尔网页和服务之间的连接断了又没察觉，新消息就不刷新。刷新页面即可。

## 还是解决不了

到[反馈问题](report.md)提交反馈，写上平台、协议端名称和版本，附上账号详情「诊断」里的信息。不要附上 Token、Secret 等凭据。
