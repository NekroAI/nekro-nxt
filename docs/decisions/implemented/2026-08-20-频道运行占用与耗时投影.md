# 频道运行占用与耗时投影

状态：implemented

## 决策

`ChannelRuntimeProjection` 分开携带当前 Episode 的上下文占用、生成表现和缓存分析，以及已关闭区间的轮次 / 步骤 / 工具耗时和本步用量。上下文来自 DSH 公开 `sessionProjections`（`contextPressure`、`contextBreakdown`）；全会话生成汇总来自 DSH `sessionStats`；最近请求、生成速度覆盖率、缓存分析和本步用量来自 Session 事件；耗时来自事件 `time`。

## 运行语义

- 占用只在同时有 `projectedTokens` 与 `contextWindow` 时出现；没有样本则省略，不投影 0/0。
- 占用是参考值，不是计费，也不作为压缩或门禁输入。组成三项是启发式，不能加总成占用。
- 缓存以模型请求为样本，统计范围固定为当前 Episode；累计聚合在工作轨迹截断到最近 24 轮之前完成，最近窗口保留 12 次模型请求。
- DSH 的 `inputTokens`、`cacheReadTokens`、`cacheWriteTokens` 是互斥输入桶。缓存读取占输入以 `cacheRead / (input + cacheRead + cacheWrite)` 计算；会话加权覆盖、逐请求平均覆盖和请求命中比例使用各自明确的分母，不互相混称。
- `cacheReadTokens` / `cacheWriteTokens` 均缺失表示模型没有报告缓存统计，不等于明确报告 0；投影保留有 usage 的请求数和有缓存统计的请求数，让界面展示数据覆盖率。
- 首 Token 使用 DSH `isTokenDelta()` 口径，只接受非空文本、思考或工具调用增量；空增量和 block 边界不计入。
- 生成速度以 Provider `outputTokens / (assistant/message.time - firstToken.time)` 计算。会话值使用总输出 Token 除以总解码时长，不对各请求速度求算术平均。
- `sessionStats` 提供全会话平均首 Token、加权生成速度、模型处理累计和工具调用累计；最近 12 次模型请求保留首 Token、解码时长和输出 Token。界面使用最近 8 次展示趋势。
- 缺少首 Token 或 Provider usage 的步骤不按 0 统计。投影分别携带首 Token 和生成速度的有效步骤数。
- `llm/retry` 提供重试次数和计划等待；取消等待没有 `llm/retry-started`，但已经发生的调度仍计入诊断。等待是策略计划值，不冒充 Provider 内部排队时间。
- 耗时只记录事件时间戳的关闭区间。进行中的步骤不写墙上时钟。
- 首 Token 耗时只在投影里出现；`assistant/chunk` 仍不进入 SSE。
- 产品界面：会话检查器按上下文、缓存、生成表现排列。上下文使用双环展示当前预计用量；缓存区展示最近一次、最近 8 次、会话加权、逐请求平均、请求命中、累计输入桶、数据覆盖和最近趋势；生成表现区展示最近请求、会话平均、会话加权速度、模型与工具累计耗时、重试等待、数据覆盖和最近趋势。相邻区块只保留一条分界线。工作轨迹状态列展示耗时，选中行才展示本步用量。不嵌 DSH 官方状态栏，不把这些数字放进消息列或对象列。

现行接线见 `docs/08-接线与Server宿主设计.md`，界面见 `docs/NekroNxt界面交互模型.md` §3.3。
