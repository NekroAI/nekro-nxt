# 频道通信工具与 DSH 子智能体工具分名

状态：implemented

## 决策

NekroNXT 面向模型的频道通信工具统一命名为 `send_channel_message`。`send_message` 保留给 DSH 官方子智能体控制工具，用于给可继续子智能体安排下一轮任务。

## 语义边界

- 所有用户可见频道消息仍只能由 `send_channel_message` 产生；
- DSH 模型原始 text/reasoning 仍只进入 Session 运行轨迹；
- `send_message` 不会产生 Outbox 或 Adapter 投递；
- 内部 `AgentCommunicationPort.sendMessage`、`ChannelRuntime.sendMessage` 和 Outbox 领域类型不进入 DSH Tool Registry，保留原名称。

## 验证

- 可控 LLM Adapter 只有调用 `send_channel_message` 才能形成频道消息；
- 频道工具不再遮蔽 DSH 全局 `send_message`；
- 工具调用 ID 仍与 Episode ID 共同构造出站幂等键。

## 参考取舍

保留 DSH 官方工具名与 NekroNXT 统一通信协议，拒绝通过深 Fork DSH、改写其子智能体语义或机械重命名内部领域接口来规避冲突。
