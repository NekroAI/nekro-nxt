# 常见问题与排障

## 安装包被系统拦截

当前 Preview 尚未签名。确认下载来自 `NekroAI/nekro-nxt` Release，并用同名 `receipt.json` 核对 SHA-256。不要从第三方链接下载带 NekroNXT 品牌的安装包。

## Desktop 一直显示正在连接或无法连接

完全退出并重新打开 Desktop。若本地 Host 在短时间内反复退出，应用会停止自动恢复；保存诊断日志，并确认数据目录可写、磁盘空间充足。

远程实例需要核对地址、证书指纹、设备配对和 Server 状态。轮换管理密钥后旧设备必须重新配对。

## 模型目录为空或智能体不可用

前往「设置 → 模型供应商」检查凭据状态并重新运行连接测试。确认智能体引用的模型仍由实时 DSH 目录提供。

## 外部频道没有出现

确认平台连接已建立，并从平台向机器人账号发送一条测试消息。接收测试和发送测试独立，单向成功不代表另一方向拥有权限。

## 智能体没有发送回复

打开工作轨迹检查模型、工具和投递结果。模型原始文字不是频道消息；只有通信工具产生的成功投递才表示已经回复。

## 扩展保存后没有生效

保存只产生本地扩展版本。前往扩展详情或智能体工作台，为需要使用它的智能体单独启用。

## 如何报告问题

普通 Bug 使用 GitHub Issues，并删除 API Key、真实聊天、账号、群标识、临时资源 URL 和本机路径。安全漏洞按根目录 `SECURITY.md` 使用私密漏洞报告。
