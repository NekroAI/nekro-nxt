# 登录与访问

没有登录的浏览器打开任何页面都会先到登录页。登录后的浏览器出现在「设置 → 登录与访问」中，可以看到每台设备的登录时间和最后活跃时间，并撤销任意设备；「退出登录」会让这台浏览器下次需要重新登录。持续使用的设备会一直保持登录。轮换管理密钥会撤销全部已登录设备。

登录后回到此前打开的实例页面；返回地址无效或指向其他网站时，回到概览。

## 登录方式

第一台设备用管理密钥登录。之后在「设置 → 登录与访问」里可以：

- **添加通行密钥**：之后在登录页用面容、指纹或设备密码登录。通行密钥只在添加时的地址上有效，需要通过 HTTPS 的域名访问，或在本机用 `localhost` 打开。
- **让新设备登录**：点「显示二维码」，用新设备的相机扫描，或在新设备的登录页选「输入登录码」，然后在这台设备上允许。
- **确认设备登录**：新设备的登录页选「扫码登录」会显示二维码和登录码。用已登录的手机扫描，或在这里点“确认设备登录”旁的“输入或扫码”，输入登录码或用相机扫码，然后允许。iPhone 主屏幕应用和 Safari 的登录状态是分开的，在主屏幕应用里用这里的“输入或扫码”。

登录码五分钟内有效，只能用一次。每次登录都要在已登录的设备上确认。

所有设备都有通行密钥或可以扫码登录后，可以关闭「用管理密钥登录」。关闭后登录页不再直接提供管理密钥，需要时从登录页的「用管理密钥找回」进入，找回后到「设置 → 登录与访问」添加通行密钥。

## 桌面版连接

在桌面版的实例菜单中添加服务端地址，核对证书指纹后用管理密钥完成配对。桌面版设备同样出现在「设置 → 登录与访问」中。
