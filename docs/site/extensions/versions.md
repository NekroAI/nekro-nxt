# 版本、分支与发布

## 版本

扩展每保存一次就是一个新版本，接在它修改的那个版本之后，编号按先后是 `v1`、`v2`……；同一个版本被改了两次、各自保存时，第二个写作 `v2·2`。从社区安装或发布到社区的版本带“社区”标记。

扩展详情的“版本”把这些版本画成一棵谱系树，标出正在使用的、有智能体在用的、发布过的版本，中间版本可以折叠或清理。点一个版本可以：

- 切换到这个版本；
- 让智能体在它的基础上修改；
- 从它创建分支；
- 发布到社区，或导出成 `.nxt-extension` 文件；
- 保留，或删除。

## 切换和回退

每台机器上一个扩展只用一个版本。切换时，所有用它的智能体一起切过去，等她们手上的回复做完再切。各自的配置在新版本里仍然有效时会保留。

切错了，在“版本”里点“回到上一个版本”，或者管理员在群里发 `/ext revert 名称`。

新版本改了数据格式时，切换会自动升级数据并先留快照；切回读不懂新数据的旧版本时，需要同时恢复一份旧格式的快照，快照之后写入的数据会丢失。

## 分支

分支是从某个版本另起的一个新扩展，可以选择复制原扩展的数据，之后两边分开修改。想保留原扩展、另做一个不同方向的版本时用分支；只是修问题或加功能，直接修改原扩展就行。

在版本上点“从这里分支”，或在扩展详情的“更多”里选“创建分支”，填名称和标识。标识只能用小写字母、数字和连字符，创建后不能改。

## 修改名称和说明

在扩展详情的“更多 → 修改扩展信息”里改名称和说明，或者让智能体改。从社区安装的扩展，更新时名称和说明会换成发布者的版本。

## 导入和导出

- 导出：在版本上点“导出”，或在“更多”里选“导出当前版本”，得到一个 `.nxt-extension` 文件；
- 导入：在「工坊」列表顶部点导入，选择文件。导入后需要手动启用。

很早期格式的扩展标为“格式不受支持”，不能启用或安装，需要更新后再用。

## 发布到社区

1. 先在「社区」的“账号”里登录社区；
2. 在扩展详情的“更多”里选“发布到社区”；
3. 填一句话简介、详细介绍（支持 Markdown）、标签、源码地址和更新说明；
4. 点“发布”。

发布后社区会自动审查源码和权限，通常几分钟内完成，审查完成前标为“风险未知”。发现泄露凭据这类必须修改的问题时，这次发布不会公开，看完审查报告修改后再发。

规则：

- 一次发布要接在上一次发布之后。社区上已经有更新的发布（比如你在另一台机器上发过）时，先更新或合并再发；
- 别人发布的扩展不能直接发新版本，先从它创建分支，再发布分支，社区上会标明分支自哪里；
- 发布、撤回、迁移数据都要管理员确认。智能体也能帮你发布，她会先写好更新说明再发申请。

## 我的发布

「社区」的“我的发布”列出你发布过的扩展和每一次发布：下载数、审查报告、重新审查、撤回。

审查报告里有审查员“小澄”给出的六项星级（安全、开放、稳定、轻量、易用、工艺）、综合评分、每一项再拿一颗星需要做什么，以及逐条建议。

撤回一次发布后，社区不再提供它，已安装的用户会看到“作者已撤回”。
