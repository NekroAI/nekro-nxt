# 设定与频道说明

决定智能体“是谁、怎么说话”的有两处：智能体自己的「设定」对她所在的每个群都有效；「频道说明」只对一个群有效，用来定这个群的规矩。

## 设定

在智能体资料页的「设定」里编辑，新建时也有同一个框。

![资料页的「设定」和「别名」](shot:agents-persona)

写什么：

- 她是谁、什么性格、和群里的人是什么关系；
- 说话的习惯：口头禅、语气、用不用表情；
- 她在群里负责什么、不做什么。

不用写的：在群里怎么发消息、回复写多长、哪些内部信息不能说，NekroNXT 已经替她安排好了。

几句她说话的例子，往往比一串形容词管用。输入 `@` 可以引用具体的群友、频道或扩展，她会准确认出是谁、是哪个。

改完点页面底部的“保存”，正在进行的对话在当前这一步结束后用上新设定。

## 别名

「别名」是群友对她的其他叫法，比如“小荧、水母”。触发方式是“智能响应”时，消息里提到名字或别名也会叫醒她。别名至少写两个字，单个字太容易误触。

## 频道说明

同一个智能体在不同的群里，可能要守不同的规矩：技术群只聊技术，闲聊群可以随意些。这些写在频道说明里，不用为每个群单独建一个智能体。

打开频道，在右侧「频道说明」点“添加”（已有内容时是“编辑”）。

![频道的说明与笔记：上面是频道说明，下面是智能体笔记](shot:agents-channel-notes)

频道说明写群规、话题范围、语气和称呼，最多 4000 字，保存后从下一条消息起生效。它只影响这个群，不改变她的设定。改过的旧版本会保留，可以恢复。

## 频道说明和智能体笔记的区别

同一个窗口下半部分是「智能体笔记」，两者用途不同：

| | 频道说明 | 智能体笔记 |
| --- | --- | --- |
| 谁写 | 管理员 | 智能体自己，你可以修改 |
| 写什么 | 你对她在这个群的要求 | 她需要长期记住的关于这个群的事 |
| 上限 | 4000 字 | 2000 字 |

想定规矩，写频道说明；想纠正她记错的事，改笔记，必要时锁定笔记不让她再改。笔记详见[记忆与笔记](memory.md)。

把群换给另一个智能体时，可以选择保留原来的频道说明。
