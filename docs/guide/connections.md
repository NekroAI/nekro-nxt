# 连接频道

平台连接、频道和智能体绑定是三个不同对象：连接表示一个已登录账号，频道表示消息事实流，绑定决定由哪个智能体按什么方式响应。

## 添加连接

1. 前往「连接」，点击添加账号；
2. 选择已安装适配器提供的平台；
3. 填写普通配置与只写凭据；
4. 保存并等待连接状态更新。

平台名称和配置字段来自适配器。产品壳不预设某个具体平台。

## 发现频道

外部平台通常需要先向机器人账号发送一条消息，NekroNXT 才能观测并持久化频道。接收测试和发送测试是独立诊断，不阻塞绑定。

## 绑定智能体

选择发现的频道，指定响应智能体和触发方式后保存。绑定更新只改变频道响应关系，不修改智能体的人设、模型或授权能力。

外部频道中的管理员发言以机器人账号发送，并标记为“管理员从客户端发出”；它进入频道事实流，但不伪装成智能体自己的发言。

## 频道隔离

每个频道拥有独立消息事实流和会话。工具执行期间到达的新消息先可靠入库，在安全间隙注入下一步思考；普通消息不会隐式停止当前工具。
