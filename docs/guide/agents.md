# 创建和管理智能体

智能体是 NekroNXT 面向用户的长期实体，不是一次请求、一个频道或平台机器人账号。

## 创建

创建页面要求名称、人设和默认模型。点击“创建智能体”后，系统原子写入：

1. 智能体身份；
2. 第一个不可变配置版本；
3. 一个可以立即使用的内置频道；
4. 该频道到智能体的默认绑定。

提交失败不会留下半创建对象。

## 人设与模型

人设描述身份、表达方式和工作边界。编辑后点击“保存新配置”产生新版本，不直接覆盖运行中的现场。平台用户、频道和扩展可以作为稳定引用插入人设，但引用不会扩大权限。

## 授权能力

权限按“基础权限（Lv.0）→ 文件读写（Lv.1）→ 运行命令（Lv.2）→ 完整访问（Lv.3）”组织。动态创造、子智能体和网页搜索是独立能力；开启创造不会自动获得 Shell 或完整文件访问。

文件和命令能力默认关闭。授权前确认 Server 进程能够读取和修改的真实范围。

## 频道与扩展

一个智能体可以绑定多个频道；每个频道同一时间只由一个智能体响应。扩展也按智能体独立启用，保存扩展不会自动为创建它的智能体启用。
