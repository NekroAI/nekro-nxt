# ✨ 本次更新

本次更新新增 OneBot 11 连接，让智能体可以参与已有的 QQ 群聊和私聊。外部频道现在支持处理中提示、特殊事件触发和更多平台互动，同时修复了 Windows 桌面版启动和凭据保存问题。

## 🚀 主要变化

- **OneBot 11 连接**：可以把独立运行的 SnowLuma、NapCat 或 LLBot 接入 NekroNXT，让智能体参与 QQ 群聊和私聊。支持文字、提及（Mention）、引用、图片、语音、合并转发和常见富消息，连接页面提供账号状态和收发测试；
- **频道处理中提示**：外部群聊可以在智能体处理消息时显示临时回应，并在处理完成后移除。每个频道都可以单独开关；
- **特殊事件与平台互动**：频道可以选择由哪些特殊事件触发智能体，包括戳一戳、成员进退、消息撤回、消息回应和文件上传。平台支持时，智能体还可以撤回自己发送的消息，或戳一戳频道中的成员。

## 🛠️ 改进与修复

- **Windows 桌面版启动**：修复安装包缺少部分内置服务依赖，导致打开 NekroNXT 后服务无法启动的问题；
- **Windows 平台连接**：修复保存 Client Secret 时出现 `EPERM`，导致 QQ 官方机器人等需要凭据的平台连接无法添加的问题；
- **平台连接页面**：页面会根据所选平台显示对应的账号信息、连接状态和收发测试，不再出现与当前平台无关的 QQ 官方机器人字段；
- **桌面安装包验证**：发布前增加内置服务启动和凭据保存检查，减少安装后才发现服务无法启动或平台凭据无法保存的情况。

## ⚠️ 使用前留意

- **OneBot 11 接入要求**：使用前需要独立部署并登录 SnowLuma、NapCat 或 LLBot，开启正向 Universal WebSocket Server，并把消息格式设为数组。反向 WebSocket、HTTP API + Webhook、CQ 字符串消息和 raw Action 暂不可用。
