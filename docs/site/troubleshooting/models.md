# 模型与回复

查看系统或插件的运行过程，从导航底部打开「日志」，或从对应对象详情进入。操作与保存规则见[查看运行日志](../ops/logs.md)。

## 模型目录为空或智能体不可用

前往「设置 → 模型」检查凭据状态并重新运行连接测试。确认智能体引用的模型仍由实时 DSH 目录提供。

## 智能体没有发送回复

在频道顶部打开“透视”，检查模型、工具和投递结果。模型原始文字不是频道消息；只有通信工具产生的成功投递才表示已经回复。
