# DSH 插件

NekroNXT 的智能体运行在 DSH（DeepSeek Harness）上。DSH 有自己的插件，比如 DeepSeek 网页搜索、各家模型供应商的接入。「设置 → DSH 插件」列出内置的和你装的插件，大多数人不需要动这里。

![「设置 → DSH 插件」](shot:extensions-dsh)

## 安装

点「安装插件」，可以：

- 填 npm 包名和版本，比如 `@scope/plugin@1.2.3`，点“检查安装内容”；
- 或者选择一个安装包（npm 的 tgz，或 DSH 的 `.nxt-extension` 文件）。

检查结果会列出包名、版本和入口数。依赖需要运行安装脚本时，会逐个请你批准；不批准就跳过脚本安装。确认后点“安装（不启用）”。

检查配置和启用入口时会运行插件的代码，只安装可信来源的插件。

## 启用

插件装好后默认关闭。一个插件可以有多个入口，每个入口单独选择：在本机启用，或只给某个智能体启用。

插件有配置时直接在设置里填；层级多的配置可以切到“原始 JSON”编辑。密钥字段只能覆盖、不能查看。DSH 插件自带的网页界面不能在 NekroNXT 里用，其他功能照常。

## 状态

| 状态 | 意思 |
| --- | --- |
| 已启用 | 正在使用 |
| 加载失败 | 插件出错，点开看原因，或到「日志」里查 |
| 缺少服务 | 插件需要只对官方插件开放的服务，例如 agents、sessions；非官方插件拿不到 |
| 等待服务 | 依赖的服务由别的插件提供，对方启用后会自动加载 |

从 npm 安装、版本与当前 DSH 一致的 `@deepseek-ai/` 插件是官方插件，详情里标“官方插件”。上传的 tgz 即使同名也按其他插件处理。

## 关闭和移除

有的插件会在对话里留下只有它能读懂的内容。只要还有对话含有这些内容，这个插件就不能关闭或移除，否则这些对话将无法恢复。

不兼容的插件会被隔离，不会拖垮 NekroNXT 的其他功能。
