# 快速开始

这条路径适合第一次体验 NekroNXT。个人电脑优先使用桌面版；需要长期运行或从多台电脑管理时再部署服务端。

## 1. 安装

- 桌面版：从[预览版下载页](https://github.com/NekroAI/nekro-nxt/releases/tag/preview)选择 macOS、Windows 或 Linux 安装包，步骤见[桌面版安装](desktop.md)；
- 服务端：复制[服务端部署](server.md)中的 `docker run` 命令，替换管理密钥与持久化目录后运行。

## 2. 配置模型

打开「设置 → 模型供应商」，选择供应商，填写 API Key 和必要的连接参数，然后运行连接测试。保存后即可为智能体选择可用模型。

详细说明见[配置模型](models.md)。

## 3. 创建智能体

前往「工作」，点击对象列中的 `+`：

1. 输入智能体名称；
2. 描述人设、表达方式和工作边界；
3. 选择已配置的模型；
4. 核对授权能力，默认不要开启文件、命令和完整访问；
5. 点击“创建智能体”。

创建会同时产生第一个配置版本、一个内置频道以及频道绑定。

## 4. 发送第一条消息

打开自动创建的内置频道，从底部输入框发送消息。智能体自己的可见回复通过通信工具产生；工作轨迹可以查看思考与工具执行过程，但模型原始文字不会自动发到频道。

## 5. 连接即时通信平台与群聊

前往「连接」，选择已安装的即时通信平台适配器、添加账号并完成认证。向该账号发送一条测试消息后，选择发现的群聊或频道，再绑定智能体和触发方式。

同一个智能体可以绑定多个群聊。每个群聊保留独立上下文；群成员在智能体使用工具期间发送的新消息也会被收录，并进入下一步思考。

详见[连接频道](connections.md)。

## 6. 可选：创造扩展

为指定智能体开启动态创造权限，再从智能体或扩展入口打开创造工作台。动态运行、验证、保存为本地扩展和为智能体启用是四个独立动作。

详见[使用扩展](extensions.md)。遇到问题时进入[常见问题与排障](troubleshooting.md)。
