# 连接频道

NekroNXT 通过适配器连接不同即时通信平台。每个适配器都复用同一条用户路径：登录账号、发现群聊或频道、选择智能体和触发方式。

## 添加连接

1. 前往「连接」，点击添加账号；
2. 选择已安装适配器提供的即时通信平台；
3. 填写普通配置与只写凭据；
4. 保存并等待连接状态更新。

平台名称、登录方式和配置字段来自适配器。新增平台不需要改变智能体、频道和绑定的使用方式。

## 发现频道

外部平台通常需要先向机器人账号发送一条消息，NekroNXT 才能发现并记录对应群聊或频道。接收测试和发送测试是独立诊断，不阻塞绑定。

## 绑定智能体

选择发现的群聊或频道，指定响应智能体和触发方式后保存。一个智能体可以绑定多个频道；一个频道同一时间只由一个智能体响应。绑定更新只改变频道响应关系，不修改智能体的人设、模型或授权能力。

外部频道中的管理员发言以机器人账号发送，并标记为“管理员从客户端发出”；它进入频道事实流，但不伪装成智能体自己的发言。

## 频道隔离

每个群聊或频道拥有独立的消息记录和会话上下文。群成员可以连续发言、补充条件或通过提及触发智能体。工具执行期间到达的新消息先可靠记录，在合适的时机进入下一步思考；不同群聊的短期上下文不会混在一起。
