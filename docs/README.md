# NekroNxt 文档索引

现行文档只描述当前为真的规则。过程、立项快照和否决记录在 `archive/`，默认不读。代码与现行文档必须同一改动一起维护，规则见根 `AGENTS.md` §9 与 `06` §1.1。

6. `05-桌面UI与动效规范.md`：青蓝主题、桌面布局、组件状态和基础动效；
7. `06-开发与测试规范.md`：代码边界、生命周期、测试、本地开发服务、迁移和文档写作；

## 按需

- `07`：只有新架构或引入外部项目时阅读；
- `decisions/accepted/`：已确认、尚未完全落地（Desktop 栈、Client 迁移、DSH 插件安装、QQ 真机协议细节）；
- 包 README：该包的当前职责和消费者。

## 归档

`archive/` 是冻结历史，不是现行权威。需要追溯立项原文或一次否决时再打开。

冲突按以下顺序处理：用户最新明确决定 → 现行 accepted/implemented Decision → `AGENTS.md` → 编号协议 → 包 README。发现冲突时修正失真的副本或改为链接，不保留两份独立长描述。
