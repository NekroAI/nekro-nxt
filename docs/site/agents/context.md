# 上下文与压缩

上下文是智能体眼下这段对话记得的内容：设定、规则、工具说明，加上最近的聊天。聊得越久上下文越大，回复越慢、越贵。

## 看看她现在记得多少

打开频道，右侧「记忆」里的「当前会话」显示上下文占用了模型窗口的多少，按系统、工具、对话分开。

点「查看」能看到模型实际收到的内容：用的哪个模型、上下文窗口多大、系统提示词由哪些部分组成，以及她这一轮能用的工具。回复不对劲时，先看看她到底收到了什么。

![「查看」打开的上下文详情](shot:agents-context-view)

## 压缩

压缩把较早的对话整理成一段摘要，腾出空间，最近的对话保持原样。

- **自动**：占用到智能体的「压缩阈值」（默认 80%）时自动压缩，阈值在资料页的「模型」里调，见[选模型与控制花费](../models/choosing.md#压缩对话太长时怎么办)；
- **手动**：点「当前会话」上的「压缩」。她当前在做的事会停下，压缩在后台进行，完成后接着聊；
- **聊天命令**：管理员在群里发 `/compact`，效果和手动压缩一样。

想临时调整这段对话的压缩阈值，可以发 `/threshold 40%`（可写 `max`、`min`，发 `/threshold reset` 恢复）。这只影响当前这段对话，下次压缩或开新会话后恢复。

## 清空上下文

她明显糊涂了、反复出错，或者想换个话题从头开始时，在频道右侧的「危险操作」里点「清空上下文」旁的“清空”。她当前的任务会停下，从空白开始；聊天记录和笔记都还在，需要时她会去翻。

管理员在群里发 `/reset` 效果相同。

![「危险操作」：清空上下文、彻底清除和删除频道](shot:agents-danger)

## 彻底清除聊天记录

「彻底清除」删除这个频道的全部聊天记录、对话和附件，她也查不到了，无法恢复。要输入频道名确认。

会保留：频道本身和接线、频道说明、成员笔记、扩展数据。

只想让她忘掉某个人，用成员笔记的“忘掉”，见[记忆与笔记](memory.md#成员笔记)。

## 删除频道

「删除频道」把频道从列表里移除，聊天记录保留。要连记录一起删，先彻底清除再删除。
