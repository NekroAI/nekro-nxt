# 模型与回复

## 群里没反应

先分清是“她没被叫醒”，还是“叫醒了但失败了”。跟着下面的问题一步步排查：

```nxt:wizard
id: troubleshoot-no-reply
title: 群里没反应
steps:
  - id: bell
    ask: 右上角铃铛的「需要关注」里，有这个智能体的提醒吗？
    choices:
      - label: 有
        next: alert
      - label: 没有
        next: trigger
  - id: alert
    ask: 提醒里写的是什么？
    choices:

      - label: 本轮失败或回复失败
        next: turn-failed
  - id: trigger

      - label: 仅观察

      - label: 被提及时
        next: mentioned
      - label: 其他
        next: paused
  - id: mentioned
    ask: 群友是真的 @ 了她，或者回复了她的消息吗？
    choices:
      - label: 是
        next: paused
      - label: 不是
        next: not-mentioned
  - id: paused
    ask: 频道右侧的「暂停回应」开着吗？

      - label: 开着

  - id: inspect

      - label: 找得到

  - id: turn-failed

    answer: “被提及时”只在有人 @ 她或回复她时开口。直接 @ 她试试；想让她更主动，改成“智能响应”。
```

## 模型不可用

智能体用的模型已经不在供应商的模型列表里了，比如供应商被删除、模型被移出列表、密钥失效。

打开这个智能体，在「模型」里换一个可用的模型；或者到「设置 → 模型」检查供应商，把模型加回列表、重新测试连接。

## 回复失败

失败的那一轮下方会显示原因，并有“压缩上下文”“清空上下文”两个按钮。

| 原因里写着 | 怎么办 |
| --- | --- |
| 认证失败，请更新 API 密钥 | 密钥错了或过期了，到「设置 → 模型」重新填写 |
| 额度不足或订阅限制 | 去供应商那里充值；也可以配[备用模型](#额度用完或经常限流)自动顶上 |
| 供应商限流 | 稍等再试；经常出现就配备用模型 |
| 超出了输出长度上限 | 这一轮要说的太长了，让她分几次说，或换输出上限更大的模型 |
| 上下文超出模型上限 | 点“压缩上下文”；还不行就“清空上下文” |

连续失败两轮以上时，通常“清空上下文”就能恢复。清空只是让她从头开始想，聊天记录和笔记都还在。

更底层的原因（比如连不上供应商的地址）在导航底部的「日志」里，搜智能体或模型名即可。

## 回复很慢

常见原因：

- **上下文太大。** 和她聊得越久，每一步要处理的内容越多。打开频道右侧的「记忆」点“压缩”，或者在智能体的「模型」里把“压缩阈值”调低一些，让她更早自动压缩。
- **一件事做得太久。** 查资料、写扩展这类费时的事，打开「能力」里的“子对话”，让她交给子对话去做，群里的对话不用一直等着。
- **新消息要排队。** 她正在处理的这一步结束后，才会看到新来的消息，所以刚发的消息常常要等一会儿。
- **模型本身慢。** 换一个更快的模型，或把“思考强度”调低。

## 测试连接失败

在「设置 → 模型」打开供应商，点失败原因旁边的图标看原文：

- 认证失败：API 密钥填错、过期，或者没填；
- 额度不足：余额或套餐用完了；
- 限流：请求太频繁，稍后再试；
- 其他错误：多半是接口地址不对。兼容 OpenAI 的中转服务地址一般以 `/v1` 结尾，以服务方的说明为准。

测试连接只发一句简单的话。测试通过但真正聊天时报 400 的，可能是中转服务不支持工具调用，换一个服务或协议试试，并把日志里的原文[反馈给我们](report.md)。

## 加了模型却没出现

在供应商页点“获取可用模型”之后，勾选只是选中，还要点“加入所选”，再点“保存供应商”。

想让扩展也能用这家的模型，要打开“允许智能体主动在扩展配置中使用此供应商模型”。

## 额度用完或经常限流

给智能体配备用模型：在智能体的「模型」里添加“备用模型”，最多三个，按顺序使用。主模型额度用完时立刻切换；限流、出错、超时时先重试几次再切换。频道顶部会显示正在使用备用模型，过一段时间再自动换回主模型。

密钥错误、上下文超限、参数错误不会切换，因为换了也一样失败。

## 看不懂图片

智能体的主模型不支持图片时，「需要关注」里会提示群里的图片会被跳过。给她换一个支持视觉的模型（模型选择里标着“支持视觉”）即可。

单次图片太多时，超出模型上限的图片会被省略，需要时请群友重发。

## 语音转文字失败

在智能体的「能力」里打开“语音消息转文字”，并在「设置 → 附加功能」安装本地语音识别或选择云端供应商。转写失败时，她会看到失败原因，比如模型还没安装、云端供应商密钥失效。

## 还是解决不了

到[反馈问题](report.md)提交反馈，附上「透视」里失败那一轮的信息和「日志」里的相关记录。
