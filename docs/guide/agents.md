# 创建和管理智能体

智能体是在频道里和大家聊天、帮大家做事的角色。一个智能体可以同时在多个频道里工作。

## 创建

在「智能体」点击列表顶部的 `+`，填写名称、设定和模型后创建。新智能体自带一个内置频道，创建后直接进入，可以马上开始聊天。

## 设定与模型

设定写它是谁、什么性格、怎么说话、和群里的人是什么关系。在群里怎么发消息、回复写多长、哪些内部信息不能说，这些通用规矩 NekroNXT 已经替它安排好了，设定里不用再写。几段它说话的例子往往比形容词管用。

可以在设定里插入具体的人、频道或扩展，智能体会准确认出这些对象。

改完点“保存”。正在进行的对话会在当前这一步结束后用上新设定。想回到以前的样子，用“更多 → 恢复之前的配置”。

## 能力

能力分四级：基础权限、工作区读写、运行命令、完整访问，越往后能做的事越多，风险也越高。文件和命令默认关闭。

- **工作区读写**：智能体只读写自己的工作区（数据目录下的 `workspaces/<智能体>`），看不到其他智能体的工作区和 NekroNXT 的数据。
- **运行命令**：命令同样只能写工作区；读取时，NekroNXT 的数据目录、其他智能体的工作区和你的用户主目录都被挡住，系统程序、常见语言运行时（如 nvm、pyenv、conda 装的 Node 与 Python）和字体仍可使用。“命令联网”默认开启，关掉后命令和编排程序都无法访问网络。
- **完整访问**：读写范围与 NekroNXT 程序本身相同，命令始终可以联网。

不同系统能限制的范围不同：macOS 和装有 bubblewrap 的 Linux 都能限制读取范围和联网；Docker 部署在宿主内核支持 Landlock 时能限制读取范围，但系统临时目录（如 `/tmp`）中的文件仍可读取，也不能断开命令的网络；Windows 只能限制写入，命令仍能读取工作区以外的文件，也始终可以联网。界面会在对应的开关处说明。

动态创造、子智能体、网页搜索和定时任务可以分别打开。开启运行命令后，还可以打开“编排模式（PTC）”：智能体把翻大量记录、批量处理文件这类多步骤的事写成一段程序一次做完；开启后智能体的所有操作都通过程序完成，运行记录里每次编排执行下列出程序调用过的工具。桌面版没有可用的 Node 时，可以在开关下方直接下载运行环境。

## 频道与扩展

一个频道同一时间只由一个智能体回复。扩展按智能体分别启用：保存好的扩展要为需要它的智能体启用后才能用。

## 它怎么记事

智能体在每个频道里记两种笔记：群笔记记群里的规矩、固定的活动和群里的梗；成员笔记记某一个人希望怎么被称呼、在做什么、有什么喜好。成员笔记会在这个人找它说话时一起出现，所以群里人再多，它也能认出回来的人。笔记由它自己写，频道一段时间没有新消息后，它会自动整理一遍。在频道详情的「记忆」里可以查看、修改或锁定笔记，也可以让它忘掉某个人。

笔记里没有的事，它会去翻这个群的聊天记录：有人问起之前说过的话，它会先查原话再回答。

很久没被叫到时，积压的消息不会一股脑交给它。在频道详情的「上下文」里可以设置未读消息读取上限、未读图片查看上限，以及多久没有新消息后自动整理笔记。跑团、记录类的群可以调高读取上限；表情包多的群少看几张图，回复会更快。
