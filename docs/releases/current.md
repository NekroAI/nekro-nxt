# ✨ 本次更新

本次更新修复 Windows 桌面版安装后无法启动及无法添加平台连接的问题，并加强桌面安装包的启动与凭据保存验证。

## 🛠️ 改进与修复

- **Windows 桌面版启动**：修复安装包复制 Server 运行依赖后，部分间接依赖无法解析，导致 NekroNXT 在 Host 就绪前退出的问题；
- **Windows 平台连接**：修复保存 Client Secret 时对目录调用 Windows 不支持的权限操作，导致添加 QQ 官方机器人等需要凭据的平台连接失败的问题；
- **桌面安装包验证**：各平台构建安装包前会从最终打包目录启动内置 Server，并真实保存一条临时凭据，确认服务就绪且凭据可持久化后才继续发布。
