# 从社区安装

「社区」是 NekroNXT 的扩展市场，扩展由社区作者发布，每次发布都经过自动审查。浏览和安装不需要登录。

## 找扩展

在「社区」的“发现”里：

![社区的“发现”页](media:community-discover)

- 按类别看：智能体能力、页面、平台适配；
- 搜索名称、介绍或标签；
- 打开“只看官方”，只列出 NekroNXT 团队维护的官方扩展；
- 按最近更新、综合评分、下载最多或最新上架排序。

卡片上的标记：

- **已审查**、**待复审**、**有风险**：自动审查的结论；
- 星级：审查员“小澄”给出的综合评分，是安全、开放、稳定、轻量、易用、工艺六项的平均分；
- **已安装**、**可更新**：这台机器上的情况；
- **需更新 NekroNXT**：这个扩展要求更新的 NekroNXT 才能装。

## 装之前看什么

点开一个扩展，先看三样：

1. **需要的权限**：分“本机权限”和“智能体权限”两层，每项标着常规、需留意或高风险；
2. **审查评级**：六项评分和审查发现。审查只描述它发现的问题，不做安全担保；
3. **更新说明**和发布者。

审查还没完成的发布标为“风险未知”，审查发现安全问题时页面会提醒先看审查记录。只安装你信任的作者的扩展。

## 安装

1. 点“安装”。NekroNXT 会下载并校验，然后弹出导入确认，写明来源、审查结论和申请的权限；
2. 点“导入”。导入后不会自动启用；
3. 按需要启用：给智能体用的工具，在扩展详情的“智能体”里为某个智能体打开，或者在智能体资料页的“扩展”里打开；带页面或平台的扩展，在扩展详情里“安装”到本机。启用时会请你批准它申请的权限。

扩展需要配置（比如 API Key）时，在扩展详情的“配置”里填写，见[扩展是什么](overview.md#配置)。

## 让智能体帮你找

智能体也能在社区里搜索扩展，查看发布、权限和审查结论。她想装某个扩展时，会在频道里发出申请，写明扩展、发布号、权限、审查结论和理由，管理员同意后才安装。

## 更新

「工坊」的扩展库里有“社区更新”，列出从社区装来的和你发布过的扩展，以及它们和社区最新发布的关系：

| 状态 | 意思 |
| --- | --- |
| 已是最新 | 和社区最新发布一致 |
| 社区有更新 | 可以点“更新”，作为新版本导入并切换过去 |
| 本机有修改 | 你在本机改过，社区没有新发布 |
| 两边都有修改 | 可以让智能体把社区的改动合进本机版本，或者保留本机、改用社区版本 |

扩展详情的标题下也有“检查更新”按钮，社区有新版时旁边出现“更新到 #N”，可以直接更新。打开扩展详情或“社区更新”时，距上次检查超过 1 小时会自动再查一次；后台每 6 小时检查一次。

更新会让所有在用这个扩展的智能体一起切到新版本，有新权限时要你同意。切错了可以在扩展详情里回到上一个版本。

## 社区账号

发布扩展、查看自己发布的审查报告才需要登录。在「社区」的“账号”里点“登录社区”，在浏览器里完成授权。退出登录不影响已安装的扩展。

## 遇到扩展的问题

在「社区」的“反馈”里新建反馈，或在社区网站的扩展页选“反馈问题”。详见[反馈问题](../troubleshooting/report.md)。
