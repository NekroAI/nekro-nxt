# 统一使用通信工具发送用户可见消息

状态：implemented

智能体自己的用户可见发言必须调用 `send_channel_message`。网页与外部平台同一规则。模型原始 `text`/`reasoning` 只进入内部运行轨迹，不自动投递。管理员可通过网页以机器人账号向外部频道发言，走 Adapter 出站并注入系统事实，不记为模型工具发送。

文字、Mention、图片、文件和音频使用有序 `MessagePart[]`。详细契约以 `docs/03-消息内容与投递协议.md` 为唯一事实源；工具名分界见 `docs/decisions/implemented/2026-08-18-频道通信工具与DSH子智能体工具分名.md`。
