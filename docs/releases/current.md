# ✨ 本次更新

这一版让智能体在群里更像一个群友：说话不再像在上班汇报，记得住群里的人和事，很久没被叫到也不会卡上几分钟。扩展统一成一种形态，一个扩展可以同时提供智能体能力、页面和平台适配；OneBot 11 连接可以发文件了。

## 🚀 主要变化

- **记忆**：智能体在每个频道里记两种笔记：群笔记记群规、固定活动和群里的梗，成员笔记记某个人希望怎么被称呼、在做什么、有什么喜好。有人找它说话时，关于这个人的笔记会一起出现，群里人再多也能认出回来的人。有人问起以前的事，它会先翻聊天记录查原话再回答。群里安静一段时间后，它会自己整理一遍笔记；
- **频道详情的「记忆」**：可以查看和修改群笔记与成员笔记、锁定笔记、让它忘掉某个人，也能看到它最近查过什么、记了什么。这里还能调整很久没被叫到时一次读入多少未读消息、直接看几张图片，以及群里安静多久后整理笔记；
- **说话方式**：重写了给智能体的说明。群聊里它一两句话接话，不用标题和加粗，有人等它回复时不会默默结束；
- **频道说明**：在频道详情给智能体写只在这个频道生效的要求，例如群规、语气和称呼，不改动它的人设；
- **认出自己和本机其他智能体**：智能体能分清哪个账号是自己、哪些是本机其他智能体，同一个群里的本机智能体默认不会互相接话，需要时可以在频道详情打开；
- **扩展形态统一**：一个扩展可以同时提供智能体能力、页面、平台适配和 MCP 服务，扩展页面可以放进左侧导航轨。社区按扩展提供的能力分类，扩展详情改为小澄的评级卡，市场支持多种排序；
- **OneBot 11 发文件**：智能体可以在群聊和私聊里发送文件，单个文件最大 64 MB，协议端和 NekroNXT 不必在同一台机器上。扩展还可以使用表情回应、合并转发、群公告、群打卡和群管理等平台操作；
- **生成的文件直接发送**：智能体在工作区里生成的图片和文件可以直接发到群里，发送前可以先看一眼，建错的可以删掉；
- **透视与检查器**：透视会列出每一轮进入模型的消息，并标出触发这一轮的成员；频道详情可以查看智能体实际收到的系统说明、工具和所用模型；
- **版本与更新提醒**：界面底部显示当前版本，有新版本时变成提醒，点击查看更新内容；预览版只提醒新的预览版。「设置 → 关于」可以手动检查，也可以关闭自动检查；
- **服务端镜像**：服务端镜像同时发布到 Docker Hub，国内网络拉取 ghcr.io 困难时可以改用，地址见服务端部署说明。

## 🛠️ 改进与修复

- **响应速度**：很久没被叫到的群，不再把全部积压消息和图片一次交给智能体；同一张图片不再在每一步重新上传。积压多、图片多的群响应快了很多；
- **回应与戳一戳**：只在有人回应机器人发的消息、戳机器人时才触发智能体，群友之间的互动只记入频道；机器人自己贴表情、戳人、撤回不再引发反复触发；
- **时间**：智能体看到的消息时间统一带时区，成员说「下午三点」时按服务端所在时区理解；
- **扩展**：编辑扩展配置时，填到一半的内容不再被后台刷新清掉；启用或停用扩展不再打断正在进行的对话；扩展的保存记录统一称为版本；
- **界面**：悬浮的连接提示不再与下方内容叠在一起；界面上的说明和报错改为直接说对象、动作和结果，内部错误另行记录，不再直接显示给用户。

## ⚠️ 升级前留意

- **旧格式的扩展**：扩展格式在这一版更新，0.3.0 时安装的扩展如果没有更新，会显示「格式不受支持」，不能启用。官方扩展已经更新，到「社区 → 已安装」更新即可；自己创造的扩展需要让智能体按新格式重新创造；
- **社区**：社区已经切换到新的扩展格式，旧版本的 NekroNXT 无法再从社区安装扩展，请升级后使用；
- **服务端时区**：服务端用 `TZ` 环境变量设置时区，不设置时按 UTC 理解成员说的时间，请设为成员实际所在的时区；
- **智能体会自己记笔记**：笔记默认由智能体维护。不希望它在某个频道记笔记时，在频道详情的「记忆」里锁定笔记。
