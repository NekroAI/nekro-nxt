# NekroNxt 工作台布局原型

离线交互原型，用来确认外壳几何：图标轨、对象列、画布、检查器。不连接 Host，不写入真实配置。

旧的五项后台导航原型已被这份覆盖。

## 打开

```bash
pnpm prototype
```

然后访问 `http://127.0.0.1:4173/`。也可以直接打开 `index.html`。

## 看什么

顶部「场景」切换七个目标状态，也可以用左侧图标轨自己点：

1. **工作 · 频道会话**：默认。树是智能体和频道；中间只有消息；右侧是运行轨迹和就地改触发。
2. **工作 · 智能体工作台**：点树里的「浅枫」。人设、能力、扩展在同一画布滚动，不再是四个一级 Tab。
3. **连接**：对象列换成账号；画布里测收发并绑定，不跳走。
4. **扩展**：启用/停用仍是独立动作。
5. **设置**：模型 / DSH 扩展 / 外观。
6. **创造**：从工作台进去，不占图标轨。
7. **空态**：创建向导。

树在切频道和工作台时保持，不会整页卸掉。检查器可收起。右上可切深色。
