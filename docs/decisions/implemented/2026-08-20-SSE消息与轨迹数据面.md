# SSE 消息与轨迹数据面

状态：implemented

## 决策

`GET /api/events` 是消息和工作轨迹的实时数据面。帧里直接携带与 REST 相同的投影；`listMessages` / `getRuntime` 只用于首载、翻页和重连对账。

## 运行语义

- 仍是一条全局 SSE。`channel-fact` 带消息批和每频道 `revision`；`runtime` 带裁剪后的 `ChannelRuntimeProjection` 和每频道 `revision`。
- 可回放帧写 SSE `id:`。Host 用内存环形缓冲响应 `Last-Event-ID`；缓冲过期则 `status.replay = expired`，前端按频道 REST 对账。
- 不另建持久通用事件日志。频道 Event Log 和当前 Session 投影仍是权威。
- 不做按字节切帧。轨迹超约 48KB 时发 `truncated` 并回退 REST。
- 不广播 DSH `assistant/chunk`。用户可见气泡仍只来自通信工具事实。

现行接线见 `docs/08-接线与Server宿主设计.md`。

## 验证

- Server：入站后 SSE 帧含完整消息；`Last-Event-ID` 能补发窗口内帧。
- Web Host：已加载频道收到 fact / runtime 不再回拉 latest 或整份轨迹；`replay=expired` 时对账。
