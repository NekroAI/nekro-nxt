# 安全策略

## 私密报告漏洞

请使用 GitHub Security Advisories 的 [Report a vulnerability](https://github.com/NekroAI/nekro-nxt/security/advisories/new) 提交安全问题。

不要为漏洞创建公开 Issue、Discussion 或 Pull Request，也不要在报告中附带真实聊天、生产凭据或不必要的个人数据。

报告应包含：

- 受影响的 NekroNXT 版本、Release ID 或 commit；
- 桌面版或服务端、操作系统和部署方式；
- 最小复现步骤与预期影响；
- 已采取的临时缓解措施；
- 可以安全共享的日志、截图或合成测试数据。

## 支持范围

当前优先处理最新预览版、最新稳定版（发布后）以及仍由项目明确支持的版本。私有依赖、第三方 Fork、修改后的品牌发行和未经支持的部署环境可能需要先在未修改版本上复现。

维护者会先确认收到报告，再评估影响、修复和披露方式。仓库公开时启用 GitHub Private Vulnerability Reporting；在该功能启用前，项目不会宣称已经提供公开安全接收渠道。
