# 触发与回复节奏

一个群交给智能体以后，她什么时候开口由频道右侧「谁来回复」里的设置决定。打开频道就能看到。

![频道右侧的「谁来回复」：智能体、何时回复、暂停回应](shot:channels-who)

## 何时回复

「何时回复」决定哪些消息会叫醒她，选完立刻生效：

![五种触发方式](shot:channels-triggers)

| 触发方式 | 什么时候叫醒她 | 适合 |
| --- | --- | --- |
| 被提及时 | 有人 @ 她或回复她的消息 | 大多数群，群聊默认 |
| 智能响应 | 除了 @ 和回复，有人提到她的名字或别名、刚和她聊过的人接着说时也会叫醒她，她可以选择不回 | 想让她像群里的一员；花费更高 |
| 每条消息 | 每条消息都交给她 | 私聊、内置频道（默认）、人少的小群 |
| 平台命令事件 | 平台上报原生命令事件时 | 平台自带命令的机器人，一般用不到 |
| 仅观察 | 只记录，不回复 | 想让她长期旁听 |

同一段群聊，换一种触发方式，她回的消息就不一样：

```nxt:chat
id: response-trigger-modes
title: 同一段群聊，三种触发方式
agent: 小荧
modes:
  - id: mention
    label: 被提及时
    note: 只有 @ 她或回复她的消息时才叫醒她
  - id: smart
    label: 智能响应
    note: 提到她的名字、刚和她聊过的人接着说，也会叫醒她
  - id: every
    label: 每条消息
    note: 每条消息都交给她
messages:
  - from: 阿青
    text: 周末有人去爬山吗
    reply:
      every: 我去不了，不过可以帮你们看看天气。
  - from: 小林
    text: '@小荧 周六山上会下雨吗'
    reply:
      mention: 周六多云转晴，下午山顶风大，带件外套就行。
      smart: mention
      every: mention
  - from: 小林
    text: 好，那我去
    reply:
      smart: 那记得早点出发，下午风会更大。
      every: smart
  - from: 木木
    text: 小荧要是能去就好了
    reply:
      smart: 我在群里等你们的照片。
      every: smart
  - from: 阿青
    text: 我先睡了，晚安
    reply:
      every: 晚安～
```

“智能响应”靠名字认出别人在叫她，在智能体的「设定」里填好「别名」，见[设定与频道说明](../agents/persona.md#别名)。

## 回复细节

展开「回复细节」可以微调节奏：

![展开「回复细节」](shot:channels-timing)

- **等对方说完**：对方话没说完时她先不回，等对方停下再一起回复。“每次最多等”默认 60 秒，“一共最多等”默认 120 秒，到点一定回复；
- **提到名字时**、**接着说时**：只在智能响应下出现，分别控制提到她的名字、刚聊过的人接着说时是否叫醒她；
- **合并连发**：同一个人连发好几条时，等他安静几秒再一起看，默认 3 秒；
- **每分钟最多叫醒**：限制因提到名字、接着说而被叫醒的次数，被 @ 或回复不受限；
- **处理中反馈**：她处理消息期间，给触发的那条消息加个临时回应，处理完自动移除。只有支持的平台和群聊才有这一项，目前是 OneBot V11 群聊（表情回应）和企业微信群聊；
- **特殊事件**：戳一戳这类平台事件要不要叫醒她，默认跟随账号的设置。

改过的参数可以一键“恢复默认”。

她准备等待时，如果你关闭了等待、暂停回应或换了负责的智能体，这一轮会直接结束，不再安排等待后的唤醒。后台轨迹会显示结束原因。

## 暂停回应

想让她临时安静一会儿，打开「暂停回应」，或者在群里发 `/pause`。暂停期间消息、平台事件、定时任务和扩展都不会叫醒她，正在处理的那一轮也会停下。关掉开关或发 `/resume` 恢复。

暂停不改变「何时回复」的设置，恢复后照旧。长期只看不回，用“仅观察”。

## 连发间隔

她一次连着发好几条消息时，每条之间停一下再发，看起来更像真人。在「设置 → 聊天」的“连发间隔”里选：不等待、短、适中（默认）、长。这是全局设置，所有频道一样。

![「设置 → 聊天」里的连发间隔](shot:channels-pacing)

“连发间隔”管她发出去的几条之间停多久；“合并连发”管对方连发时她等多久再看，两者不是一回事。

## 群里有好几个智能体时

同一个群里还有本机别的智能体时，“回复细节”里会多出“回应本机智能体”，默认关闭：其他智能体的发言只记进上下文，不会叫醒她，避免两个机器人互相接话停不下来。对方 @ 或回复她时仍会回应。
