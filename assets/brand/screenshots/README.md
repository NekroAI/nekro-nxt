# 产品截图

本目录保存从生产构建产品旅程获取的真实 NekroNXT 页面截图。画面使用虚构智能体、频道、消息、扩展和平台账号，不包含真实用户或入站数据。

- `channel-conversation.png`：频道会话与运行检查器；
- `agent-workbench.png`：智能体人设、模型和配置摘要；
- `connections.png`：平台连接详情；
- `creator-workbench.png`：动态创造、验证和保存流程。

品牌插画不能替代这些截图。界面、展示名或核心用户路径变化时，应重新运行生产旅程并更新截图；导入后清除图片元数据，再运行 `pnpm brand:export && pnpm brand:check` 更新清单。
