# 连接频道

NekroNXT 通过适配器连接不同即时通信平台。每个适配器都复用同一条用户路径：登录账号、发现群聊或频道、选择智能体和触发方式。

## 添加连接

1. 前往「连接」，点击添加账号；
2. 选择已安装适配器提供的即时通信平台；
3. 填写普通配置与只写凭据；
4. 保存并等待连接状态更新。

平台名称、登录方式和配置字段来自适配器。安装新的适配器后，仍按账号、频道和智能体的顺序完成连接。

## 发现频道

先从外部平台向机器人账号发送一条消息，NekroNXT 随后记录对应群聊或频道。接收测试和发送测试是两项独立诊断，不阻塞绑定。

## 绑定智能体

选择发现的群聊或频道，指定响应智能体和触发方式后保存。一个智能体可以绑定多个频道；一个频道同一时间只由一个智能体响应。绑定更新只改变频道响应关系，不修改智能体的人设、模型或授权能力。

外部频道还可以开启“显示处理中状态”，并逐项设置戳一戳、成员进退、消息撤回等特殊事件。特殊事件使用独立的触发列表，默认只记录；“仅观察”同时关闭普通消息和特殊事件触发。

外部频道中的管理员发言以机器人账号发送，并标记为“管理员从客户端发出”。该标记随消息进入频道事实流，用于与智能体发言区分。

## 频道隔离

每个群聊或频道拥有独立的消息记录和会话上下文。群成员可以连续发言、补充条件或通过提及触发智能体。系统先记录工具执行期间到达的新消息，再把这些内容交给智能体的下一步思考。每个群聊只读取自己的短期上下文。

## QQ 官方机器人

QQ 官方机器人通过 QQ 开放平台的 OpenClaw 入口创建，使用 `AppID` 与 `AppSecret` 接入。NekroNXT 主动连接 QQ Gateway，无需部署协议端或配置公网回调地址。

按照 [QQ 官方机器人接入教程](connections/qq-official-bot.md)创建机器人、保存凭据、建立测试私聊，并完成收发测试与频道绑定。机器人可用的私聊和群聊范围由 QQ 开放平台当前开放能力决定。

## OneBot V11

OneBot 11 连接适用于已独立部署的协议端。NekroNXT 作为 WebSocket 客户端连接协议端提供的 Universal WebSocket Server，并使用可选的只写 Access Token 完成认证。SnowLuma、NapCat 和 LLBot 均按 OneBot 11 协议接入。

协议端必须使用数组消息格式。首版支持群聊和私聊的文字、Mention、引用、图片、语音、合并转发和富消息摘要；主动文件、群管理、公告、签到、精华和 raw Action 尚未开放。

按照 [OneBot V11 接入教程](connections/onebot-11.md)配置 SnowLuma、NapCat 或 LLBot，填写 Endpoint，并完成收发测试和频道绑定。各协议端的自动化兼容与真实账号验收状态以 [OneBot 11 Decision](../decisions/implemented/2026-08-26-OneBot11正向WebSocket适配器.md) 为准。

## 企业微信智能机器人

企业微信智能机器人使用官方长连接接入。NekroNXT 通过 BotID 与只写 Secret 主动连接企业微信，无需公网回调地址。群聊消息需要成员提及机器人账号；单聊和群聊首次发来消息后，NekroNXT 发现频道并允许发送测试与绑定智能体。

首版支持 Markdown、图片、普通文件、AMR 语音、MP4 视频、流式处理中状态，以及进入会话、模板卡片操作和消息反馈事件。按照[企业微信智能机器人接入教程](connections/wecom-ai-bot.md)创建 API 长连接机器人、填写凭据并完成验收。
