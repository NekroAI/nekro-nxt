# 已实施：Core 数据库基线与类型安全重建

状态：implemented

## 结论

Core 以 Drizzle schema 为唯一结构事实源，运行时使用 `better-sqlite3` 官方同步驱动和 typed Repository。无法识别的数据库拒绝打开，迁移目录只保留 Drizzle Kit 生成的 `0000_initial`。

公共 ID、消息、Adapter 事件、HTTP 请求响应和持久 JSON 由 Zod Schema 提供运行时边界并推导 TypeScript 类型。Server 与 Web 共享 Host API Contract Registry；响应损坏时必须失败，不能由泛型伪装成已校验数据。

## 数据库基线

当前 22 张领域表：

- 智能体：`agent_definitions`、`agent_revisions`、`agent_current_revisions`；
- 连接与频道：`connections`、`connection_state`、`channels`、`platform_identities`、`channel_members`、`channel_bindings`、`channel_events`；
- 会话与准入：`episodes`、`episode_handoffs`、`episode_handoff_events`、`admissions`、`admission_events`；
- 出站：`outbound_intents`、`physical_deliveries`；
- 资源：`assets`、`asset_occurrences`；
- 扩展：`local_extensions`、`extension_revisions`、`agent_activations`。

Binding、Activation 只保存当前关系；Admission 与 Handoff 的事件来源使用关系表，不保存 JSON ID 数组。

## 提交与恢复边界

- 创建智能体、首 Revision、当前指针、Web Channel 与 Binding 在一个 `BEGIN IMMEDIATE` 事务提交；提交前验证模型仍存在于 DSH Provider 目录。
- 入站 blob 先原子发布，再在一个数据库事务提交 Channel Event 与 AssetOccurrence；Admission 只在事务完成后启动。
- Extension 源码目录先原子发布，再事务提交 Extension 与 Revision；未引用目录不参与恢复。
- Physical Delivery 直接保存 `sent/failed/unknown` 回执；崩溃时 `sending` 变为 `unknown`，不自动重发。
- Gateway 只在 Event 提交成功后保存唯一 resume state；平台重放由 Event dedupe 消化。

## 运行语义

- Trigger Policy 只决定是否启动 Turn；运行中 Turn 会准入普通群消息，Mention/Command 启动后分页补齐全部未准入事件。
- Episode 摘要期间保持 `active`；摘要完成后一次事务提交旧 Episode 关闭、新 Episode、Handoff 与来源事件。
- 换绑通过 Channel Runtime lane 的安全点执行，并以 `binding-replaced` 关闭旧智能体 Episode。
- 外部平台频道不允许 Web Composer 冒充平台入站；Channel Runtime 的入站和出站真实提交统一发布 `channel-fact` SSE。
- Extension API 按 Extension 返回 `revisions[]` 与 `activations[]`；Activation 路径显式包含 Agent 和 Extension，动态保存显式指定 Episode、Plugin 与 Package。

## 类型和 SQL 门禁

- 常规 CRUD、关联查询、事务和状态转换只使用 Drizzle Query Builder；业务源码禁止 `.prepare()`、`.exec()`、`sql.raw()` 和字符串 SQL。
- `as never`、双重断言和未校验 `JSON.parse` 为零；确属 DSH 声明接缝的断言只允许位于固定 `dsh-interop/unsafe.ts`，且数量不可增长。
- TypeScript 启用 unused、override、index-signature、side-effect import、unreachable 等严格检查；CSS Modules 生成精确声明。
- `.mjs/.js` 检查脚本纳入 `checkJs`；workspace 依赖、迁移生成物、JS/`.d.ts` exports 与 API Contract 完整性进入常驻检查。

## 明确边界

不实现图片增强队列、发送重试历史、Extension Draft、市场、导入/删除 Extension 或管理员外部平台主动发言。DSH Session SQLite 由 DSH 所有，Core 不读取其私有表。
