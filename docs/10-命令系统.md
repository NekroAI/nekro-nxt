# 命令系统

命令是频道消息之外的显式操作入口，由同一个 Host 执行服务处理平台聊天与 Web 请求；不调用模型来识别命令或代替授权。设置的「命令」分区管理全局策略，频道检查器管理覆盖与成员授权。

## 语法与权限

`/命令 参数 --选项 值` 支持 Unicode 名称、别名、单/双引号、反斜线转义、位置参数、`--key=value`、布尔选项与 `--` 结束选项解析。参数按声明的 string、number、integer、boolean、choices、min/max 验证；字符串长度按 Unicode 码点计算。缺少参数、重复/未知选项、类型错误及未闭合引号均返回用法。

单引号和双引号内都支持反斜线转义，例如 `'a\ b'` 得到 `a b`；这与 shell 的单引号规则不同。非布尔选项的值若以 `--` 开头，使用 `--key=--value`；写成 `--key "--value"` 仍会报缺少值。

| 命令 | 行为 | 最低权限 |
|---|---|---|
| `/help [命令]` | 可用命令、参数、示例 | 普通用户 |
| `/status` | 当前频道、智能体、响应模式、运行状态 | 普通用户 |
| `/stop` | 停止当前轮次，保留上下文 | 频道管理 |
| `/reset` | 清空上下文，保留聊天历史 | 频道管理 |
| `/compact` | 复用现有摘要压缩与降级处理 | 频道管理 |
| `/off` | 保存策略后仅观察 | 频道管理 |
| `/on` | 恢复策略；没有保存值时群聊为提及/回复触发，私聊和内置频道始终响应 | 频道管理 |

帮助始终可用，只展示调用者可执行的命令。启用状态按频道覆盖、全局、注册默认值取第一个已设置值；权限不得低于声明的最低要求或全局收紧要求。外部授权精确绑定连接、频道与平台用户 ID，从当前频道已有成员目录选取；昵称、消息事实及平台群管理员标志均不授予命令权限。Web 管理身份来自已认证管理边缘或可信本地宿主，请求体不能声明身份。

只识别纯文本，允许剥离开头指向当前连接账号的结构化 mention；指向其他成员的 mention 不剥离，因此 `@别人 /stop` 作为普通聊天处理。剥离机器人 mention 后仍包含其他 mention、quote、附件或富文本时也不识别命令，代码块不识别。`//` 在普通聊天投影中去掉一个斜杠，原始入站事实仍保留。未知、禁用、无权限和错误参数均在命令通道结束，不交给模型。平台来源的未知命令和无权限请求只记录失败，不公开回复；Web 管理界面仍能查看原因。未绑定频道也可执行帮助和状态。

## 运行、投递与恢复

入站在同一事务中保存消息事实和命令执行记录，完成识别后立即返回；命令不进入普通扩展入站钩子或模型准入。处理器、回复规划和回执等待交给后台队列，同一频道按接收顺序执行，最多四个频道并行。慢命令不阻塞同一连接后续消息入库。Web 执行请求共用队列，并等待执行结果返回。

命令原文和结果保留在历史；积压、运行中注入和恢复统一排除命令，不产生模型回复义务。管理命令复用 Channel Runtime 的停止和上下文接口，取得原有串行执行通道后复核绑定代次与授权，避免锁重入。响应策略保存按频道、智能体及绑定代次限定，换绑不继承旧保存值。

平台用事件 ID、Web 用客户端请求 ID 去重，同一 Web ID 更换内容或执行者会拒绝。执行记录保存来源、执行身份、命令完整名称、智能体及扩展版本。状态为 pending、running、succeeded、failed、uncertain；宿主恢复把未完成的 running 标为 uncertain，不自动重跑处理器。启动期间先保存新命令，等待扩展智能体挂载恢复后执行，避免把尚未注册的命令误判为未知。

命令结果使用原 Outbox、Adapter 规划与回执，但通过 `commandExecutionId` 和 `channelId` 关联，Episode 和 agentRevisionId 为空。发送 `/reset` 回执不会重建模型会话。一个执行只能有一个 Outbound，规划后断电也能从唯一关联找回；已开始发送但没有权威回执的物理投递标为 unknown，不盲目重发。执行成功和回复失败是两个独立事实，Web 明确展示；Adapter 不在线、无法建立 Outbox 计划时，已保存的结果仍随命令原文显示。

Drizzle 增量迁移保存新系统启用时最大的既有事件 ID，旧事件不追溯执行。迁移保持聊天、旧 Episode、Outbox 及物理回执；该截止点只用于区分启用前的历史，不作为恢复扫描起点。执行记录的恢复标记随执行状态和回复状态更新并建立索引；启动只读取待执行或待补回复的记录，不遍历频道事件或已完成命令。恢复入口只在首次开放时调度，重复开放不重复扫描。关闭宿主时取消运行中的处理器，未启动的队列项保留为 pending，供下次恢复。执行期间停用扩展先撤销新调用，再发送取消信号并等待处理器清理。

## 扩展 SDK

Manifest 使用 V7，命令归属智能体层，声明 `requires: { sdk: 9 }` 和 `{ kind: 'command', ...definition }`。Host factory 调用 `harness.registerCommand(definition, handler)`，获得注销函数；声明与实际注册必须完全一致。注册属于扩展本机实例，执行与取消按智能体挂载隔离，不依赖 DSH Session，不在每个 Session 的 apply 中注册。一个扩展可注册多个命令，名称/别名不能重复，内置名称保留。

完整名称固定为 `/扩展ID:命令`，短名唯一时可用，冲突返回完整候选名称。处理器收到已验证参数、执行身份、当前频道、AbortSignal 和受授权约束的 status/stop/reset 宿主能力；不可通过普通用户命令调用管理能力。一次返回结构化文本、图片或文件结果，媒体必须是当前频道已授权的 Asset ID，不接受宿主文件路径。

已启用扩展在重配置或停用过程中暂停命令时，保留已提交版本的命令名称、别名和策略，将目录项标为不可执行并给出原因；有权限的调用返回「命令所属扩展暂时不可用，请稍后重试」，不会记为未知命令。重新挂载完成或暂停回滚后恢复执行；停用提交后才移除目录项。

导入隔离验证实际执行命令，管理宿主能力使用合成结果；启用、更新和卸载沿用现有不可变 Revision/智能体挂载 流程。运行中的调用持有原 handler，卸载等待它清理；处理器应监听 AbortSignal，不能留下未等待的后台任务。首版通过本地源码包导入命令扩展，参考[可安装回声示例](../apps/server/examples/command-echo/README.md)。

工坊动态创造暂不支持命令贡献。定义或恢复动态候选时，预检会拒绝 `kind: 'command'` 并提示使用本地源码包导入；不会把未注册的命令候选送入验证或安装。

## Web 与接口

聊天输入 `/` 展示当前频道可执行命令；方向键选择，Tab/Enter 补全，补全后的 Enter 执行。管理命令不受模型供应商不可用、未绑定频道或主动发送开关的输入框限制；执行服务仍按命令规则拒绝未绑定的管理操作。外部控制台的命令原文只作为本地事实，不作为机器人消息发送到平台。

类型化 Host API 包括目录、执行、读取记录、全局/频道策略、频道成员与授权变更；`HostApiContracts` 是请求与响应形状的唯一来源。所有管理接口沿用管理边缘鉴权，执行接口重新核对策略、授权及绑定。执行记录随消息快照和 SSE 投影更新，命令结果使用独立来源标记，不冒充智能体发言。

首版不提供正则触发、多步等待、流式输出、模型调用命令、Ctrl+K 联动或 Nekro Agent 插件兼容。
