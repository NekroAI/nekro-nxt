# NekroNxt 界面交互模型

> 用途：约束产品概念图、交互原型和后续 UI 实现  
> 状态：产品形态设计基线  
> 原则：先定义页面对象、状态和操作后果，再设计控件
>
> 视觉 Token、桌面布局尺寸、组件状态和动效遵循 `05-桌面UI与动效规范.md`。

> 文案铁律：界面中的实体统一称“智能体”。Agent、AI 成员、Bot、助手不得作为同一实体的替代类型名；英文内部类型不得直接显示给用户。

## 1. 全局对象规则

### 1.1 每个页面只有一个主要对象

| 页面 | 主要对象 | 次要上下文 |
|---|---|---|
| 工作模式默认画布 | 上次使用的 Channel | 对象列中的智能体树 |
| 零智能体空态 | 创建入口 | 无 |
|智能体创建页面 |智能体Draft | 默认 Web Channel |
| Channel 对话 | Channel Binding | 响应它的智能体|
|智能体工作台 | `AgentDefinitionDraft` | 当前 Revision、绑定频道和活动 Session |
| 频道绑定向导 | Binding Draft | Connection、Channel、智能体|
| 创造工作台 | 当前智能体的动态 Package | 审批与保存 |
| 本地扩展 | Local Extension | 当前版本和启用关系 |

同一时刻画布只有一个主要对象；检查器只服务它。页面标题、主操作和检查器都必须服务这个对象。完整编辑进入该对象的画布，而不是另一个一级模式。

### 1.2智能体与 Channel 的关系

-智能体是长期产品实体；
- Channel 是一段消息事实流；
- Channel Binding 决定哪个智能体响应该 Channel；
- 一个智能体可以同时保留多个有效 Channel Binding，并分别参与多个独立频道；
- 一个 Channel 同一时间只能绑定一个智能体；换绑改变后续响应所有权，不删除该频道已有消息；
- 一个 Channel Conversation 只显示该 Channel 的消息；
- 跨 Channel 长期记忆可以共享，但短期聊天记录不直接混合；
- 切换左侧 Channel 就是切换中央 Conversation，而不是筛选同一混合流。

### 1.3 Extension 的三个独立动作

```text
动态运行
→ 保存为本地 Extension Revision
→ 激活给一个或多个智能体
```

- 动态运行：临时、可停止、可能重启丢失；
- 保存：源码和 Revision 持久化，但不自动扩大作用范围；
- 激活：指定哪个智能体使用哪个 Revision。

## 2. 状态词典

### 2.1 Host 状态

- 正在连接；
- 运行正常；
- 连接不稳定；
- 无法连接。

### 2.2 Connection 状态

- 已连接；
- 正在连接；
- 认证过期；
- 已断开；
- 异常。

### 2.3智能体运行状态

- 空闲：没有活动 Turn；
- 思考中：模型正在生成；
- 使用工具：Tool 正在运行；
- 等待输入：等待用户问题或审批；
- 已暂停：用户暂停新 Turn；
- 不可用：模型、配置或 Runtime 有错误。

智能体不使用含糊的“在线”表示一切正常。

### 2.4 Channel Binding 状态

- 监听中；
- 已暂停响应；
- Connection 断开；
- 配置错误。

### 2.5 扩展启用状态

- 未启用；
- 已启用；
- 启用失败。

## 3. 应用外壳

### 3.1 全局模式

```text
工作（默认）
连接
扩展
设置
```

图标轨只切换模式。工作模式的对象列是智能体树；连接、扩展、设置各自用对象列列出该类对象。创造工作台和运行详情由明确动作进入，不占据图标轨。默认打开上次使用的频道；没有频道则打开第一个智能体；一个智能体都没有时进入创建空态。

工作模式使用 `/work` 路由族：`/work/channels/:channelId`、`/work/agents/:agentId`、`/work/agents/new` 和 `/work/creator`。旧 `/channels/*`、`/agents/*`、`/creator` 只做 replace 兼容重定向，不再作为产品链接目标。

### 3.2 工作模式对象列

```text
小奈
├─ 网页聊天
├─ 设计群
└─ 项目频道
```

- 点击智能体名称：画布换成该智能体工作台，对象列保持；
- 点击 Channel：画布换成该 Channel Conversation；
- 智能体和频道可在同组内拖动排序，松手后立即按新顺序展示，并由 Host 保存；
- 未绑定频道拖进智能体：确认后绑定（日常绑定入口，确认框可选响应方式）；
- 已绑定频道拖到另一智能体：确认后换绑；
- 已绑定频道拖到「未绑定频道」或树外侧：确认后先停止该频道正在工作的智能体（若有），再解绑；
- 跨组拖放只提案：投放处显示虚线，松手后树保持原绑定位置再确认；执行权在 Host，SSE 只播报步骤；
- 拖动智能体时整组（名称和它的频道）一起走，其他组不跟着抖动；拖动频道时只有同组频道让位，不把别的智能体条目挤来挤去；
- 智能体标题行和频道整行都可直接 Pointer 拖动，不显示 `...` 菜单或右键操作列表。行尾移动图标只提示可拖动并提供键盘入口，视觉上不呈现为按钮；图标覆盖在行尾，常态不占标题空间，只在 Hover、键盘聚焦或拖动时出现；绑定、换绑与解绑由拖放确认、频道检查器或智能体管理页提供；
- 绑定关系改变后，焦点跟随频道到新位置；顺序保存失败时恢复 Host 权威顺序，不保留仅存在于浏览器中的临时排序；
- `+`：打开创建智能体页面；「未绑定频道」旁的加号新建未绑定网页频道，再拖到智能体上交给它响应；
- 绑定向导仍可用于改触发策略和没有拖拽时的备用；
- Connection 状态不在这里用一个绿点替代，异常时显示明确图标与文案。
- 对象列是外壳的一部分，不在频道页里再画第二棵树。
- 对象列和右侧检查器都可通过分隔条调整宽度；拖动结束后只在当前浏览器保存。双击分隔条、键盘 Enter / Space 或设置页“恢复默认分栏”恢复默认宽度。对象列始终保留，不提供会清空主要导航的收起入口；频道与智能体工作台共用检查器宽度和默认显示偏好，页面标题栏右侧用单一图标提供收起 / 展开入口。

### 3.3 右侧检查器

频道会话页头切换「会话 / 工作轨迹」。右侧检查器列保持：会话视图显示绑定和活状态，工作轨迹视图按选中记录类型叠放详情。切换视图不得卸掉检查器列。时间轴只出现在工作轨迹，会话页不放。

会话检查器的「运行」在有样本时用两个紧凑环形图展示上下文：已用/剩余，以及系统/工具/对话/其他组成；Hover 扇区轻微浮起，跟随指针且只淡入的 Tooltip 显示精确 token 与比例，键盘 Focus 提供同等信息。缓存读取作为独立数值，不混入组成。没有窗口或用量时整块省略，不画空表盘。工作轨迹台账状态列写耗时；选中一行后检查器叠放本步用量和首字耗时（有才显示），仍不使用页签。占用是参考值，不是计费或压缩门禁。

检查器的「绑定」把智能体名称、更换智能体和管理智能体聚合在同一区块，频道来源和响应方式作为绑定的子内容；未绑定时只给出状态和绑定入口。频道显示名称属于次要编辑。人设、模型和能力仍进入智能体管理页。工作轨迹检查器不使用摘要 / 输入 / 输出页签：内部输出看全文，发送看发出的内容，工具同时看输入和输出。

## 4. 工作模式入口

### 4.1 默认画布

工作模式打开上次使用的频道。没有上次记录时打开第一个频道；没有频道时打开第一个智能体工作台。一个智能体都没有时，画布是创建空态。

对象列列出智能体及其绑定频道、尚未绑定的频道。点击智能体名称进入该智能体工作台；点击频道进入该频道会话。对象列的 `+` 打开创建智能体页面。

智能体卡片墙不是默认首页，不为“浏览全部智能体”单独保留一级目的地。

### 4.2 创建入口

| 按钮 | 显示条件 | 结果 |
|---|---|---|
| 创建智能体 / 创建第一个智能体 | 用户可管理当前实例 | 打开智能体 Draft 页面 |
| 打开最近频道 | 智能体已绑定频道 | 打开该智能体最近使用的频道 |

## 5. 创建智能体页面

创建入口打开 `/work/agents/new` 完整页面。创建与编辑智能体复用名称、人设、模型、能力、字段校验和双列布局；创建模式明确标记“新智能体草稿”，编辑模式展示真实运行状态和未保存变化。创建不使用 Dialog 或分步 Tabs。

### 5.1 默认行为

- 自动创建 Web Channel；
- 默认使用“通用方式”；
- 默认启用子智能体；网页搜索只在 DSH Web Provider 与凭据就绪时默认启用；文件工具、Bash、动态创造和不受限文件访问默认关闭；
- 可以先跳过外部平台；
- 没有可用模型时，在模型分区就地保存供应商，不中断创建去设置页；
- 最终确认前不写入正式 `AgentDefinition`。

### 5.2 按钮逻辑

| 按钮 | 结果 |
|---|---|
| 创建智能体| 原子创建 `AgentDefinition`、首个 Revision 和 Web Channel |
| 取消创建 | 丢弃 Draft，返回 `/work`，不留下半创建智能体|

## 6. Channel Conversation

### 6.1 页面标题

标题使用 Channel 名称，例如“设计群”。副标题显示：

```text
由“小奈”响应 · 被提及或回复时触发
```

智能体不是该页面标题，因为中央事实流属于 Channel。

### 6.2 消息流

- 只显示当前 Channel 的平台消息；
- 智能体消息只能来自已成功记录的通信工具调用，并标记发送中、已发送、部分发送、失败或结果未知；
- DSH 模型原始文字和 reasoning 不投递给 Adapter，但 Web UI 会话流以「内部输出」展示；
- 文字、Mention、图片和文件均是同一逻辑消息的有序内容部分；
- 工具卡片穿插在会话流中，归属于触发它的智能体 Turn；通信工具成功发送的内容仍是聊天气泡；
- 系统事件使用低噪声状态行，不伪装成聊天消息；
- 其他 Channel 的消息只产生全局未读提示，不进入当前流。

网页频道以后台用户为观察者：智能体消息在左，后台用户输入在右。外部频道以智能体/管理员观察频道为视角：平台成员在左，智能体和管理员通过机器人账号发出的消息在右。消息车道占满中央可用宽度；文本 part 统一安全渲染 Markdown，媒体、Mention 与引用保持原始有序结构。

### 6.3 新群消息与当前 Tool

Tool 运行时到达的新消息先入库，并在安全间隙注入下一步思考。会话页用说明文字表达这一点；展开待注入列表尚未作为主操作开放。

### 6.4 Composer

Composer 只在会话视图浮动于消息画布底部，不形成独立说明区；切换工作轨迹后不渲染。网页频道常态从左到右显示信息图标、短标签“发给智能体”、输入和靠右的无文字发送图标；信息 Tooltip 说明该内容作为当前网页频道入站交给绑定智能体。

管理员输入作为该频道的入站消息交给绑定智能体，不是智能体的模型输出。

外部平台频道常态从左到右显示信息图标、短标签“发到频道”、输入和靠右的无文字发送图标；信息 Tooltip 说明连接展示名、平台可见后果和“管理员从网页发出”来源。Composer 只画一个整体外框，不在里面再套有边框的输入框。连接未允许主动发送或尚未绑定智能体时，短标签替换为一句可见阻塞原因并禁用发送。

内容经 Adapter 以机器人账号投递到该频道；会话注入系统事实，不记为 `send_channel_message`。消息列表用「管理员从网页发出」标记。连接未允许主动发送、或尚未绑定智能体时，说明前置条件并禁用发送。可另外提供「去网页频道和智能体对话」。

不放含义模糊的“能力”按钮。智能体能力在智能体管理页配置。尚未绑定智能体时，主操作是“绑定智能体”，打开共享绑定向导。

### 6.5 运行控制

会话页说明新消息会在安全间隙注入。停止当前任务、展开待注入消息、编辑绑定和暂停响应尚未作为频道主操作开放。

## 7.智能体管理与 Revision

智能体工作台是这个智能体的完整画布。人设、模型、频道、能力和扩展在同一文档中滚动，不再用四个一级 Tab 切换身份。页头固定名称、运行状态和保存；右侧检查器给出最近频道和当前阻塞。缺模型、未绑定频道、网页搜索待凭据和动态创造运行都在本页给出就地入口。`?tab=` 只滚动到对应章节。

创建页与本页共用 `AgentEditorShell`：主编辑列承载名称、人设、模型和能力，辅助列只显示当前状态、阻塞项和创建/保存结果预览。创建模式不伪造已绑定频道或扩展，编辑模式继续显示真实频道与扩展。

### 7.1 页面分区

- 人设与模型；
- 已绑定频道；
- 授权能力；
- 已关联扩展。

### 7.2 Draft 规则

人设与模型进入同一份 Draft。页面在有未保存更改时提供保存和放弃。能力开关独立提交，不进入这份 Draft。

### 7.3 保存结果

| 按钮 | 结果 |
|---|---|
| 保存新配置 | 为人设与模型创建新 Revision |
| 放弃更改 | 丢弃人设与模型 Draft |
| 能力开关 | 立即写入能力 Revision |

运行中的任务在安全间隙使用兼容的新配置。产品不提供“立即替换工具执行中的 Session”。

### 7.4 高能力开关

子智能体、网页搜索、文件工具、动态创造、开发 Shell、不受限文件访问分别设置。高风险项给出醒目前端警示，但不按频道类型强制关闭；开启创造不隐式开启文件或 Shell。

网页搜索缺少凭据时，在能力页就地保存 DeepSeek API 密钥；完整插件配置仍进入设置。动态创造的主操作是“打开频道去描述需求”，“查看创造运行”带上当前智能体进入创造页。

### 7.5 频道与扩展

已绑定频道可在本页改触发策略。未发现频道的平台账号在本页说明，绑定仍打开共享任务单；是否执行过可选收发测试不构成智能体配置阻塞。扩展章节可以直接启用或停用，与扩展页使用同一动作。

### 7.6 领域页面

- 设置：对象列是唯一分类导航，页面不再渲染重复 Tabs；
- 连接：围绕账号身份与健康、发现频道、绑定状态和配置组织；收发测试作为一次性可选诊断折叠展示；
- 扩展：围绕版本、作用智能体、贡献内容、验证证据和生命周期组织；
- 三类页面使用各自的信息层级，不复用同一张详情大卡片仅替换标题；顶栏不复述模式名，对象列只命名对象集合，主画布只命名当前对象或任务；
- 空对象列不重复主画布空态。连接主画布用“接入聊天平台”引导首个账号；扩展主画布用“扩展库 / 从一次动态运行开始”提供创造入口，对象列只保留集合标题。

## 8. 频道绑定向导

绑定是共享任务单，不是两个一级页面互相跳转。连接页发现频道后即可就地绑定；智能体工作台绑定新频道；未绑定的会话页就地选择智能体。完成后留在原处。收发测试不进入绑定步骤，只在需要诊断平台权限时单独执行。

### 8.1 步骤

```text
选择平台
→ 连接账号
→ 选择频道
→ 绑定智能体
→ 完成绑定
```

### 8.2 最终确认内容

- Adapter 与 Connection；
- Channel；
- 响应它的智能体；
- 触发方式。

### 8.3 按钮逻辑

| 按钮 | 结果 |
|---|---|
| 测试接收 | 验证 Adapter 事件能到达 Channel Runtime，不触发正式智能体|
| 发送测试消息 | 通过目标平台的机器人账号向 Channel 发送明确标记的测试消息 |
| 绑定频道 | 在当前页创建或替换 Binding，不跳转到另一个一级页面 |
| 完成绑定 | 创建 Binding 并开始监听，不要求先执行收发测试 |
| 测试接收 / 发送 | 在连接详情的可选诊断区单独执行一次，不改变绑定流程状态 |

### 8.4 连接辨识名

创建连接时可以填写最多 80 个字符的辨识名；输入会 trim，空值表示未设置。连接详情、对象列、频道来源、智能体频道列表和绑定选择器统一显示“辨识名或连接名”，同时以 Adapter displayName 标注平台身份。已创建的非系统托管连接可保存或清除辨识名；系统托管 Web 连接不显示编辑入口。

## 9. 创造工作台

创造不是一级导航。页面展示已授权智能体活动会话里的动态 Package，以及待确认的 Client 预览。需求在该智能体的频道里描述，不另建创造智能体。

| 按钮 | 结果 |
|---|---|
| 允许预览 / 拒绝 | 审批或拒绝当前动态 Client 界面 |
| 保存为本地扩展 | 写入不可变源码 Revision，不自动启用 |

启用在扩展页单独完成。停止动态版本、继续修改、回到上个动态版本尚未作为工作台主操作开放。

## 10. 本地扩展

页面列出已保存的本地扩展、当前版本、目标智能体和启用状态。

| 按钮 | 结果 |
|---|---|
| 启用给智能体 | 为该扩展的当前版本创建 Activation |
| 停用扩展 | 去掉该智能体的启用关系 |

## 11. 按钮命名铁律

1. 动词必须说明对象：用“停止当前任务”，不用“停止”；
2. 保存和生效分开：用“保存为本地扩展”“启用给小奈”；
3. 不使用“确定”代替真实动作；
4. 不使用“查看”而不说明查看什么；
5. 不把权限、能力和运行模式塞进 Composer；
6. 危险动作只在它真正危险时使用警示色；
7. 不可执行的按钮说明前置条件，不能只灰掉；
8. 每个主按钮只产生一种可解释状态变化。

## 12. 未开放

- 创造工作台的停止/继续修改/回退动态版本；
- 恢复模式产品面。
