# 定时任务

群友可以直接在聊天里请智能体设提醒或周期任务，比如“明早八点提醒我交报告”“每个工作日早上九点发天气”。到点后她会收到通知，再决定在群里说什么、做什么。

## 打开

在智能体资料页的「能力」里打开「定时任务」，新建的智能体默认开着。关掉后她不能再新建任务，已有的任务仍按计划触发。

## 在聊天里建

直接用平常的话说就行。她会复述时间和内容，建好后告诉你下次什么时候触发。

- 一次性：“半小时后提醒我收衣服”“周五下午三点提醒大家开会”；
- 周期：“每天早上八点”“每个工作日”“每周一”；
- 修改、暂停、删除也是对她说，比如“把早安提醒改到七点半”。

任务只属于建它的那个频道，每个频道最多 20 个还会触发的任务。

## 在资料页管理

资料页的「定时任务」按来源列出这个智能体的全部任务：任务名和所在频道、计划、下次触发时间。

![资料页的「定时任务」，还没有任务时](shot:agents-schedules)

每个任务的“…”菜单里可以：

- **立即执行**：现在触发一次，不影响下一次的时间；
- **暂停 / 恢复**：周期任务恢复后从现在算下一次，不补触发；
- **删除**。

界面上没有新建任务的表单，新建和修改都在聊天里完成。扩展创建的任务单独分组，只能在这里暂停，要在扩展的配置里关掉。

## 错过了怎么办

NekroNXT 没在运行时错过的任务，重新启动后只补触发一次；一次性任务过期超过 7 天就不再补。

## 和暂停回应的区别

频道的“暂停回应”（或聊天命令 `/pause`）让她暂时不回应这个频道的任何事，期间到点的定时任务也不会叫醒她。这和暂停某一个任务是两回事。
