# 子对话

遇到费时间的事，比如翻大量聊天记录、整理资料、写一段代码，智能体可以开一个子对话去处理，自己继续在群里聊，做完再回来汇报。

## 打开

在智能体资料页的「能力」里打开「子对话」，新建的智能体默认就是开着的。

## 在哪里看

进行中的子对话缩进显示在频道列表里所属频道的下方，点开可以看它做了什么、用的哪个模型。子对话里的消息只在智能体之间传递，你只能查看，不能在里面发言；需要时可以结束或删除它。

除了智能体自己开的，她在[动态创造](../extensions/dynamic-creation.md)里验证新做的工具时，NekroNXT 也会自动开一个叫“验证 …”的子对话来试用它。这类子对话不调用模型，不花钱。

## 给子对话选模型

在资料页「模型」的「子对话模型」里点“添加”，可以为子对话配几个候选模型（最多 8 个），每个写上名称和用途。她开子对话时按事情挑一个；没挑时用“不指定时”选的那个，默认是主模型。

![「子对话模型」：没有添加时，子对话都用主模型](shot:agents-sub-models)

- 一个子对话开了以后一直用同一个模型；
- 子对话不复用群里对话的缓存，所以给它配便宜的模型，不会让群里的回复变慢或变贵；
- 修改候选模型后，她要到下一段会话（闲置后被叫醒、压缩或重启之后）才看到新的选项。

## 保留多久

结束的子对话连同记录保留一段时间后自动清理，在「设置 → 子对话」的「结束后保留」里调，默认 7 天，也可以一直保留。
