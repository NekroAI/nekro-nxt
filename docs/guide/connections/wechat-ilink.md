# 接入微信 iLink

NekroNXT 通过实验性微信 iLink 通道接收私聊文本，并在收到该会话消息后回复纯文本。创建连接只需使用平台应用扫码登录，不填写账号 ID、访问令牌、API 地址或 CDN 地址。

```text
微信私聊
  ↕
实验性 iLink 通道
  ↕ 扫码登录后的长轮询
NekroNXT → 发现私聊 → 绑定智能体
```

## 开始前准备

准备以下内容：

- 一个专用微信机器人账号；不要使用日常个人账号做实验；
- 可扫描二维码并确认登录的平台应用；
- NekroNXT 中至少一个可用的智能体。

该通道基于非官方微信 iLink / OpenIlink 协议。协议稳定性、账号风控和合规风险不由 NekroNXT 保证。

## 在 NekroNXT 添加连接

1. 前往「连接」，点击「添加平台连接」；
2. 选择「微信 iLink」；
3. 点击「扫码登录」，使用平台应用扫描页面中的二维码并确认；
4. 登录成功后，NekroNXT 会自动创建连接并保存只写访问令牌。

页面只显示二维码和登录状态，不展示账号 ID、访问令牌、API 地址或 CDN 地址。关闭弹窗会取消尚未完成的登录会话。

同一个微信账号同时只能保留一个活动连接。重复扫码会被拒绝；如需恢复同账号的旧连接，应先归档或删除当前活动连接。

已创建连接的详情页提供「入站媒体接收」开关。开启后，收到的图片和文件会下载并导入为频道资源；关闭时只记录可解释的占位内容。

## 发现频道并绑定智能体

1. 使用测试微信号向该机器人账号发送一条私聊文本；
2. 返回连接页面，运行接收测试；
3. 对已发现的私聊运行发送测试；
4. 点击「绑定智能体」，设置响应智能体和响应方式；
5. 再次发送私聊文本，确认智能体能够回复。

发送测试和智能体回复都需要先收到该会话消息，以取得 context_token。尚未发现的私聊不能主动发起。

## 消息和媒体范围

首版范围：

| 方向 | 能力 |
|---|---|
| 入站文本 | 支持 |
| 入站图片 / 文件 | 可选；关闭时记录占位内容 |
| 出站文本 | 仅回复已发现的私聊 |
| 群聊、Mention、引用、撤回 | 尚未开放 |
| 主动发送、出站图片 / 文件 | 尚未开放 |

入站文件只作为频道资源保存和展示，不会自动复制到智能体开发工作区。

## 最小验收清单

- 扫码登录后自动出现微信 iLink 连接；
- 私聊文本能够进入频道；
- 收到该会话消息后可以完成发送测试；
- 关闭入站媒体接收时，图片和文件显示为可解释占位内容；
- 开启入站媒体接收后，图片和文件进入频道资源；
- 快照、日志和页面不出现访问令牌或 context_token。

当前实现已通过合成协议夹具和自动化测试，尚未完成独立真实账号验收。完成真实扫码、私聊文本、入站媒体和会话过期测试后，才能标记为“已验证支持”。

## 按症状排障

### 二维码过期或登录失败

关闭弹窗后重新点击「扫码登录」。确认使用的是专用机器人账号，并且平台应用已确认登录。

### 连接显示会话已过期

访问令牌失效后，在原连接详情点击「重新认证」，使用同一账号扫码。成功后保留连接、频道历史、绑定和入站媒体设置；账号不一致或取消时不会替换原连接。

### 发送测试失败

先向该机器人账号发送一条私聊文本，等待连接发现频道后再发送。没有 context_token 时，微信 iLink 不能主动发起私聊。
