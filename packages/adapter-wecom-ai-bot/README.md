# 企业微信智能机器人 Adapter

该包实现企业微信官方智能机器人长连接。Connection 使用 `BotID` 与只写 `Secret` 主动连接 `wss://openws.work.weixin.qq.com`，通过官方 WebSocket 命令完成订阅、消息接收、回复、主动发送和媒体上传。

首版支持群聊与单聊文本、图片、普通文件、MP4 视频、AMR 语音，以及进入会话、卡片操作和消息反馈事件。群消息触发智能体时可创建流式处理中消息；智能体的首条纯文本发言可以结束并替换该消息。

企业微信成功发送回执不含消息 ID，因此回执只确认平台接受请求。Adapter 不提供撤回、戳一戳、模板卡片发送、媒体转码或 raw 命令透传。
