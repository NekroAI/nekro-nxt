# 通知

有事需要你处理时，比如智能体做好的工具等你允许运行、凭据申请、扩展发出的提醒，NekroNXT 可以通知到你的电脑和手机。在「设置 → 通知」里设置，改完点页面底部的“保存”。

![「设置 → 通知」：渠道和通知类别](shot:ops-notifications)

## 渠道

| 渠道 | 默认 | 发到哪里 | 需要 |
| --- | --- | --- | --- |
| 系统通知 | 开 | 桌面版和安卓应用的系统通知 | 无 |
| 浏览器推送 | 开 | 开启了推送的手机和电脑浏览器 | 受信任证书的 HTTPS 访问地址 |
| Bark | 关 | 装了 Bark 的苹果设备 | Device Key |
| 企业微信 | 关 | 企业微信群 | 群机器人的 Webhook 地址 |
| ntfy | 关 | 订阅了主题的 ntfy 应用，可以用自建服务 | 主题名，开启了访问控制时还要令牌 |

每个启用的渠道旁有“测试”按钮，可以先发一条试试。Device Key、Webhook 地址这些保存后只显示已配置。

Bark、企业微信和 ntfy 由 NekroNXT 直接发出，不要求你用 HTTPS 访问实例，但运行 NekroNXT 的机器要能访问这些服务。

## 通知哪些事

「通知我」里可以分别开关：创造任务等待确认运行、社区反馈更新、凭据申请、扩展通知。默认都开着。

## 手机上收通知

- **Android 应用**：打开「系统通知」，并在设置里的“这台手机”打开后台通知。关掉应用后也能收到，通知栏会常驻一条“保持连接”；
- **iPhone、iPad**：在 Safari 里把 NekroNXT “添加到主屏幕”，从主屏幕打开后开启浏览器推送；需要 HTTPS 地址；
- **收不到浏览器推送的安卓手机**：国内很多安卓手机收不到浏览器推送，改用 Android 应用，或者用企业微信、ntfy 渠道。

开启浏览器推送需要通过受信任证书的 HTTPS 访问，局域网 `http://` 或自签名证书都不行，见[通过公网和 HTTPS 访问](../install/https.md)。手机的安装和连接见[在手机上使用](../install/mobile.md)。

## 收不到通知

- 先点渠道旁的“测试”，看测试通知能不能到；
- 浏览器推送：设置页的“接收推送的设备”里会说明这台设备为什么不能开启，比如不是 HTTPS、浏览器不支持、通知权限被拒绝；
- Android 应用：检查系统的通知权限和电池优化，部分手机还要允许自启动。
