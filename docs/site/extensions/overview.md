# 扩展是什么

扩展给智能体和 NekroNXT 增加新能力。一个扩展可以提供其中几样：

- 智能体能调用的**工具**，比如查天气、掷骰子、画图；
- 新的**聊天平台**，装好后出现在「接线」的平台列表里；
- 频道右侧的**面板**、工具结果的展示方式；
- 独立的**页面**，可以放进左侧导航。

扩展有三种来源：让智能体在聊天里现场做（见[让她自己做扩展](dynamic-creation.md)），从[社区安装](install.md)，或者导入别人给你的 `.nxt-extension` 文件。另外还可以[接入 MCP 服务](mcp.md)。

所有扩展都在「工坊」里管理。

## 安装到本机，为智能体启用

扩展分两层生效：

- **本机**：带页面或平台的扩展，要在扩展详情里“安装”到这台机器；
- **智能体**：给智能体用的工具，要在扩展详情或智能体资料页的“扩展”里为某个智能体“启用”，开关立即生效。还没安装的扩展会在这时一起安装。

做好、导入或从社区装来的扩展都不会自动启用。

扩展申请了权限时会先请你批准：对整台机器生效的在安装时批准，只对某个智能体生效的在启用时批准。每项权限标着“常规”“需留意”或“高风险”。新版本申请了更多权限时，旧版本继续运行，直到你批准。

“卸载”只是停用，数据保留；“删除扩展”才会永久删除。

## 配置

扩展有配置项时在扩展详情的“配置”里填：

- **本机配置**：所有智能体共用，比如服务地址、API Key；
- **智能体配置**：每个智能体各一份。

带密钥的配置项选择「设置 → 凭据」里的凭据，也可以就地新建，见[凭据与关联账号](../ops/credentials.md)。每层配置下方有“配置历史”，列出每次修改的时间、来源和原因，可以恢复到某一版。

## 扩展的数据

表情包这类扩展的价值在于长期积累的数据。扩展详情的“数据”显示记录、索引和素材的数量。

- 新版本改了数据格式时，切换过去会自动升级数据，切换前留一份快照；升级失败会恢复快照并退回原版本；
- 可以随时留快照，每个扩展保留最近 3 份；
- “迁移与导出”可以把数据（可选连同配置）导出到另一台机器，或从另一个扩展迁入，比如把原扩展的数据迁到分支。API Key 等凭据不会被导出或迁移。

## 加工智能体发出的消息

有些扩展会在智能体的消息发出前加工它，比如翻译、配音、加署名，或者内容不合适时取消发送。启用这类扩展时会单独确认：能修改或取消消息的算高风险。被扩展改过的消息，时间线上标出“经 X 处理”或“由 X 追加”。同一个智能体启用了好几个会改消息的扩展时，可以调整它们的先后顺序。

## 扩展页面

页面要在扩展详情安装后才能打开，入口在顶栏“搜索”（`⌘K`）的“扩展页面”，以及扩展详情的“打开”。安装前会列出页面能读写什么、能访问哪些网址。

## 平台扩展

提供新聊天平台的扩展，安装后出现在「接线」的“添加平台账号”里。卸载会停止这个平台的收发，账号、频道和聊天记录都保留，重新安装后自动恢复。

## 安全

- 扩展是代码。平台扩展和页面运行在 NekroNXT 里，只安装你信任的来源；
- 社区的自动审查只描述它发现的问题，不是安全担保；
- 动态创造本身不让智能体读写文件或运行命令，这些要在智能体的“能力”里另外打开；
- 扩展申请“在本机运行程序”（比如 ffmpeg）时要单独确认，程序只能读写交给它的文件，不能联网。

## 官方扩展

官方扩展由 NekroNXT 团队维护，包括掷骰抽签、网页搜索与阅读、图片生成、语音合成、今日运势、节日提醒、RSS 订阅、群管和消息守卫，在「社区」里打开“只看官方”就能找到。源码在 [nekro-nxt-extensions](https://github.com/NekroAI/nekro-nxt-extensions)，也是编写扩展的参考。
