# 查看运行日志

从左侧导航底部打开「日志」，查看当前服务实例的系统、DSH 插件、扩展、连接和智能体运行过程。插件、连接和智能体详情中的「查看日志」会带入对应条件。

## 查看与定位

首次进入显示最近一小时的信息、警告和错误。顶部可以组合关键词、时间、级别与来源；更多筛选提供扩展、连接、智能体和频道。关键词按字面内容搜索消息、错误和详情，不使用正则表达式。

日志页随窗口铺满可用空间，顶部筛选和底部操作固定，只有日志列表、来源列表与详情各自滚动。窄窗口的高级筛选在抽屉中打开。新日志出现在底部。回看历史、选中文字或打开详情后，页面保持阅读位置；点「回到最新」继续跟随。连续重复输出默认折叠，展开可以逐条查看，导出仍包含每条记录。页面最多保留五千条已加载记录，完整历史按保留策略存储在服务端。

点击记录打开详情，可复制消息、堆栈和结构化字段。「查看相关日志」优先显示同一次操作的记录，没有操作关联时显示同一来源前后两分钟的日志。已删除对象的历史名称仍然保留。

插件顶部的状态来自当前插件管理信息，历史错误不会把已恢复的插件继续标为故障。正常模型调用和工具执行不写运行日志；失败摘要包含工具或模型、原因、耗时和智能体/频道关联，完整运行内容仍在频道运行记录中。模型调用失败而原因被包装（例如只显示 `TRANSPORT`）时，同一“模型调用”来源下会多一条记录，列出失败阶段和最多三层底层原因的名称、错误码与说明，不含请求内容、请求头、凭据和网址参数。正常消息排队和送达仅在临时调试时记录；部分送达、发送失败与结果未知会记录频道、送达比例和平台原因。连接首次中断立即记录，同一原因持续中断最多每五分钟汇总一次，原因变化立即记录，恢复时显示中断时长。引用预览的正常降级仅记 Debug，引用信息保存失败记警告。扩展与插件的加载、停止及失败仍保留。定时任务失败会标明所属扩展、任务和回退结果；审批通知失败记录对应智能体，服务请求异常显示方法、路由、状态码和耗时。日志摘要末尾不加句号，堆栈和结构化原始诊断保持原样；已有历史记录不重写。

## 临时调试

平时保存 Info、Warn、Error。选择一个来源或整个实例，可以开启 5、15、30 分钟的 Debug 采集，默认十五分钟。到期、手动结束或服务重启后关闭。

级别筛选只决定查看哪些已保存记录，不会开启采集，也不会补回过去未采集的 Debug。调试开关作用于当前服务实例，其他管理客户端也能看到有效任务。

## 复制、导出与保留

「清空视图」从当前时刻重新观察，不删除服务端历史。

导出支持文本和 JSONL，包含当前筛选的全部结果，不限于屏幕上已经加载的行。导出开始时固定截止点，每次最多 50 MiB，超出时缩小时间范围；同一实例一次执行一个导出。可以取消进行中的导出。

在「设置 → 日志保存」调整保留策略，默认七天、256 MiB。可选 1～30 天、64～2048 MiB，时间或容量达到限制后清理最旧记录。调小保留范围时会提示旧日志将被清理。

日志在保存前隐藏凭据、敏感地址参数和个人目录信息。第三方自由文本仍可能包含业务信息，分享前请检查。超长记录会标记截断，日志过量或存储失败造成的缺口也会明确显示。

## 启动和保存异常

日志保存异常不阻断聊天，关注事项和日志页会提示。先检查磁盘空间、数据目录权限和日志设置，再重新读取。损坏或不支持的日志库不会自动删除。

服务启动后可以回看上次启动失败的日志。完全无法启动时，继续查看服务端控制台或桌面版启动诊断；启动恢复页不开放匿名日志访问。

本期集中记录服务端运行。浏览器自身控制台、桌面主进程及任意直接写入进程字节流的第三方输出，不属于新增的统一采集范围。
