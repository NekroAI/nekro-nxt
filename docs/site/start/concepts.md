# 基本概念

NekroNXT 里的东西不多，弄清这几样之间的关系，其他页面就好读了。

```nxt:diagram
id: concepts-map
title: 几样东西怎么连在一起
type: flow
nodes:
  - id: account
    label: 平台账号
    note: QQ 机器人、微信……
    at: [0, 0]
  - id: channel
    label: 频道
    note: 群、私聊、内置频道
    at: [1, 0]
  - id: agent
    label: 智能体
    note: 人设、模型、能力
    at: [2, 0]
  - id: extension
    label: 扩展
    note: 工具、页面、技能
    at: [2, 1]
edges:
  - from: account
    to: channel
    label: 带进来
  - from: agent
    to: channel
    label: 接线
  - from: extension
    to: agent
    label: 加本事
```

一句话：平台账号把群和私聊带进来，成为频道；你把频道接到某个智能体上，她就在那里说话；扩展给她加本事。

一条群消息到她的回复，大致走这几步：

```nxt:diagram
id: concepts-message-path
title: 一条群消息怎么变成回复
type: flow
animate: true
nodes:
  - id: member
    label: 群友发言
    note: 比如 @ 了她
  - id: account
    label: 平台账号
    note: 收到这条消息
  - id: channel
    label: 频道
    note: 记进聊天记录
  - id: agent
    label: 智能体
    note: 按触发方式决定开口
  - id: reply
    label: 回到群里
    note: 经同一个账号发出
```

## 智能体

一个有名字、有设定、有模型的 AI 角色，是在群里聊天和做事的那一位。你可以有好几个智能体，各自的人设、模型和能力互不影响。

一个智能体可以同时在很多个群里工作，每个群的对话上下文分开，不会把甲群的话带到乙群去。

详见[创建智能体](../agents/create.md)。

## 频道

一个群、一个私聊，或者 NekroNXT 自带的内置频道，都是一个频道。频道保存这里的全部消息记录。

- 内置频道：创建智能体时自动生成，只有你能看到，适合试聊和调试。
- 群和私聊：来自平台账号，见下一节。

一个频道同一时间只交给一个智能体回复；换给另一个智能体时，聊天记录保留。

## 平台账号

你在某个聊天平台上的一个机器人账号，比如一个 QQ 官方机器人，或通过 OneBot 接入的一个 QQ 号。在「接线」里添加。

平台账号不是群本身。账号连上以后，NekroNXT 收到哪个群的消息，那个群才作为频道出现。一个账号可以带来很多个频道；同一个平台也可以添加多个账号。

## 接线

决定“哪个智能体、在什么时候、回复哪个频道”。「接线」页把平台账号、频道、智能体排成三列，从频道拉一根线到智能体就接好了。

接线时要选触发方式，也就是她什么时候开口：被 @ 时、每条消息都回、只旁听不说话等。见[把她拉进第一个群](first-group.md#触发方式怎么选)。

## 能力

智能体的「能力」决定她除了聊天还能做什么，比如搜索网页、读写文件、运行命令、分出子对话、自己写扩展。

读写文件和运行命令默认关闭，按需要逐级打开：

| 级别 | 能做什么 |
| --- | --- |
| 基础权限 | 只能对话，不能读写文件或运行命令 |
| 工作区读写 | 读写她自己工作区里的文件 |
| 运行命令 | 在工作区里运行命令 |
| 完整访问 | 读写工作区以外的文件，范围和 NekroNXT 本身一样 |

## 扩展

给智能体增加本事的功能包：新的工具、新的平台、新的页面等。扩展可以从「社区」安装，也可以让智能体在「工坊」里自己做出来。

装好的扩展要为某个智能体单独启用才会生效。详见[扩展是什么](../extensions/overview.md)。

## 笔记

智能体在每个群里会记两种笔记：关于这个群的（规矩、固定活动、常聊的话题）和关于群里某个人的（怎么称呼、最近在忙什么）。笔记由她自己整理，你可以在频道右侧的「记忆」里查看、修改和锁定。

## 子对话

智能体遇到费时间的事，可以开一个子对话去处理，处理完再回到群里说结果。子对话不在群里发言，显示在所属频道下方。需要在「能力」里打开。
