# ✨ 本次更新

这一版主要面向手机和外网使用：新增 Android 应用，手机浏览器可以添加到主屏幕，登录支持通行密钥和扫码，通知可以发到浏览器推送、企业微信和 ntfy。使用文档搬到了 nxt.nekro.ai/docs，界面和智能体都能直接查阅。添加供应商时可以直接选 NekroAPI。

## 🚀 主要变化

- **Android 应用**：在社区下载页安装 NekroNXT 应用，在「设置 → 登录与访问」点「连接安卓应用」旁的「显示配对码」，用应用扫码连接。关掉应用后也能收到通知，可以在应用里切换实例和更新应用；
- **手机上使用**：手机浏览器首次打开时提示「添加到主屏幕」，左侧菜单里也有这个入口。手机界面重新排过：顶部是页面标题，频道和智能体先列表、再进详情，底部导航悬浮在页面上，频道长按弹出操作，输入框贴着键盘。系统返回手势先关闭浮层；连不上实例时显示提示页；
- **登录与访问**：原来的「登录设备」改为「设置 → 登录与访问」。可以添加通行密钥，用面容、指纹或设备密码登录；新设备可以扫码登录，在已登录的设备上确认。所有设备都能用通行密钥或扫码登录后，可以关闭「用管理密钥登录」。这里还可以填写实例的访问地址，通知里的链接会打开这个地址上的对应页面；
- **通知**：「设置 → 通知」新增浏览器推送、企业微信和 ntfy 渠道，每个渠道可以单独测试。「通知我」里可以分别开关创造任务等待确认运行、社区反馈更新、凭据申请和扩展通知；
- **使用文档**：使用文档搬到 nxt.nekro.ai/docs，按栏目重写并配上截图。顶栏的「?」打开当前页面对应的文档；回复失败、模型不可用、连接异常、消息发送失败、看不懂图片这几类「需要关注」附上「怎么处理」链接；智能体的「能力」里新增「查阅社区文档」，默认开启，智能体回答 NekroNXT 的用法时可以自己去查；
- **NekroAPI**：在「设置 → 模型」添加供应商时，列表第一项是 NekroAPI，地址已填好，只需填 API 密钥；还没有密钥时点「获取密钥」。用 Claude 模型时选「NekroAPI · Claude」入口，Claude 的提示缓存在这个入口下才会生效。「获取可用模型」只列出能用来对话的模型；
- **扩展访问本机服务**：声明了「访问任意公网地址」的扩展，现在也可以访问用户在它的配置里填写的本机或局域网地址，适合既要下载任意网址、又要连接自建服务的扩展。启用时的权限说明会列出这些配置项。

## 🛠️ 改进与修复

- **QQ 语音**：语音和文字不再放在同一条消息里发出，文字和引用不会再被丢掉；
- **升级后起不来**：升级被中断后，实例可能一直无法启动。现在会跳过损坏的升级记录正常启动；Docker 版启动时会把旧镜像留下的、属主不对的文件交还给运行用户；
- **媒体处理**：Windows 桌面版读取媒体信息时不再失败；媒体处理的报错里不再出现本机目录；
- **界面**：附件入口合成一个按钮，手机上直接调起系统选择；下拉选择器再点一次可以关上；手机上长按不再选中文字或弹出系统菜单。

## ⚠️ 升级前留意

- **经反向代理访问的实例**：没有设置 `NEKRO_MANAGEMENT_KEY` 的实例会拒绝经过反向代理的请求；设置了 `NEKRO_TRUST_PROXY` 却没有管理密钥时，实例不会启动。经反向代理访问时请同时设置这两个变量。`NEKRO_TRUST_PROXY` 现在也可以填写反向代理的地址或网段，只采用这些地址发来的转发头；
- **通行密钥和浏览器推送需要 HTTPS**：要通过受信任证书的 HTTPS 域名访问实例，局域网的 HTTP 地址和自签名证书都用不了。iPhone、iPad 要先把 NekroNXT 添加到主屏幕，再从主屏幕打开开启推送。很多国内安卓手机收不到浏览器推送，可以改用 Android 应用，或者用企业微信、ntfy 渠道。
