# 智能体多频道与频道唯一绑定

状态：implemented

## 决策

一个智能体可以同时拥有多个有效 Channel Binding。一个 Channel 同一时间最多只有一个有效 Binding。把频道绑定给另一个智能体时，系统原子替换该频道的当前 Binding。

## 数据与运行语义

- 每个频道的消息、Admission、Episode 和 DSH Session 独立，不混合短期上下文；
- 换绑只改变后续响应所有权，不删除该频道已有消息或 Episode；
- Binding 表保存当前关系，以 `channel_id` 保证一个频道只有一个当前智能体；
- 换绑、解绑和频道删除按 `channelId` 串行，在转换锁内重读当前 Binding，再进入实际前任智能体的运行 lane；并发 A→B、A→C 不会跳过 B 的 Session 静止；
- 智能体页面展示全部已绑定频道；绑定频道是新增关系，不替换该智能体的其他频道。

## 验证

- `packages/channel-runtime` 使用受控并发场景覆盖连续换绑时实际前任 Session 被关闭；`packages/core`、`packages/storage-sqlite`、Server Host API 与产品旅程覆盖同一智能体绑定多个频道，以及换绑后该频道只保留一个当前智能体。

## 非目标

跨频道短期上下文合并、自动消息迁移、批量解绑和隐式跨频道发送。
