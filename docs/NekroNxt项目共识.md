# NekroNXT 项目共识

> 用途：一页看清产品是什么。铁律见根 `AGENTS.md`，进度见 `04-一期开发计划与决策清单.md`，界面见产品形态与交互模型。

NekroNXT 以 DSH 为智能体内核，以智能体为产品中心，支持网页和多平台群聊，并让用户授权的智能体在界面里创造、运行、修改和保存本地扩展。它不是 Nekro Agent 的升级版，不迁移旧数据，不兼容旧插件。

用户显式创建智能体，再配置人设、模型、能力、本地扩展和一个或多个频道。一个智能体可以同时绑定多个频道；一个频道同一时间只由一个智能体响应。用户可见发言只通过通信工具发送。动态运行、保存扩展版本和给智能体启用是三个独立动作。

交付两个宿主、一套 Runtime：Windows/macOS 安装即用的 Desktop，以及单容器、单 `/data` 的 Server。首版先做完本地创造闭环、Web 对话和首个外部频道，再交付 Desktop/容器，最后才考虑社区。

不在首版做：社区市场、签名、SBOM、全部聊天平台、多租户、云端强依赖、完整 Fork DSH，或把 Core 数据库当成插件 API。
