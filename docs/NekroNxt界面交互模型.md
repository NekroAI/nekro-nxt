# NekroNXT 界面交互模型

> 用途：约束界面的对象、状态和操作后果
> 状态：现行（[客户端体验重构与扩展界面统一](decisions/accepted/2026-10-04-客户端体验重构与扩展界面统一.md)落地后）
> 原则：先定义对象、状态和操作后果，再设计控件
>
> 视觉 Token、组件和动效遵循 `05-桌面UI与动效规范.md`。用户可见改动的像素级验收遵循 `06-开发与测试规范.md` §5.1。

> 文案铁律：界面中的实体统一称“智能体”。Agent、AI 成员、Bot、助手不得作为同一实体的替代类型名；英文内部类型不得直接显示给用户。空间与交互术语见 `01-术语与文案规范.md` §3.1。

## 1. 全局对象规则

### 1.1 每个空间只有一个主要对象

| 空间 | 路由 | 主要对象 | 次要上下文 |
|---|---|---|---|
| 现场 | `/live` | 需要关注的事项与活动中的频道 | 近期活动潮汐 |
| 频道 | `/channels/:channelId` | 当前频道的消息时间线 | 检查器：响应智能体、上下文、来源 |
| 智能体 | `/agents/:agentId`、`/agents/new` | 智能体资料（新建时为草稿） | 频道、技能、版本 |
| 工坊 | `/workshop/tasks/:taskId`、`/workshop/extensions/:extensionId` | 创造任务或本地扩展 | 发起任务的智能体、使用它的智能体 |
| 接线 | `/wiring/connections/:id`、`/wiring/channels/:id`、`/wiring/new` | 平台账号或频道的绑定关系 | 接线板全景 |
| 设置 | `/settings/:section` | 一个设置分区 | 无 |
| 扩展页面 | `/apps/:pageInstanceId/*` | 扩展自有页面 | 无 |

进入应用默认打开现场。打开 `/channels` 时回到上次打开的频道，没有记录时打开第一个频道。

### 1.2 智能体与频道的关系

- 智能体是长期产品实体；频道是一段消息事实流；
- 频道绑定决定哪个智能体响应该频道；一个智能体可同时绑定多个频道，一个频道同一时间只有一个响应智能体；
- 换绑改变后续响应，不删除频道已有消息；
- 频道时间线只显示该频道的消息；短期上下文不跨频道混合。

### 1.3 扩展的独立动作

```text
动态运行（工坊中的创造任务）
→ 保存为本地扩展的不可变版本
→ 智能体扩展：启用给一个或多个智能体（需要时先批准权限）
  或 宿主扩展：安装到本机（页面扩展需要先批准权限）
```

- 动态运行：临时、可停止；
- 保存：版本持久化，但不自动启用；
- 启用 / 安装：明确作用于哪个智能体或本机、使用哪个版本。卸载适配器保留连接和历史。

## 2. 状态词典

### 2.1 本机状态

正在连接、运行正常、连接不稳定、无法连接。连接不稳定时保留最后一次成功的数据。

### 2.2 平台账号状态

已连接、正在连接、已配置、认证过期、已断开、异常。

### 2.3 智能体运行状态

- 空闲：没有活动轮次；
- 思考中：模型正在生成；
- 使用工具：工具正在运行；
- 等待输入：等待用户回答或批准；
- 不可用：模型、配置或运行时有错误。

不使用含糊的“在线”。

### 2.4 创造任务状态

正在开发、等待确认、正在验证、可以保存、正在修复、需要处理（失败或中断）、已停止、已保存。

### 2.5 扩展状态

智能体扩展：未启用、N 个智能体使用、运行异常。宿主扩展：未安装、已安装、运行异常。版本格式不再受支持时标记“格式不受支持”，该版本不能启用。

## 3. 应用外壳

- **导航轨**：现场、频道、智能体、工坊、接线；设置在底部。扩展页面不自动进入导航轨。
- **顶栏**：服务实例（Desktop 中点击打开实例切换）、面包屑、搜索、关注铃。
- **状态栏**：本机、每个平台账号、正在工作的智能体，各自点击进入对应对象。
- **命令面板**（`⌘K` / `Ctrl+K`）：分组为前往、频道、智能体、扩展页面、操作（新建智能体、切换浅色或深色）和成员。输入时向服务查找平台成员，选中后打开成员所在频道或所属账号。上下键选择，回车打开。
- **关注铃**：数字为需要关注的事项数，点击回到现场。
- **升级提示**：服务已升级而页面未刷新时，画布顶部提示刷新；刷新前保存频道草稿，有未保存表单时先确认。

## 4. 现场

- 顶部统计：正在工作的智能体、需要关注的事项、近期消息数；
- **活动潮汐**：近两小时（无数据时扩展到一天）各频道的消息量，悬停显示该时刻的分频道数量；
- **需要关注**：未确认投递、投递失败、失败轮次、等待确认的创造任务、异常账号、缺少模型或识图模型。每条给出一个直接动作（打开频道、打开任务、打开账号、打开智能体）和“忽略”。同一智能体的同类事项三条以上折叠为一行。忽略持久保存；同一问题再次出现会重新列出；
- **活动频道**：有近期消息或正在工作的频道卡片，显示响应智能体、末条消息和活动曲线；其余频道收为一行快捷入口；
- 引擎升级后的上下文归档说明与兼容性隔离提示也在这里显示，可重新检查。

## 5. 频道

### 5.1 频道列表

- 两种视图：“按智能体”分组和“最近活动”；
- 按智能体视图支持拖动：组内调整顺序；拖到另一个智能体组即换绑，拖到“未接线”即解绑。跨组放下后弹出确认，确认框显示前后接线与触发方式；
- 每行副标题显示连接展示名（`alias ?? 适配器名`），有未读时显示数量。

### 5.2 时间线

- 成员消息、管理员从客户端发出的消息与智能体发言分开呈现；智能体发言只来自通信工具；
- 每个智能体轮次在常态下显示一行工具摘要。打开头部的“透视”后，同一时间线展开思考、工具输入输出、扩展工具视图和用量，不跳转到另一视图；
- 未确认送达的出站消息显示“重发”和“已送达”两个处理动作；
- 打开频道即推进阅读位置。

### 5.3 排队与停止

- 工具执行期间到达的新消息会被收录并排队，在安全间隙注入；时间线底部显示“N 条新消息排队中”，可展开查看；
- 正在进行的轮次带“停止”按钮，确认后中止当前模型或工具，不清空上下文，已完成的步骤不撤回，排队的消息保留。普通新消息不会隐式取消当前工具。

### 5.4 Composer

- 发给内置频道时直接提交；发到外部频道时标明以哪个平台账号发出，记为“管理员从客户端发出”；
- 输入法组字期间回车不发送；无法发送时就地说明原因；
- 草稿按频道保存，切换频道和刷新后保留。

### 5.5 检查器

- 响应：当前智能体、触发方式，可换绑或解绑；
- 上下文：占用量与来源构成，可“压缩上下文”或“清空上下文”（均需确认）；
- 来源：所属平台账号，可跳到接线；内置频道可删除，外部频道可移除；
- 扩展面板：频道面板与该频道响应智能体的紧凑面板。

## 6. 智能体

### 6.1 新建

填写名称、设定和模型后创建；创建会同时生成一个内置频道，完成后进入该频道。

### 6.2 资料页

- 顶部：头像、名称、当前状态、模型；缺少模型或识图模型时显示提示；
- **设定**：名称、设定文本（支持结构化引用）、模型、识图模型。修改后底部出现“发布新版本”栏，显示与当前版本的逐行差异；发布产生新的不可变版本，运行中的会话在安全点切换；
- **频道**：该智能体响应的频道与各自触发方式；
- **技能**：系统访问（基础权限 / 文件读写 / 运行命令 / 完整访问，运行命令及以上需确认）、子智能体、网页搜索（缺凭据时可就地保存）、动态创造，以及作用于智能体的扩展开关（需要时先批准权限）；
- **扩展面板**：该智能体启用的扩展贡献的完整面板；
- **版本**：全部历史版本与各版改动的字段，可把任一旧版本恢复为当前版本；
- **删除**：输入名称确认；可选同时删除它自动创建的内置频道、同时删除工作区。

## 7. 工坊

### 7.1 列表

左侧分为“创造任务”（需要处理的排在前面）与“本地扩展”。顶部可导入 `.nxt-extension` 文件，导入后不自动启用。没有任务和扩展时，列出已开启动态创造的智能体，点击进入其频道描述需求。

### 7.2 创造任务

- 进度：生成候选 → 确认运行 → 启动 → 界面验证 → 保存 → 启用；失败步骤标红；
- 下一步：根据状态只给一个主动作——等待确认时“允许运行 / 拒绝”；通过验证后“保存为扩展”；已保存后“查看扩展 / 给某智能体启用”；失败时显示失败阶段与原因，可回到已验证的上一次候选；
- 预览：任务进行中显示候选界面；界面验证在浏览器中完成，需要保持页面打开；
- 尝试：全部候选尝试与各自状态；
- 保存：保存为新扩展，或保存为已有扩展的新版本；
- 停止任务、删除任务记录（已保存的扩展保留）。

### 7.3 本地扩展详情

- 智能体扩展：每个智能体一行，选择使用的版本并开关；
- 宿主扩展：选择版本安装或切换、卸载，页面扩展安装前批准权限；
- 配置：扩展声明的配置项；
- 版本：每个版本的能力、验证记录与导出；
- 删除扩展。

## 8. 接线

- 接线板三列：平台账号 → 频道 → 智能体。从频道端口拖到智能体即接线（确认后生效）；点击端口用列表选择智能体；点击连线可换绑或断开；
- 右侧详情：平台账号显示状态与错误、名称、频道、频道活动默认触发、诊断（测试接收、测试发送）、扩展面板、成员列表、重新扫码登录（扫码类平台）与删除（可选同时删除频道数据）；
- **添加账号**（`/wiring/new`）：先选平台，再填写统一配置表单或扫码登录；也可恢复已移除的账号；
- 窄窗口改为“频道 + 响应智能体选择”的列表。

## 9. 设置

模型、平台适配器（标注内置或本地扩展来源，可直接添加账号）、DSH 插件、通知（系统通知、Bark、通知事项）、外观（主题、减少动态效果）、关于。

## 10. 扩展贡献的放置

| 贡献 | 出现位置 |
|---|---|
| 智能体面板 | 智能体资料页（完整）；它响应频道的检查器（紧凑） |
| 频道面板 | 频道检查器 |
| 扩展面板 | 工坊扩展详情 |
| 连接面板 | 接线账号详情（状态、诊断）；添加账号页（设置） |
| 工具视图 | 时间线工具摘要（chip）与透视卡片（card） |
| 富消息渲染器 | 时间线中对应适配器的富消息 |
| 页面 | 命令面板“扩展页面” |

没有贡献时不渲染任何占位。

## 11. 按钮命名铁律

1. 动词说明对象：用“停止当前任务”“压缩上下文”，不用孤立的“确定”；
2. 保存和生效分开：“保存为扩展”“给小奈启用”；
3. 不使用“查看”而不说明查看什么；
4. 危险动作只在真正危险时使用警示色，并在确认框中说明后果与保留的对象；
5. 不可执行的按钮说明前置条件；
6. 每个主按钮只产生一种可解释的状态变化。

## 12. 未开放

未实现的操作不出现在界面中；必须展示时禁用并标注“尚未开放”，不占据一级导航或主操作位置。
