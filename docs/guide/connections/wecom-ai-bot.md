# 接入企业微信智能机器人

NekroNXT 通过企业微信智能机器人长连接接收和发送消息。配置仅需 BotID 与长连接 Secret；连接由 NekroNXT 主动建立，无需公网回调地址、固定公网 IP、Token 或 EncodingAESKey。

```text
企业微信成员或群聊
  ↕
企业微信智能机器人
  ↕ 官方长连接
NekroNXT → 发现单聊或群聊 → 绑定智能体
```

## 开始前准备

准备以下内容：

- 一个可管理智能机器人的企业微信测试企业；
- 一个已启用 API 模式的智能机器人；
- 智能机器人配置页提供的 BotID 与长连接 Secret；
- NekroNXT 中至少一个可用的智能体。

一个 BotID 同时只允许一个有效长连接。测试环境、开发环境和正式环境应分别创建机器人，避免不同实例互相断开连接。

## 在企业微信创建智能机器人

1. 登录企业微信管理后台，进入智能机器人配置；
2. 创建智能机器人并选择 API 模式；
3. 在 API 模式中选择长连接；
4. 保存 BotID 与长连接 Secret；
5. 将机器人添加到测试群聊，并确认测试成员可以打开机器人单聊。

API 长连接与“设置接收消息地址”的 Webhook 模式互斥。切换模式会改变接入凭据和消息链路，NekroNXT 使用长连接模式。

Secret 是只写凭据。保存后 NekroNXT 只显示凭据状态；截图、日志和问题报告中不应包含 Secret。

## 在 NekroNXT 添加连接

1. 前往「连接」，点击「添加平台连接」；
2. 选择「企业微信智能机器人」；
3. 填写企业微信配置页中的 BotID；
4. 填写长连接 Secret；
5. 可设置连接别名，然后创建连接；
6. 等待连接状态变为「已连接」。

Endpoint 固定为 `wss://openws.work.weixin.qq.com`，无需填写。首版不提供私有化企业自定义 Endpoint、自签 CA 或 TLS 文件配置。

连接连续三次认证失败后会停止重连。修正 BotID 或 Secret 后重新建立连接。同一 BotID 被另一个实例连接时，当前连接进入“连接冲突”状态并停止重连。

## 发现频道并绑定智能体

1. 在单聊中向机器人账号发送一条消息；
2. 在测试群聊中提及机器人账号并发送一条消息；
3. 返回连接页面，分别运行接收测试；
4. 选择已发现的单聊或群聊，运行发送测试；
5. 点击「绑定智能体」，设置响应智能体和响应方式；
6. 在群聊中再次提及机器人账号，确认智能体能够响应。

企业微信群消息只有在成员提及机器人账号时才会推送给智能机器人。NekroNXT 会把这些消息标记为已提及机器人账号；消息正文中的 `@名称` 保持平台原文，不转换为结构化 Mention。

企业微信可能根据企业主体返回明文或加密 userid。NekroNXT 将回调中的 userid 作为当前 Connection 范围内的稳定成员身份；显示名缺失时使用中性成员展示。

主动发送需要目标成员或群聊先向机器人发送消息。企业微信建立会话授权后，NekroNXT 才能使用已发现的 userid 或 chatid 发送消息。

## 处理中状态

「显示处理中状态」默认开启。群消息实际触发智能体后，NekroNXT 使用企业微信流式消息显示“正在处理…”。智能体首次发送纯文本时，该流式消息会替换为实际内容并结束；后续文本分片或媒体按普通消息发送。

- Session 正常结束且没有文本发言时，状态更新为“处理已结束。”；
- 错误、取消、超时或服务停止时，状态更新为“处理未完成。”；
- 处理持续九分钟时，状态更新为“处理仍在继续，结果将另行发送。”，后续结果使用主动发送；
- 企业微信要求流式消息在十分钟内完成。

私聊不自动创建处理中占位消息。

## 消息和媒体范围

首版接收文本、图文混排、图片、语音转写、文件、视频和引用摘要。企业微信引用回调不含被引消息 ID，因此引用只保存安全摘要，不建立内部引用关系。

主动发送范围：

| 内容 | 格式 | 单个文件上限 |
|---|---|---:|
| 文本 | Markdown | 20,000 UTF-8 字节/条 |
| 图片 | PNG、JPEG、GIF | 10 MiB |
| 语音 | AMR | 2 MiB |
| 视频 | MP4 | 10 MiB |
| 普通文件 | 任意文件 | 20 MiB |

Adapter 直接发送现有 Asset 字节，不执行图片、音频或视频转码。其他音频格式需要在发送前转换为 AMR，其他视频格式需要在发送前转换为 MP4。

## 特殊事件

频道绑定可以逐项启用以下事件触发智能体：

- 进入机器人会话；
- 触发模板卡片操作；
- 提交正向反馈；
- 提交负向反馈；
- 撤销消息反馈。

这些事件默认进入频道事实流但不触发智能体。「仅观察」会同时关闭普通消息和特殊事件触发。首版记录模板卡片操作，但不更新或主动发送模板卡片。

进入会话事件启用触发后，智能体首条纯文本可以在企业微信规定的五秒窗口内作为欢迎语发送；超过窗口会返回明确失败。

## 最小验收清单

- BotID 与 Secret 可以建立长连接；
- 群聊提及和机器人单聊均能接收文字消息；
- 已发现的群聊和单聊均能完成发送测试；
- 图片、语音转写、文件、视频和引用摘要能够进入频道；
- 群聊触发时可以创建并结束处理中状态；
- 正向、负向和撤销反馈能够进入频道；
- 断网恢复后自动重连；
- 使用相同 BotID 建立第二条连接时，旧连接进入连接冲突状态。

当前实现已通过合成协议夹具和自动化测试，尚未完成独立企业微信测试企业的实机验收。完成真实消息、媒体、反馈、欢迎语、重连和连接冲突测试后，才能标记为“已验证支持”。

## 按症状排障

### 认证连续失败

- 确认使用的是智能机器人 API 长连接 Secret；
- 核对 BotID 与 Secret 是否来自同一个机器人；
- 确认机器人仍处于 API 长连接模式；
- 修改凭据后重新建立连接。

### 群聊没有收到消息

- 确认机器人账号已经加入目标群聊；
- 发送消息时明确提及机器人账号；
- 确认当前 BotID 没有被另一套 NekroNXT 或测试程序连接；
- 回到连接页检查最近诊断并重新运行接收测试。

### 主动发送失败

- 先让目标成员或群聊向机器人发送一条消息；
- 确认发送目标来自当前 Connection 已发现的频道；
- 检查每会话 30 条/分钟、1000 条/小时的平台限制；
- 媒体失败时核对格式与大小限制。

### 处理中状态没有结束

- 检查连接是否在流式更新期间断开；
- NekroNXT 重启后会在企业微信十分钟窗口内尝试结束遗留状态；
- 写入后结果无法确认时停止后续更新，由企业微信在十分钟后自动结束流式消息。
