# 把她拉进第一个群

[快速开始](quickstart.md)里，智能体只在内置频道里和你一个人聊。这一页把她接进一个真正的群：先添加一个平台账号，等群出现在 NekroNXT 里，再把群交给智能体。这里以 QQ 官方机器人为例，其他平台只有第一步不同。

## 开始前

- 已经配好模型、创建了一个智能体；
- NekroNXT 能访问外网。QQ 官方机器人由 NekroNXT 主动连出去，不需要公网地址，也不用开端口；
- 一个手机 QQ，用来在 QQ 开放平台创建机器人。

## 1. 在 QQ 开放平台创建机器人

这一步在 QQ 那边完成，按 [QQ 机器人官方文档](https://bot.q.qq.com/wiki/)操作：创建机器人，拿到 AppID 和 AppSecret。

AppSecret 只在创建或重置时完整显示一次，复制下来妥善保存；再次查看会重置，旧的就失效了。

机器人能进哪些群，由 QQ 平台给它开放的范围决定。新建的机器人一般先只对创建者开放，可以用平台提供的测试群来验收。

## 2. 添加平台账号

1. 打开「接线」，点右上角的「添加平台账号」；
2. 在平台列表里选「QQ 官方机器人」；
3. 「名称」随便起一个，方便以后区分，比如“小奈的 QQ 机器人”；
4. 把 AppID 填进「App ID」，AppSecret 填进「Client Secret」；
5. 点「添加账号」。

![填写 QQ 官方机器人的 App ID 和 Client Secret](shot:first-group-qq-form)

添加后会自动打开这个账号的详情。状态变成「正常」就说明连上了；如果停在“正在连接”或者提示认证失败，见[平台接入排障](../troubleshooting/platforms.md)。

## 3. 让群出现

账号刚连上时，频道一栏是空的。NekroNXT 只有在收到群里的消息之后，才知道这个群存在。

到 QQ 群里 @ 一下机器人，随便说一句话。稍等片刻，这个群就会出现在账号详情和接线板的频道一栏，标着「未接线」。

![账号连上后，群出现在频道一栏，还没有接线](shot:first-group-account)

QQ 官方机器人一般拿不到群名，群会先显示成“未命名群聊”。群多的时候，先在频道页点「修改频道名称」改个好认的名字。

## 4. 把群交给智能体

在接线板上点这个群，右侧「谁来回复」里有「智能体」一项，选你的智能体。也可以直接从群右侧的圆点拖一根线到智能体上。

确认框里的「触发」决定她什么时候开口，群聊默认是「被提及时」：有人 @ 她，或者回复她的消息时才回答。第一次先用这个，确认能正常回复再按需要改。点「接线」完成。

![选好智能体和触发方式，点「接线」](shot:first-group-bind)

接好以后，群和智能体之间多了一根线，群下方显示当前的触发方式。以后想换，改右侧的「何时回复」即可，马上生效。

![接线完成：群已交给智能体，触发方式是「被提及时」](shot:first-group-wired)

## 5. 在群里试一试

回到 QQ 群，@ 机器人说句话，智能体会在群里回复。点右下角的「打开频道」，可以在 NekroNXT 里看到这个群的消息；回复没出来时，点频道顶部的「透视」看看她这一轮做了什么。

## 触发方式怎么选

| 触发 | 什么时候回复 | 适合 |
| --- | --- | --- |
| 被提及时 | 有人 @ 她或回复她的消息 | 大多数群，群聊默认 |
| 智能响应 | 除了 @ 和回复，有人提到她的名字或别名、刚和她聊过的人接着说，她也会接话 | 想让她更像群里的一员；花费更高 |
| 每条消息 | 每条消息都交给她 | 私聊、人少的小群 |
| 仅观察 | 只记录，不回复 | 想先让她旁听一阵 |

QQ 官方机器人在群里通常只能收到 @ 它的消息，所以“每条消息”和“智能响应”在 QQ 官方群里和“被提及时”差别不大。想让她听到群里的每一句话，用 [OneBot V11](../channels/onebot-11.md) 接入。
